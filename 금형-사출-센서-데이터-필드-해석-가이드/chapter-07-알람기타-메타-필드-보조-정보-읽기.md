# 7. 알람·기타 메타 필드 — 보조 정보 읽기

## 알람 필드(Alarms)의 이진 해석

`Alarms` 필드는 측정된 수치나 양을 나타내는 연속형 데이터가 아니라, 공정의 정상 여부를 구분 짓는 **이진(Binary) 지표**입니다. 따라서 이 필드의 값을 해석할 때는 수치적 크기가 아닌 '상태'에 집중해야 합니다.

| 필드명 | 값 | 해석 |
| :--- | :--- | :--- |
| **Alarms** | 1 | True (알람 발생 / 이상 상태) |
| **Alarms** | 0 | False (알람 미발생 / 정상 상태) |

**그래서 이 필드가 뜻하는 바는 다음과 같습니다.**
해당 샷(Shot)이 진행되는 동안 설비에 알람이 발생했는지 여부를 나타내는 플래그(Flag) 값입니다.

## 데이터 식별을 위한 Label 필드

`Label` 필드는 물리적인 측정값이나 공정 조건과는 무관한 **단순 일련번호**입니다. 

- **해석:** 데이터셋 내에서 각 행을 구분하기 위해 부여된 고유 번호입니다.
- **용도:** 특정 시점의 데이터를 빠르게 식별하거나, 데이터의 전체적인 순차적 흐름을 추적하는 용도로 활용합니다.

**그래서 이 필드가 뜻하는 바는 다음과 같습니다.**
물리적 의미가 없는 단순 식별자로, 데이터의 정렬 상태나 누락 여부를 확인하는 용도로 사용됩니다.

## 설명 미제공 필드의 명시적 정리

데이터셋에는 포함되어 있으나, 제공된 필드 설명 자료에서 구체적인 정의가 확인되지 않은 필드들이 존재합니다. 분석가는 이러한 필드를 임의로 추측하여 해석하는 오류를 범해서는 안 되며, **'설명 미제공'** 상태로 명확히 분류하여 데이터의 한계를 정의해야 합니다.

| 필드명 | 설명 |
| :--- | :--- |
| **Weight1** | 설명 미제공 |
| **Weight2** | 설명 미제공 |
| **Quality** | 설명 미제공 |
| **Worker** | 설명 미제공 |
| **Part No(Injection Machine)** | 설명 미제공 |

**그래서 이 필드들이 뜻하는 바는 다음과 같습니다.**
현재 제공된 자료만으로는 해당 필드들이 무엇을, 어느 시점에, 어떤 단위로 측정했는지 알 수 없으므로 분석 대상에서 제외하거나 추가 확인이 필요합니다.

## 보조 필드 활용 시의 주의사항

본 챕터에서 다룬 알람, 라벨 등의 보조 필드는 단독으로 분석하기보다 앞서 다룬 **센서 데이터(T, P) 및 공정 시간 데이터(ProcessTime)와 결합**하여 해석해야 합니다.

보조 필드는 주 공정 데이터의 이상 유무를 알려주는 '신호' 역할을 합니다. 예를 들어 `Alarms` 값이 '1'인 경우, 해당 시점의 온도 센서 값이나 압력 센서의 레진 도달 시간 등에 어떤 특이점이 있었는지를 역추적하는 방식으로 활용하는 것이 올바른 분석 방향입니다.

***

**핵심 정리**
- `Alarms`는 0(정상)과 1(이상)로 구분되는 이진 지표이다.
- `Label`은 물리적 의미가 없는 단순 일련번호이다.
- 설명이 없는 필드(`Weight`, `Quality` 등)는 임의로 추론하지 않고 '설명 미제공'으로 처리한다.
