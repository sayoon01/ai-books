# 4. 온도 센서 T1~8과 접미사 — 시점이 다른 네 가지 온도

## 온도 센서 채널(T1~T8)의 정체

데이터셋에서 `T1`부터 `T8`까지 반복적으로 등장하는 필드들은 금형 내부에 물리적으로 배치된 **8개의 온도 센서 채널**을 의미합니다. 

여기서 필드명에 붙은 숫자(1~8)는 각 센서의 위치를 구분하기 위한 식별자입니다. 즉, 동일한 접미사가 붙어 있더라도 `T1_Start`와 `T2_Start`는 서로 다른 지점에서 측정된 값입니다. 분석 시에는 특정 센서 하나만 보는 것이 아니라, 8개 채널의 전체적인 경향성을 함께 파악하는 것이 중요합니다.

## 시점별 온도 측정: Start, End, Max

온도 센서 필드 중 `_Start`, `_End`, `_Max` 접미사가 붙은 데이터는 실제 **온도(℃)**를 측정한 값입니다. 이 접미사들은 사출 공정의 타임라인 상에서 '어느 시점'의 온도를 기록했는지를 구분하는 기준이 됩니다.

| 접미사 | 측정 시점 및 의미 | 단위 |
| :--- | :--- | :--- |
| **`_Start`** | 사출이 시작되기 전, 금형의 초기 온도 | ℃ |
| **`_End`** | 사출이 완료된 후, 제품을 취출(Ejecting)하기 전의 온도 | ℃ |
| **`_Max`** | 해당 사이클 공정 중 센서에 기록된 가장 높은 온도 | ℃ |

**$\rightarrow$ 이 필드들은 사출 전-중-후의 온도 변화를 추적하여 금형의 열적 상태를 파악하는 데 사용됩니다.**

## 주의: T*_Detect의 정체 — 온도가 아닌 '시간'

데이터 해석 시 가장 주의해야 할 지점이 바로 `_Detect`와 `_MaxDetect` 필드입니다. 필드명이 `T`(Temperature)로 시작하기 때문에 온도 값으로 오해하기 쉬우나, 실제로는 **레진이 해당 센서 위치에 도달한 '시간'**을 측정한 데이터입니다.

*   **`T*_Detect`**: 레진이 각 센서(T1~T8)에 도달한 시점의 시간 (단위: 초)
*   **`T*_MaxDetect`**: Detect 값 중 최대 시간 (단위: 초)

이 필드들은 '얼마나 뜨거운가'가 아니라 **'레진이 얼마나 빨리/느리게 흘러갔는가'**를 나타내는 지표입니다. 따라서 앞서 설명한 `_Start`, `_End`, `_Max`와는 측정 대상 자체가 완전히 다릅니다.

**$\rightarrow$ `T*_Detect` 시리즈는 온도(℃)가 아니라 시간(초) 데이터임을 명확히 구분하여 해석해야 합니다.**

## 접미사 오독으로 인한 분석적 오류

접미사의 의미를 정확히 구분하지 않고 데이터를 분석할 경우, 성격이 전혀 다른 두 데이터를 섞어 분석하는 치명적인 오류가 발생할 수 있습니다.

1.  **시점 혼동의 오류**: `T*_Start`와 `T*_End`의 차이를 분석하면 '사출로 인한 온도 상승분'을 알 수 있지만, 여기에 `T*_Max`를 잘못 섞으면 공정 중 일시적인 피크치와 시점별 상태 값을 혼동하게 됩니다.
2.  **측정 대상 혼동의 오류**: 가장 위험한 사례는 `T*_Detect`를 온도 데이터로 인식하는 것입니다. 만약 `T*_Detect`를 온도 값으로 간주하여 다른 온도 필드들과 함께 평균을 내거나 편차 분석을 수행한다면, 온도(℃)와 시간(초)이라는 서로 다른 물리량이 합쳐져 아무런 의미 없는 수치가 산출됩니다.

따라서 분석 전, 해당 필드가 **'온도'**를 뜻하는지 **'도달 시간'**을 뜻하는지를 접미사를 통해 반드시 먼저 확인해야 합니다.

## 핵심 정리: 온도 센서 필드 해석 맵

온도 센서 관련 필드의 해석 기준을 요약하면 다음과 같습니다.

| 구분 | 접미사 | 측정 대상 | 측정 시점 | 단위 |
| :--- | :--- | :--- | :--- | :--- |
| **온도 데이터** | `_Start` | 온도 | 사출 전 | ℃ |
| | `_End` | 온도 | 취출 전 | ℃ |
| | `_Max` | 온도 | 공정 중 최대치 | ℃ |
| **시간 데이터** | `_Detect` | **도달 시간** | 레진이 센서에 도달한 때 | **초** |
| | `_MaxDetect` | **도달 시간** | 도달 시간의 최대치 | **초** |

*   **T1~T8**은 물리적 센서 위치를 나타내는 식별자이다.
*   **`_Detect`**가 붙은 필드는 이름과 달리 온도가 아닌 **'시간'** 데이터이다.
*   분석 시 **℃(온도)**와 **초(시간)** 단위를 엄격히 구분하여 접근해야 한다.
