# 8. 종합 — 이 데이터로 무엇을 읽을 수 있는가

## 데이터 필드의 유기적 결합: 한 샷(Shot)의 디지털 초상화

지금까지 살펴본 개별 필드들은 독립적인 수치가 아니라, 하나의 행(Row)으로 묶여 **'사출 1회(Shot)'라는 물리적 사건**을 디지털로 재구성한 기록물입니다. 데이터셋의 한 행은 다음과 같은 유기적 결합을 통해 해당 샷의 전체 맥락을 기술합니다.

*   **식별 필드 (Who/What):** `Model`, `PartNo`, `Resin` 등의 필드는 "어떤 제품을, 어떤 재료로, 어떤 조건에서 생산했는가"라는 기초 배경을 정의합니다.
*   **온도 및 압력 필드 (How/State):** `T1~8`, `P1~8` 센서 데이터는 "레진이 금형 내부를 흐를 때 물리적 상태가 어떠했는가"라는 공정의 상태(State)를 정밀하게 묘사합니다.
*   **공정 시간 필드 (Sequence/Duration):** `ProcessTime1~6`과 `CycleInterval`은 "각 단계가 어떤 순서로, 얼마만큼의 시간이 소요되었는가"라는 시간적 흐름(Sequence)을 완성합니다.

결국, 이 데이터의 한 행을 읽는다는 것은 단순히 숫자를 보는 것이 아니라, **[식별 정보 $\rightarrow$ 물리적 상태 $\rightarrow$ 시간적 흐름]**으로 이어지는 사출 공정의 '디지털 초상화'를 확인하는 것과 같습니다.

## 해석의 범위와 한계: '무엇'과 '어떻게'의 구분

분석가는 본 가이드가 제공하는 '필드 해석'의 범위와 이후 수행할 '통계 분석'의 범위를 명확히 구분해야 합니다. 데이터 스키마를 이해하는 것과 그 데이터를 통해 인사이트를 도출하는 것은 서로 다른 단계입니다.

| 구분 | 필드 해석 (Schema Interpretation) | 통계 분석 (Statistical Analysis) |
| :--- | :--- | :--- |
| **목적** | 데이터의 정의와 측정 의미 파악 | 공정의 이상 유무 및 인과관계 규명 |
| **확인 가능한 것** | 측정 시점, 측정 단위, 필드의 물리적 의미 | 적정 온도/압력의 임계치, 불량률과의 상관관계 |
| **분석 내용** | "T1_Start는 사출 전 금형 온도이다." | "T1_Start가 X도 이상일 때 불량률이 높아진다." |

본 가이드는 **'무엇을 측정했는가'**에 대한 정의를 내리는 단계입니다. 이를 통해 데이터의 정체성을 정확히 파악했다면, 이후에는 별도의 통계적 접근을 통해 **'어떻게 제어해야 하는가'**에 대한 답을 찾아야 합니다.

## 데이터 핸들링 시 주의사항: 오독을 막는 세 가지 원칙

데이터를 실제 분석 도구(Python, Excel, SQL 등)에 올리기 전, 잘못된 해석으로 인한 오류를 방지하기 위해 다음 세 가지 원칙을 반드시 준수하십시오.

**1. 단위 변환의 필수성**
`ProcessTime1~6` 필드는 원시 데이터 상태 그대로 사용해서는 안 됩니다. 반드시 **1,000으로 나누어 초(Second) 단위로 변환**한 후 분석에 활용하십시오.

**2. 접미사의 엄격한 구분**
`_Detect` 또는 `_MaxDetect`라는 접미사가 붙은 필드는 온도($^\circ\text{C}$)나 압력($\text{bar}$) 수치가 아닙니다. 이는 레진이 해당 센서에 도달하기까지 걸린 **'시간(초)'**을 의미하므로, 물리량과 시간량을 혼동하여 계산하는 오류를 주의하십시오.

**3. 설명 미제공 필드의 임의 해석 금지**
`Weight1`, `Weight2`, `Quality`, `Worker` 등 자료에서 설명이 제공되지 않은 필드(`-` 표기)는 분석가의 추측으로 의미를 부여해서는 안 됩니다. 확인되지 않은 필드는 '설명 미제공' 상태로 두고, 필요시 현업 담당자를 통해 공식적인 정의를 확인하십시오.

## 결론: 데이터 해석이 분석의 시작점이다

데이터 분석의 성패는 고도화된 알고리즘이 아니라, 분석 대상이 되는 데이터의 의미를 정확히 이해하는 **'데이터 리터러시(Data Literacy)'**에서 결정됩니다. 필드 하나하나의 측정 시점과 단위, 물리적 의미를 정확히 짚어내는 과정이 전제되지 않은 분석은 잘못된 결론으로 이어질 위험이 큽니다.

본 가이드를 통해 구축한 필드 해석 능력을 바탕으로, 이제 단순한 숫자들의 집합인 데이터셋을 실제 물리적 공정의 흐름으로 읽어내어 유의미한 분석을 수행하시기 바랍니다.

***

**핵심 정리**
*   한 행(Row)은 **[식별 $\rightarrow$ 상태 $\rightarrow$ 시간]** 정보가 결합된 사출 1회(Shot)의 완성된 기록이다.
*   본 가이드는 **필드의 정의(What)**를 다루는 것이며, **최적 조건(How)**을 찾는 것은 통계 분석의 영역이다.
*   **단위 변환(ProcessTime $\div$ 1,000)**, **접미사 구분(Detect = 시간)**, **미설명 필드의 임의 해석 금지**라는 세 가지 실무 원칙을 준수해야 한다.
