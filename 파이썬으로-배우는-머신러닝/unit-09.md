## 개념 설명: 비지도학습이란?

**비지도학습(Unsupervised Learning)**은 학습 데이터에 정답(Label)이 없는 상태에서 데이터의 내재된 구조나 패턴을 찾아내는 머신러닝 방식입니다.

### 지도학습 vs 비지도학습
- **지도학습:** 문제(Feature)와 정답(Label)을 함께 줍니다. "이 사진은 고양이야." $\rightarrow$ 모델은 고양이의 특징을 학습하여 새로운 사진이 왔을 때 고양이인지 맞춥니다.
- **비지도학습:** 문제(Feature)만 줍니다. "이 데이터들 사이에서 공통점을 찾아봐." $\rightarrow$ 모델은 데이터 간의 거리나 밀도를 분석해 비슷한 것들끼리 그룹핑합니다.

### 군집화(Clustering)
비지도학습의 가장 대표적인 작업이 바로 **군집화**입니다. 군집화는 데이터셋을 여러 개의 그룹(Cluster)으로 나누는 것인데, 같은 그룹에 속한 데이터들은 서로 유사하고, 다른 그룹에 속한 데이터들과는 이질적인 특성을 갖도록 만드는 것이 목표입니다.

---

## 기술 설명: K-Means 알고리즘

**K-Means(K-평균)**는 가장 직관적이고 널리 쓰이는 군집화 알고리즘입니다. 여기서 'K'는 우리가 나누고 싶은 그룹의 개수를 의미합니다.

### K-Means의 작동 원리 (4단계)
1. **중심점 설정:** 데이터 공간에 무작위로 $K$개의 중심점(Centroid)을 배치합니다.
2. **그룹 할당:** 모든 데이터 포인트에서 각 중심점까지의 거리를 계산하여, 가장 가까운 중심점이 속한 그룹으로 데이터를 할당합니다.
3. **중심점 업데이트:** 각 그룹에 속한 데이터들의 **정중앙 위치(평균 지점)를 계산하여, 그 위치로 중심점을 이동**시킵니다. 즉, 그룹의 대표값이 그룹의 한가운데에 오도록 조정하는 과정입니다.
4. **반복:** 중심점이 더 이상 변하지 않거나 설정한 반복 횟수에 도달할 때까지 2번과 3번 과정을 반복합니다.

### 최적의 $k$를 찾는 방법: 엘보우 방법(Elbow Method)
우리는 몇 개의 그룹으로 나누는 것이 최적인지 미리 알 수 없습니다. 이때 사용하는 것이 **엘보우 방법**입니다.
- **원리:** $k$ 값을 1부터 차례대로 늘려가며 **군집 내 오차 제곱합(SSE, Sum of Squared Errors)**을 측정합니다. (scikit-learn에서는 `inertia_` 속성으로 제공됩니다.)
- **판단:** $k$가 증가할수록 오차는 줄어들지만, 어느 지점부터는 오차가 줄어드는 속도가 급격히 느려집니다. 이때 그래프의 모양이 마치 **'팔꿈치(Elbow)'**처럼 꺾이는 지점이 나타나는데, 그 지점이 가장 효율적인 $k$ 값이라고 판단합니다.

## 파이썬 코드 실습

실제 데이터는 변수마다 단위(Scale)가 다르기 때문에, 거리 기반 알고리즘인 K-Means를 적용하기 전에는 반드시 **스케일링**을 거쳐야 합니다.

```python
import numpy as np
import matplotlib.pyplot as plt
from sklearn.cluster import KMeans
from sklearn.preprocessing import StandardScaler
from sklearn.datasets import make_blobs

# 1. 가상 데이터 생성 (연봉과 소비지수)
# 의도적으로 연봉(X축)과 소비지수(Y축)의 범위를 다르게 설정하여 스케일링의 필요성을 보여줍니다.
X, _ = make_blobs(n_samples=300, centers=4, cluster_std=1.0, random_state=42)
X[:, 0] = X[:, 0] * 100  # 연봉 데이터의 범위를 크게 확대 (단위 차이 발생)

# 2. 데이터 스케일링 (필수 과정)
# StandardScaler를 통해 모든 특성의 평균을 0, 분산을 1로 맞춥니다.
scaler = StandardScaler()
X_scaled = scaler.fit_transform(X)

# 3. 엘보우 방법을 통한 최적의 k 찾기
inertia = []
for k in range(1, 11):
    kmeans = KMeans(n_clusters=k, random_state=42, n_init='auto')
    kmeans.fit(X_scaled)
    inertia.append(kmeans.inertia_)

# 엘보우 그래프 시각화
plt.figure(figsize=(12, 5))
plt.subplot(1, 2, 1)
plt.plot(range(1, 11), inertia, marker='o')
plt.title("Elbow Method")
plt.xlabel("Number of clusters (k)")
plt.ylabel("Inertia")

# 4. 최적의 k(여기서는 4)로 최종 모델 학습 및 시각화
k_optimal = 4
kmeans_final = KMeans(n_clusters=k_optimal, random_state=42, n_init='auto')
labels = kmeans_final.fit_predict(X_scaled)
centroids = kmeans_final.cluster_centers_

plt.subplot(1, 2, 2)
plt.scatter(X_scaled[:, 0], X_scaled[:, 1], c=labels, s=30, cmap='viridis')
plt.scatter(centroids[:, 0], centroids[:, 1], c='red', s=200, marker='X', label='Centroids')
plt.title(f"K-Means Clustering (k={k_optimal})")
plt.xlabel("Scaled Annual Income")
plt.ylabel("Scaled Spending Score")
plt.legend()
plt.show()
```

### 실행 결과 해설
- **엘보우 그래프(왼쪽):** $k$가 1에서 4까지는 오차(Inertia)가 급격히 감소하다가, 4 이후부터는 감소 폭이 완만해집니다. 따라서 꺾이는 지점인 $k=4$가 최적의 군집 수임을 알 수 있습니다.
- **군집화 결과(오른쪽):** `StandardScaler`를 통해 연봉과 소비지수의 단위 차이를 제거했기 때문에, 어느 한 변수에 치우치지 않고 균형 있게 그룹이 나누어진 것을 볼 수 있습니다.
- **빨간색 X 표식:** 각 그룹의 정중앙 위치에 배치된 중심점입니다.

## 실무 활용 사례

비지도학습, 특히 군집화는 비즈니스 현장에서 매우 강력한 도구로 사용됩니다.

1. **고객 세분화(Customer Segmentation):** 모든 고객에게 동일한 마케팅을 하는 대신, 구매 패턴/방문 빈도/연령대 등을 분석해 'VIP 그룹', '잠재적 이탈 그룹', '가성비 추구 그룹' 등으로 나누어 맞춤형 프로모션을 진행합니다.
2. **이미지 압축:** 이미지의 수만 가지 색상 중 비슷한 색상끼리 묶어 대표색(중심점)으로 대체함으로써 이미지 용량을 줄입니다.
3. **이상치 탐지(Anomaly Detection):** 대부분의 데이터가 특정 군집에 모여 있는데, 어떤 데이터가 어떤 군집에도 속하지 않고 멀리 떨어져 있다면 이를 '이상치(예: 신용카드 부정 사용)'로 간주합니다.

## 자주 하는 실수

### 1. 데이터 스케일링(Scaling)을 생략하는 경우
K-Means는 **거리 기반** 알고리즘입니다. 만약 한 변수는 '연봉(단위: 만원, 범위 2000~8000)'이고 다른 변수는 '나이(단위: 세, 범위 20~60)'라면, 숫자가 훨씬 큰 연봉 변수가 거리 계산에 압도적인 영향을 미칩니다. 결과적으로 나이 정보는 무시되고 연봉으로만 그룹이 나뉘게 됩니다.
- **해결책:** 반드시 `StandardScaler`나 `MinMaxScaler`를 사용하여 모든 특성의 범위를 비슷하게 맞춰줘야 합니다.

### 2. $k$ 값을 임의로 정하는 경우
몇 개의 그룹으로 나누는 것이 최적인지 모르는 경우가 많습니다. $k$를 너무 작게 잡으면 서로 다른 특성이 섞이고, 너무 크게 잡으면 의미 없는 세분화가 일어납니다.
- **해결책:** 본문 실습에서 다룬 **엘보우 방법(Elbow Method)**을 사용하여 데이터 기반으로 최적의 $k$를 선택하세요.

## 핵심 요약

- **비지도학습**은 정답(Label) 없이 데이터의 패턴을 스스로 찾는 학습 방식이다.
- **군집화(Clustering)**는 유사한 특성을 가진 데이터들을 하나의 그룹으로 묶는 것이다.
- **K-Means**는 중심점을 잡고 $\rightarrow$ 할당하고 $\rightarrow$ 정중앙 위치로 업데이트하는 과정을 반복하여 최적의 그룹을 찾는다.
- 거리 기반 알고리즘이므로 **데이터 전처리(스케일링)**가 필수적이다.
- 최적의 군집 수 $k$를 찾기 위해 **엘보우 방법**을 활용하여 오차가 급격히 줄어드는 지점을 찾는다.

## 확인 문제

1. 지도학습과 비지도학습의 가장 결정적인 차이점은 무엇인가요?
2. K-Means 알고리즘에서 '중심점(Centroid)'이 업데이트되는 기준은 무엇인가요?
3. K-Means를 적용하기 전, 데이터의 단위(Scale)가 서로 다를 때 반드시 수행해야 하는 작업은 무엇이며, 그 이유는 무엇인가요?

**[정답 및 해설]**
1. **정답:** 학습 데이터에 정답(Label/Target)이 포함되어 있는지 여부입니다. 지도학습은 정답을 통해 학습하고, 비지도학습은 데이터 자체의 구조를 학습합니다.
2. **정답:** 해당 중심점에 할당된 모든 데이터 포인트들의 산술 평균 위치(정중앙 지점)로 업데이트됩니다.
3. **정답:** 데이터 스케일링(표준화 또는 정규화)입니다. K-Means는 거리 기반 알고리즘이므로, 변수 간 단위 차이가 크면 숫자가 큰 변수가 결과에 압도적인 영향을 주어 왜곡이 발생하기 때문입니다.
