## 실생활 비유: "공부 시간과 시험 점수의 상관관계"

여러분은 시험 전날, 친구들과 이런 이야기를 나눈 적이 있을 것입니다.
*"보통 1시간 공부할 때마다 5점 정도 오르는 것 같아. 내가 10시간을 공부하면 대략 50점 정도는 나오겠지?"*

여기서 여러분은 무의식중에 **'회귀 분석'**을 하고 있는 것입니다. 과거의 경험(데이터)을 바탕으로 **'공부 시간'**이라는 입력값이 변할 때 **'시험 점수'**라는 결과값이 어떻게 변하는지 그 규칙성을 찾아낸 것이죠. 

만약 여러분이 이 규칙을 그래프로 그린다면, 점들이 흩어져 있겠지만 그 중심을 가로지르는 하나의 '직선'을 그릴 수 있을 것입니다. 이 직선이 바로 머신러닝이 찾고자 하는 **'최적의 예측 모델'**입니다.

---

## 개념 설명: 회귀(Regression)란 무엇인가?

**회귀**란 쉽게 말해 **"연속적인 수치를 예측하는 것"**입니다. 

우리가 앞서 배운 '지도학습'은 크게 두 가지 갈래로 나뉩니다. 하나는 **분류(Classification)**이고, 다른 하나가 바로 **회귀(Regression)**입니다. 이 둘의 차이를 명확히 아는 것이 중요합니다.

- **분류 (Classification):** "이 사진은 고양이인가, 강아지인가?", "이 메일은 스팸인가, 정상인가?"처럼 **범주(Category)**를 맞추는 것입니다. 결과값이 'A 아니면 B'로 딱 떨어집니다.
- **회귀 (Regression):** "내일의 기온은 몇 도일까?", "이 아파트의 적정 가격은 얼마일까?", "다음 달 매출액은 얼마일까?"처럼 **연속적인 숫자(Continuous Value)**를 맞추는 것입니다.

즉, 정답이 '예/아니오'나 '종류'가 아니라 **'얼마나(How much)'**에 해당하는 수치라면 그것은 회귀 문제라고 할 수 있습니다.

## 기술 설명: 선형 회귀의 원리

### 1. 최적의 선을 찾는 방정식
선형 회귀(Linear Regression)는 데이터의 분포를 가장 잘 나타내는 하나의 직선을 찾는 것입니다. 중학교 수학 시간에 배운 일차함수 식을 떠올려 보세요.

$$y = ax + b$$

- **$x$ (독립변수):** 예측을 위해 사용하는 입력값 (예: 공부 시간)
- **$y$ (종속변수):** 우리가 예측하려는 결과값 (예: 시험 점수)
- **$a$ (기울기/Weight):** $x$가 변할 때 $y$가 얼마나 변하는지를 나타내는 가중치
- **$b$ (절편/Bias):** $x$가 0일 때의 기본값 (편향)

머신러닝 모델의 학습이란, 수많은 데이터들을 가장 잘 설명할 수 있는 **최적의 $a$와 $b$ 값을 찾아내는 과정**을 말합니다.

### 2. 손실 함수(Loss Function): "얼마나 틀렸는가?"
컴퓨터는 어떻게 '최적의 선'을 찾을까요? 바로 **'오차'**를 계산하기 때문입니다.

- **실제값:** 실제 데이터에 기록된 정답
- **예측값:** 모델이 직선($y = ax + b$)을 통해 계산한 값

이 **실제값과 예측값의 차이**를 **오차(Error)**라고 하며, 이 오차들의 합이나 평균을 계산하는 식을 **손실 함수(Loss Function)**라고 합니다. 모델은 이 손실 함수의 값이 최소가 되도록(즉, 오차가 가장 적어지도록) $a$와 $b$를 계속해서 수정합니다.

## 파이썬 코드 실습: Scikit-learn으로 회귀 모델 만들기

이제 실제로 파이썬의 `Scikit-learn` 라이브러리를 사용하여 집값 예측 모델을 만들어 보겠습니다. 집의 크기(평수)에 따라 가격이 결정된다는 단순한 가정을 세워보겠습니다.

> **💡 중요: 데이터 모양(Shape) 주의사항**
> Scikit-learn의 회귀 모델은 입력 데이터인 `X`를 **2차원 배열(행렬)** 형태로 기대합니다. 
> - **잘못된 형태:** `[10, 15, 20]` (1차원 리스트) $\rightarrow$ 모델이 "특성이 몇 개인지 모르겠다"며 에러를 냅니다.
> - **올바른 형태:** `[[10], [15], [20]]` (2차원 배열) $\rightarrow$ "데이터가 3개이고, 각 데이터당 특성이 1개구나"라고 인식합니다.
> 그래서 코드에서 `.reshape(-1, 1)`을 사용하여 1차원 데이터를 2차원으로 변환해 주는 것입니다.

```python
import numpy as np
import matplotlib.pyplot as plt
from sklearn.linear_model import LinearRegression

# 1. 데이터 준비 (X: 집 크기(평수), y: 집값(억 원))
# reshape(-1, 1)을 통해 1차원 배열을 2차원 배열로 변환합니다.
X = np.array([10, 15, 20, 25, 30, 35, 40]).reshape(-1, 1) 
y = np.array([2.1, 3.2, 4.1, 4.9, 6.1, 7.2, 8.1])

# 2. 모델 생성
model = LinearRegression()

# 3. 모델 학습 (fit 메서드 사용)
# 데이터 사이의 최적의 직선(기울기와 절편)을 찾는 과정입니다.
model.fit(X, y)

# 4. 새로운 데이터로 예측 (predict 메서드 사용)
# 예측할 때도 X 데이터는 2차원 형태([[값]])여야 합니다.
new_house_size = np.array([[28]])
predicted_price = model.predict(new_house_size)

print(f"28평 아파트의 예측 가격은 {predicted_price[0]:.2f}억 원입니다.")

# 5. 결과 시각화
plt.scatter(X, y, color='blue', label='Actual Data') # 실제 데이터 점
plt.plot(X, model.predict(X), color='red', label='Regression Line') # 학습된 예측 직선
plt.xlabel('House Size (pyeong)')
plt.ylabel('Price (100M KRW)')
plt.legend()
plt.show()
```

### 실행 결과 해설
- **`model.fit(X, y)`**: 이 메서드가 실행될 때 머신러닝 모델은 내부적으로 데이터를 훑으며 오차를 최소화하는 최적의 기울기($a$)와 절편($b$)을 계산합니다.
- **`model.predict([[28]])`**: 학습된 직선 방정식에 $x=28$을 대입하여 $y$값을 출력합니다.
- **그래프 결과**: 파란색 점들(실제 데이터) 사이를 붉은색 직선이 관통하는 것을 볼 수 있습니다. 이 직선이 바로 모델이 학습한 '데이터의 경향성'입니다.

## 모델의 성적표: 회귀 모델 평가 지표

모델이 예측값을 내놓았지만, 이 모델이 얼마나 믿을만한지 정량적으로 확인해야 합니다. 이때 사용하는 지표들이 있으며, 각각의 목적이 다릅니다.

1. **MAE (Mean Absolute Error, 평균 절대 오차):** 
   - 실제값과 예측값의 차이를 절대값으로 변환해 평균을 낸 것입니다.
   - **특징:** 오차의 크기가 그대로 반영되어 "평균적으로 약 $\text{X}$원 정도 틀린다"라고 가장 직관적으로 해석할 수 있습니다.
2. **MSE (Mean Squared Error, 평균 제곱 오차):** 
   - 오차를 제곱하여 평균을 낸 것입니다. 
   - **특징:** 오차가 클수록 제곱값이 기하급수적으로 커집니다. 따라서 **큰 오차(이상치)에 대해 매우 민감하게 반응**합니다. 모델이 가끔씩 아주 크게 틀리는 것을 방지하고 싶을 때 유용하게 감시하는 지표입니다.
3. **$R^2$ (R-squared, 결정계수):** 
   - 모델이 데이터의 분산을 얼마나 잘 설명하는지를 나타내며, 0에서 1 사이의 값을 가집니다.
   - **특징:** MAE나 MSE는 데이터의 단위(원, 달러 등)에 따라 값이 달라지지만, $R^2$는 상대적인 비율이므로 "이 모델이 전체적으로 얼마나 정확한가"를 판단하는 표준 척도가 됩니다.

### 💡 어떤 지표를 봐야 할까요?

| 지표 | 핵심 질문 | 추천 상황 |
| :--- | :--- | :--- |
| **MAE** | "평균적으로 얼마나 틀려?" | 일반적인 오차 수준을 직관적으로 알고 싶을 때 |
| **MSE** | "크게 틀린 데이터가 있어?" | 이상치(Outlier)에 민감하게 반응하여 모델을 튜닝할 때 |
| **$R^2$** | "모델이 데이터를 얼마나 잘 설명해?" | 모델의 전반적인 성능을 다른 모델과 비교하고 싶을 때 |

## 더 나은 예측을 향해: 단순 회귀에서 다중 회귀로

지금까지는 '집 크기'라는 **하나의 변수**만 사용했습니다. 이를 **단순 선형 회귀(Simple Linear Regression)**라고 합니다. 하지만 실제 집값은 크기만으로 결정되지 않습니다.

- 집의 연식 (Age)
- 역세권 여부 (Station Distance)
- 주변 학군 (School District)

이렇게 여러 개의 독립변수($x_1, x_2, x_3 \dots$)를 사용하는 것을 **다중 선형 회귀(Multiple Linear Regression)**라고 합니다.

- **단순 회귀:** $y = ax + b$
- **다중 회귀:** $y = a_1x_1 + a_2x_2 + a_3x_3 + \dots + b$

변수가 많아질수록 모델은 더 복잡한 현실을 반영할 수 있게 되어 예측력이 향상되는 경우가 많습니다. 하지만 여기서 주의해야 할 점이 바로 **'과적합(Overfitting)'**입니다.

> **⚠️ 과적합(Overfitting)이란?**
> 과적합은 마치 **교과서의 연습문제와 정답을 통째로 외워버린 학생**과 같습니다. 외운 문제는 완벽하게 맞히지만, 조금만 응용된 새로운 문제가 나오면 전혀 풀지 못하는 상태죠.
> 
> 머신러닝에서도 변수를 너무 많이 넣으면, 모델이 데이터의 일반적인 '경향'을 배우는 것이 아니라 개별 데이터의 '잡음(Noise)'까지 학습해 버립니다. 결과적으로 학습 데이터에 대해서는 완벽한 예측을 하지만, **실제 새로운 데이터(현실)에서는 예측력이 뚝 떨어지는 문제**가 발생합니다.

## 실무 활용 사례

회귀 모델은 산업 현장에서 매우 광범위하게 사용됩니다.
- **이커머스:** 과거 판매 데이터를 기반으로 다음 달 예상 매출액 예측 $\rightarrow$ 재고 물량 조절.
- **에너지:** 기온, 습도, 요일 데이터를 기반으로 전력 수요량 예측 $\rightarrow$ 발전소 가동률 조정.
- **마케팅:** 광고비 지출액에 따른 예상 신규 고객 유입 수 예측 $\rightarrow$ 광고 예산 최적화.

## 자주 하는 실수

**❌ "데이터가 직선 형태가 아닌데 선형 회귀를 사용하는 경우"**
- **문제:** 데이터가 곡선(예: 지수 함수 형태)으로 분포되어 있는데 억지로 직선을 그으면 오차가 매우 커집니다.
- **해결:** 데이터를 시각화하여 경향성을 먼저 파악하세요. 곡선 형태라면 '다항 회귀(Polynomial Regression)'나 다른 비선형 모델을 고려해야 합니다.

**❌ "단위가 너무 다른 변수들을 그대로 다중 회귀에 넣는 경우"**
- **문제:** 예를 들어 '방 개수(1~5개)'와 '연봉(수천만 원)'을 동시에 넣으면, 숫자가 큰 연봉 변수가 모델에 압도적인 영향을 줍니다.
- **해결:** 모든 변수의 범위를 일정하게 맞추는 **스케일링(Scaling)** 과정을 거쳐야 합니다.

## 핵심 요약
- **회귀**는 연속적인 수치 값을 예측하는 지도학습 기법이다.
- **선형 회귀**는 데이터의 경향성을 가장 잘 나타내는 최적의 직선($y=ax+b$)을 찾는 것이다.
- **손실 함수**를 통해 실제값과 예측값의 오차를 줄이는 방향으로 모델을 학습시킨다.
- **MAE(직관적 오차), MSE(큰 오차 민감), $R^2$(설명력)**를 통해 모델의 성능을 평가한다.
- 변수가 하나면 **단순 회귀**, 여러 개면 **다중 회귀**라고 하며, 변수가 너무 많으면 **과적합**이 발생할 수 있다.

## 미니 프로젝트: 우리 동네 카페 매출 예측하기

**상황:** 당신은 카페 사장님입니다. 일일 방문객 수와 매출액의 관계를 분석하여, 방문객이 100명일 때 매출이 얼마가 될지 예측하는 모델을 만들어 보세요.

**제공 데이터:**
- 방문객 수(X): `[20, 35, 50, 65, 80, 95]`
