# 3. NumPy와 Pandas

## 이번 장에서 배우는 내용

머신러닝 모델을 만드는 과정은 마치 요리를 하는 것과 같습니다. 좋은 재료(데이터)를 준비하고, 이를 다듬고 손질(전처리)해야 비로소 맛있는 요리(모델)가 완성됩니다. 이번 장에서는 파이썬의 기본 리스트만으로는 처리하기 힘든 방대한 양의 데이터를 효율적으로 다루기 위해, 머신러닝의 '기본 도구'인 **NumPy**와 **Pandas**를 배웁니다.

- **NumPy**: 수치 계산의 핵심인 다차원 배열(Array)을 다루는 방법
- **Pandas**: 표 형태의 데이터(DataFrame)를 자유자재로 가공하는 방법
- **데이터 전처리**: 머신러닝 모델에 넣기 전 데이터를 정제하는 기초 과정

---

## 실생활 비유: 엑셀 시트와 초고속 계산기

**NumPy**는 아주 성능이 좋은 **'초고속 계산기'**와 같습니다. 우리가 수학 시간에 배우는 행렬(Matrix) 기억하시나요? NumPy는 수만 개의 숫자가 들어있는 격자판을 통째로 더하거나 곱하는 일을 순식간에 해냅니다. 파이썬 리스트가 하나하나 숫자를 꺼내어 계산하는 '수작업'이라면, NumPy는 전체 데이터를 한 번에 처리하는 '자동화 공정'입니다.

**Pandas**는 **'프로그래밍으로 조작하는 엑셀'**이라고 생각하면 쉽습니다. 엑셀에서 행과 열을 나누어 데이터를 정리하고, 필터를 걸어 특정 조건의 데이터만 뽑아내거나, 피벗 테이블을 만들어 요약하는 작업을 파이썬 코드로 구현한 것입니다. 엑셀 파일(.csv, .xlsx)을 불러와서 원하는 대로 주무를 수 있게 해주는 강력한 도구입니다.

---

## 개념 설명: 왜 리스트 대신 NumPy와 Pandas인가요?

파이썬에는 이미 `list`라는 훌륭한 도구가 있습니다. 하지만 머신러닝에서는 수백만 개의 데이터를 다뤄야 합니다. 

1. **속도의 차이**: 파이썬 리스트는 다양한 타입의 데이터를 담을 수 있어 유연하지만, 그만큼 느립니다. 반면 NumPy 배열은 '모든 요소가 같은 타입'이라는 제약을 주는 대신, 컴퓨터 메모리를 효율적으로 사용하여 계산 속도를 비약적으로 높였습니다. 이를 **벡터화(Vectorization)**라고 합니다.
2. **편의성의 차이**: 리스트에서 특정 조건의 데이터를 찾거나 통계를 내려면 `for` 문을 돌려야 합니다. 하지만 Pandas를 사용하면 `df['나이'].mean()` 한 줄로 수만 명의 평균 나이를 구할 수 있습니다.

## 기술 설명

### 1. NumPy: 수치 계산의 기초
NumPy의 핵심은 `ndarray`(n-dimensional array)입니다.
- **차원(Dimension)**: 1차원은 벡터(Vector), 2차원은 행렬(Matrix), 3차원 이상은 텐서(Tensor)라고 부릅니다.
- **브로드캐스팅(Broadcasting)**: 서로 다른 모양의 배열끼리 연산할 때, NumPy가 자동으로 모양을 맞춰 연산을 수행하는 기능입니다. (예: 모든 행에 동일한 숫자 10을 더하는 작업)

### 2. Pandas: 데이터 분석의 핵심
Pandas는 크게 두 가지 자료구조를 사용합니다.
- **Series**: 1차원 배열 형태이며, 각 데이터에 '인덱스(이름)'가 붙어 있는 형태입니다.
- **DataFrame**: 2차원 표 형태입니다. 여러 개의 Series가 모여 하나의 표를 이룬다고 생각하면 됩니다. 엑셀의 시트 하나와 정확히 일치합니다.

## 파이썬 코드 실습

이제 직접 코드를 통해 NumPy와 Pandas의 위력을 확인해 보겠습니다.

```python
import numpy as np
import pandas as pd

# --- [NumPy 실습] ---
print("--- NumPy 결과 ---")
# 1. 배열 생성
data = [1, 2, 3, 4, 5]
np_arr = np.array(data)

# 2. 벡터화 연산 (리스트라면 for문을 써야 했지만, NumPy는 통째로 계산)
result = np_arr * 10 
print(f"원본 배열: {np_arr}")
print(f"10을 곱한 결과: {result}")

# 3. 기초 통계량 계산
print(f"평균: {np.mean(np_arr)}, 표준편차: {np.std(np_arr):.2f}")


# --- [Pandas 실습] ---
print("\n--- Pandas 결과 ---")
# 1. 데이터프레임 생성 (실무에서는 보통 pd.read_csv('file.csv')로 불러옵니다)
raw_data = {
    '이름': ['김철수', '이영희', '박민수', '최지우'],
    '나이': [25, 30, 22, 28],
    '점수': [85, 92, 78, 95],
    '지역': ['서울', '부산', '서울', '광주']
}
df = pd.DataFrame(raw_data)

# 2. 조건 필터링 (나이가 25세 초과인 사람만 추출)
over_25 = df[df['나이'] > 25]

# 3. 그룹화 및 집계 (지역별 평균 점수 계산)
region_mean = df.groupby('지역')['점수'].mean()

print("전체 데이터프레임:\n", df)
print("\n25세 초과 데이터:\n", over_25)
print("\n지역별 평균 점수:\n", region_mean)
```

### 실행 결과 해설
1. **NumPy 연산**: `np_arr * 10`을 했을 때, 파이썬 리스트였다면 리스트 자체가 10번 반복되었겠지만, NumPy 배열은 내부의 **모든 요소에 각각 10을 곱합니다.** 이것이 머신러닝에서 수많은 가중치를 한 번에 계산할 때 필수적인 기능입니다.
2. **Pandas 필터링**: `df[df['나이'] > 25]` 구문은 엑셀의 '필터' 기능과 같습니다. 조건에 맞는 행만 빠르게 골라냅니다.
3. **Pandas 그룹화**: `groupby`는 엑셀의 '피벗 테이블'과 같습니다. 특정 기준(지역)으로 데이터를 묶어 통계값(평균)을 내는 매우 강력한 기능입니다.

## 실무 활용 사례

- **NumPy**: 이미지 데이터 처리 시 사용합니다. 디지털 이미지는 사실 수많은 픽셀 값(0~255)이 담긴 3차원 배열(가로 $\times$ 세로 $\times$ RGB 채널)입니다. 이미지의 밝기를 조절하거나 필터를 적용하는 모든 과정이 NumPy의 배열 연산으로 이루어집니다.
- **Pandas**: 고객 로그 분석이나 매출 분석에 사용합니다. 수백만 건의 CSV 파일을 불러와 결측치(비어있는 값)를 채우고, 이상치를 제거하며, 분석에 필요한 특징(Feature)을 생성하는 '데이터 전처리' 단계에서 Pandas가 표준으로 사용됩니다.

## 자주 하는 실수

**1. 차원 불일치 오류 (Shape Mismatch)**
- **실수**: `(3, 2)` 모양의 배열과 `(3, 3)` 모양의 배열을 더하려고 할 때 발생합니다.
- **해결**: `.shape` 속성을 사용하여 두 배열의 크기가 맞는지 확인하세요. 머신러닝 모델에 데이터를 넣을 때 가장 많이 발생하는 오류입니다.

**2. 인덱스 혼동 (`loc` vs `iloc`)**
- **실수**: Pandas에서 데이터를 추출할 때 이름으로 찾을지, 순서(번호)로 찾을지 헷갈려 합니다.
- **해결**: 
    - `loc`: **L**abel 기반. 이름(예: '나이')으로 찾을 때 사용합니다.
    - `iloc`: **I**nteger 기반. 정수 인덱스(예: 0번째 행)로 찾을 때 사용합니다.

## 핵심 요약
- **NumPy**는 다차원 배열을 다루는 라이브러리로, 수치 계산 속도가 매우 빠릅니다.
- **Pandas**는 DataFrame이라는 표 형태의 구조를 사용하여 데이터 분석과 전처리를 쉽게 해줍니다.
- 머신러닝의 데이터는 결국 **[Pandas로 정제 $\rightarrow$ NumPy 배열로 변환 $\rightarrow$ 모델 학습]**의 과정을 거치게 됩니다.

## 정답 및 해설
1. **정답**: `array * 2` (브로드캐스팅 기능을 이용해 요소별 연산을 수행합니다.)
