# 제3장. NumPy와 Pandas: 머신러닝의 기초 체력, 데이터 핸들링

머신러닝 모델은 화려한 알고리즘으로 작동하는 것처럼 보이지만, 그 본질은 **'거대한 숫자 계산'**입니다. 모델에게 데이터를 입력한다는 것은 결국 수많은 숫자가 적힌 거대한 표를 전달하는 과정입니다. 파이썬의 기본 리스트만으로는 처리하기 힘든 대량의 수치 계산을 해결해 줄 **NumPy**와, 엑셀처럼 데이터를 체계적으로 관리하고 분석하게 해 줄 **Pandas**를 학습합니다.

## 1. 학습 목표
* **NumPy**: 다차원 배열(`ndarray`)의 개념과 벡터 연산(Vectorization)의 원리
* **Pandas**: 시리즈(`Series`)와 데이터프레임(`DataFrame`)의 구조 및 조작법
* **데이터 처리**: 데이터 슬라이싱, 필터링, 기본 통계량 확인 방법
* **실무 팁**: 파이썬 리스트와 NumPy 배열의 차이점, Pandas의 효율적인 인덱싱

## 2. NumPy: 고속 수치 계산의 핵심

### [비유] 바둑판처럼 정렬된 숫자판
파이썬의 기본 리스트가 '아무 물건이나 담을 수 있는 커다란 장바구니'라면, **NumPy 배열은 '정해진 칸에 숫자만 딱딱 맞춰 담은 바둑판'**과 같습니다. 장바구니에서 물건을 하나하나 꺼내 확인하는 것보다, 바둑판의 특정 행과 열을 한꺼번에 밀어버리는 것이 훨씬 빠릅니다.

### [직관] "하나씩 하지 말고, 한꺼번에 처리하자"
우리가 100명의 점수에 각각 5점씩 더해야 한다면, 보통은 100번의 반복문(for문)을 생각합니다. 하지만 NumPy의 직관은 다릅니다. "점수 리스트 전체에 5를 더해!"라고 명령하면, NumPy는 내부적으로 모든 요소를 동시에 계산합니다. 이를 통해 코드의 길이는 짧아지고 계산 속도는 비약적으로 상승합니다.

### [기술 설명] 벡터화(Vectorization)와 ndarray
NumPy의 핵심 객체는 `ndarray`(n-dimensional array)입니다. 파이썬 리스트는 다양한 타입의 데이터를 담을 수 있어 유연하지만, 연산 시마다 타입을 확인해야 하므로 느립니다. 반면 `ndarray`는 **모든 요소가 동일한 타입**이며 메모리에 연속적으로 배치되어 있습니다.

**벡터화(Vectorization)**란 명시적인 for 루프 없이 배열 전체에 연산을 적용하는 기술입니다. 이는 내부적으로 C언어로 구현되어 있으며, CPU의 **SIMD(Single Instruction, Multiple Data)** 기능을 활용하여 하나의 명령어로 여러 데이터를 동시에 처리합니다.

## 3. Pandas: 데이터 분석의 표준 도구

### [비유] 프로그래밍으로 제어하는 엑셀 시트
**Pandas는 '파이썬으로 구현한 엑셀'**입니다. NumPy가 숫자 계산에 특화된 '고성능 계산기'라면, Pandas는 데이터에 이름(컬럼명)을 붙이고, 필터를 걸고, 정렬하는 '데이터 관리 대장'입니다. 엑셀에서 마우스로 클릭해서 수행하던 모든 작업을 코드로 정확하고 빠르게 수행할 수 있게 해줍니다.

### [직관] "숫자에 의미(라벨)를 부여하자"
NumPy 배열만으로는 `[25, 100, 30]`이라는 데이터가 '나이, 지출액, 나이'인지 '키, 몸무게, 나이'인지 알 수 없습니다. Pandas는 여기에 'Age', 'Spend', 'Score'라는 이름을 붙여 데이터에 의미를 부여합니다. 덕분에 우리는 인덱스 번호가 아닌 '이름'으로 데이터를 찾고 관리할 수 있습니다.

### [기술 설명] DataFrame과 Series
Pandas는 크게 두 가지 구조를 가집니다.
- **Series**: 1차원 배열 형태의 데이터 구조로, 인덱스(Index)와 값(Value)이 일대일 대응됩니다. (엑셀의 '열' 하나)
- **DataFrame**: 여러 개의 Series가 모인 2차원 표 형태의 구조입니다. 행(Row)과 열(Column)로 구성되며, 각 열은 서로 다른 데이터 타입(정수, 실수, 문자열 등)을 가질 수 있습니다.

**인덱싱 원리**:
- `loc`: **라벨(Label)** 기반 인덱싱. 컬럼명이나 행의 이름으로 접근합니다.
- `iloc`: **정수 위치(Integer-location)** 기반 인덱싱. 0부터 시작하는 순서로 접근합니다.

## 4. 파이썬 코드 실습

```python
import numpy as np
import pandas as pd

# --- [NumPy 실습: 벡터화 연산] ---
print("--- NumPy Section ---")
# 1. 배열 생성
data = [1, 2, 3, 4, 5]
np_arr = np.array(data)
print(f"원본 배열: {np_arr}")

# 2. 벡터 연산: for문 없이 모든 요소에 10을 더함
result = np_arr + 10 
print(f"벡터 연산 결과 (all + 10): {result}")

# 3. 2차원 행렬 생성 및 모양 확인
matrix = np.array([[1, 2, 3], [4, 5, 6]])
print(f"행렬 모양(shape): {matrix.shape}") # (행, 열)


# --- [Pandas 실습: 데이터 핸들링] ---
print("\n--- Pandas Section ---")
# 1. 데이터프레임 생성 (가상의 고객 데이터)
raw_data = {
    'Name': ['Alice', 'Bob', 'Charlie', 'David'],
    'Age': [25, 30, 35, 40],
    'Spend': [100, 200, 150, 300],
    'City': ['Seoul', 'Busan', 'Seoul', 'Incheon']
}
df = pd.DataFrame(raw_data)
print("전체 데이터프레임:\n", df)

# 2. 특정 조건 필터링 (나이가 30세 이상이고 서울에 사는 사람)
# 불리언 인덱싱(Boolean Indexing) 활용
filtered_df = df[(df['Age'] >= 30) & (df['City'] == 'Seoul')]
print("\n필터링 결과 (Age >= 30 & City == 'Seoul'):\n", filtered_df)

# 3. 요약 통계량 확인
print("\n기본 통계 정보:\n", df.describe())
```

### [결과 해석]
1. **NumPy 벡터 연산**: `np_arr + 10` 한 줄로 모든 요소에 연산이 적용되었습니다. 이는 머신러닝 모델이 수백만 개의 가중치(Weight)를 한 번에 업데이트하는 핵심 원리입니다.
2. **`matrix.shape`**: `(2, 3)`은 2행 3열을 의미합니다. 모델에 데이터를 넣기 전, 입력 차원(Input Dimension)이 맞는지 확인하는 필수 단계입니다.
3. **Pandas 필터링**: `df[...]` 내부에 조건을 넣으면 `True`인 행만 추출됩니다. 이는 SQL의 `WHERE` 절과 동일한 논리입니다.
4. **`df.describe()`**: 평균, 표준편차, 사분위수 등을 한 번에 제공합니다. 데이터의 전반적인 분포를 파악하는 EDA(탐색적 데이터 분석)의 시작점입니다.

## 5. 실무 활용 사례: "수백만 건의 고객 로그 분석"

실무에서 100만 줄이 넘는 고객 데이터를 엑셀로 열면 프로그램이 멈추거나 매우 느려집니다. 하지만 Pandas를 사용하면 다음과 같은 작업을 단 몇 초 만에 처리할 수 있습니다.

*   **결측치 처리**: `df['Spend'].fillna(df['Spend'].mean())` 코드로 구매 금액이 비어있는 고객의 데이터를 평균값으로 빠르게 채울 수 있습니다.
*   **그룹화 분석**: `df.groupby('City')['Spend'].mean()`을 통해 도시별 평균 지출액을 계산하여 지역별 마케팅 전략을 세울 수 있습니다.
*   **데이터 변환**: `np.log1p(df['Spend'])`를 사용하여 지출 금액의 극단적인 값(Outlier)이 주는 영향을 줄이는 로그 변환을 수행합니다.

## 6. 자주 하는 실수: `SettingWithCopyWarning`

초보자가 가장 많이 겪는 경고 중 하나입니다. 데이터를 추출한 뒤 값을 수정할 때 발생합니다.

```python
# ⚠️ 잘못된 예시: 체이닝(Chaining) 발생
subset = df[df['Age'] > 30] 
subset['Spend'] = 0  # 여기서 SettingWithCopyWarning 발생!
```
**이유**: `subset`이 원본 `df`의 일부를 가리키는 '뷰(View)'인지, 완전히 새로운 '복사본(Copy)'인지 Pandas가 확신할 수 없기 때문입니다.

**해결 방법**: `.loc`를 사용해 직접 접근하거나, `.copy()`를 통해 명시적으로 복사본을 만듭니다.
```python
# ✅ 올바른 예시 1: .loc 사용 (원본을 직접 수정)
df.loc[df['Age'] > 30, 'Spend'] = 0

# ✅ 올바른 예시 2: .copy() 사용 (새로운 객체 생성)
subset = df[df['Age'] > 30].copy()
subset['Spend'] = 0
```

## 9. 정답 및 해설

**A1.** 가장 결정적인 차이는 **메모리 배치와 타입의 일관성**입니다. 리스트는 요소마다 타입이 다를 수 있고 메모리에 흩어져 있지만, NumPy 배열은 동일한 타입의 데이터가 메모리에 연속적으로 배치되어 있습니다. 따라서 **벡터화 연산**이 가능해져 연산 속도가 비약적으로 빠르기 때문에 대규모 행렬 계산이 필수적인 머신러닝에서 사용합니다.

**A2.** `loc`는 **라벨(Label)** 기반 인덱싱으로, 컬럼명이나 행의 이름으로 접근합니다. 반면 `iloc`는 **정수 위치(Integer-location)** 기반 인덱싱으로, 0부터 시작하는 순서(인덱스 번호)로 접근합니다.

**A3.** 행이 100개, 열이 5개이므로 **100개의 샘플(Sample)**과 **5개의 특성(Feature)**을 가지고 있습니다.
