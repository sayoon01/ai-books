# 4. 데이터 시각화

## 이번 장에서 배우는 내용

데이터는 숫자의 집합으로 이루어져 있지만, 인간의 뇌는 숫자보다 이미지에 훨씬 빠르게 반응합니다. 이번 장에서는 수만 개의 행과 열로 이루어진 복잡한 데이터를 한눈에 파악할 수 있게 해주는 **데이터 시각화(Data Visualization)**를 배웁니다. 

파이썬의 시각화 표준 라이브러리인 `Matplotlib`과 이를 기반으로 더 쉽고 아름다운 그래프를 그려주는 `Seaborn`의 사용법을 익히고, 실제 머신러닝 모델을 만들기 전 데이터의 특징을 파악하는 **탐색적 데이터 분석(EDA, Exploratory Data Analysis)** 과정을 경험해 보겠습니다.

---

## 실생활 비유: 지도와 좌표 목록

여러분이 낯선 도시의 맛집 100곳을 방문하려고 한다고 가정해 봅시다. 이때 두 가지 형태의 정보를 얻을 수 있습니다.

1. **좌표 목록:** `(37.5665, 126.9780), (37.5650, 126.9770), ...` 처럼 위도와 경도가 적힌 엑셀 파일
2. **지도:** 좌표들이 점으로 찍혀 있고, 맛집들이 어디에 몰려 있는지 한눈에 보이는 지도

**[그림 4-1: 텍스트로 된 위도/경도 리스트와 이를 점으로 찍어 만든 지도를 대비시켜, 시각화가 어떻게 복잡한 수치를 직관적인 정보로 바꾸는지 보여주는 도식]**

좌표 목록만 보고는 "아, 강남역 근처에 맛집이 많이 모여 있구나!"라고 판단하기 어렵습니다. 하지만 지도를 보는 순간, 데이터 속에 숨겨진 **'패턴(Pattern)'**과 **'군집(Cluster)'**이 즉각적으로 보입니다.

머신러닝에서의 데이터 시각화는 바로 이 **'지도'를 그리는 작업**입니다. 수치로만 되어 있는 데이터를 그림으로 바꾸어, 어떤 데이터가 이상한지(이상치), 변수들 사이에 어떤 관계가 있는지(상관관계)를 직관적으로 파악하는 것입니다.

## 개념 설명: 왜 시각화가 머신러닝의 시작일까?

머신러닝 모델에 데이터를 무작정 집어넣는 것을 'Black Box' 방식이라고 합니다. 하지만 좋은 모델을 만들려면 데이터가 어떻게 생겼는지 먼저 이해해야 합니다. 이를 **탐색적 데이터 분석(EDA)**이라고 합니다.

시각화를 통해 우리는 다음과 같은 질문에 답할 수 있습니다.
- **데이터의 분포:** 데이터가 한곳에 몰려 있는가, 아니면 고르게 퍼져 있는가?
- **상관관계:** A라는 값이 커질 때 B라는 값도 같이 커지는가?
- **이상치(Outlier):** 다른 데이터들과 너무 동떨어져 있는 '튀는' 값은 없는가?

**중요한 점은 여기서 발견한 인사이트가 곧바로 '데이터 전처리'와 '특성 공학(Feature Engineering)'의 근거가 된다는 것입니다.** 
예를 들어, 산점도를 그려봤는데 혼자 멀리 떨어진 점(이상치)이 있다면 이를 제거하여 모델의 왜곡을 막을 수 있습니다. 또한, 히트맵을 통해 타겟 변수(예: 집값)와 상관관계가 거의 없는 변수를 찾아내어 학습에서 제외함으로써 모델을 더 가볍고 효율적으로 만들 수 있습니다. 즉, 시각화는 "어떤 데이터를 살리고 어떤 데이터를 버릴지" 결정하는 전략 회의와 같습니다.

## 기술 설명: Matplotlib과 Seaborn

파이썬에는 다양한 시각화 도구가 있지만, 가장 핵심적인 두 가지는 다음과 같습니다.

### 1. Matplotlib: 시각화의 기초 체력
`Matplotlib`은 파이썬의 가장 기본적인 시각화 라이브러리입니다. 마치 도화지와 붓처럼, 그래프의 모든 세부 요소(축 이름, 색상, 선 굵기 등)를 세밀하게 조정할 수 있습니다. 다만, 코드가 다소 길고 디자인이 투박하다는 단점이 있습니다.

### 2. Seaborn: 쉽고 아름다운 통계 그래프
`Seaborn`은 `Matplotlib`을 기반으로 만들어진 상위 라이브러리입니다. 복잡한 설정 없이 한두 줄의 코드로 세련된 그래프를 그릴 수 있으며, 특히 Pandas의 DataFrame과 매우 잘 연동됩니다. 통계적인 분석(분포, 상관관계 등)에 특화되어 있어 머신러닝 입문자에게 필수적입니다.

**[그림 4-2: 산점도(두 변수의 관계), 히스토그램(단일 변수의 분포), 박스 플롯(사분위수와 이상치)의 형태적 차이와 각각 언제 사용하는지를 정리한 비교표]**

**[주요 그래프 종류]**
- **선 그래프(Line Plot):** 시간의 흐름에 따른 변화를 볼 때 사용 (예: 주가 변동)
- **산점도(Scatter Plot):** 두 변수 간의 관계를 점으로 표현 (예: 공부 시간과 성적의 관계)
- **히스토그램(Histogram):** 데이터의 빈도수와 분포를 확인할 때 사용 (예: 연령대별 인구 분포)
- **박스 플롯(Box Plot):** 데이터의 중앙값, 사분위수, 이상치를 한눈에 볼 때 사용
- **히트맵(Heatmap):** 변수 간의 상관계수를 색상으로 표현

## 파이썬 코드 실습

이제 직접 데이터를 만들어 시각화해 보겠습니다. '공부 시간', '집중도', '시험 점수'라는 가상의 데이터를 활용해 보겠습니다.

```python
import pandas as pd
import matplotlib.pyplot as plt
import seaborn as sns
import numpy as np

# 1. 가상 데이터 생성
np.random.seed(42)
n_samples = 100
study_hours = np.random.uniform(1, 10, n_samples) 
focus_level = np.random.uniform(1, 10, n_samples)
# 공부 시간과 집중도가 높을수록 점수가 오르도록 설정
test_scores = (study_hours * 5) + (focus_level * 3) + np.random.normal(0, 5, n_samples) + 20 

df = pd.DataFrame({'Study_Hours': study_hours, 'Focus_Level': focus_level, 'Test_Scores': test_scores})

# 이상치 강제 삽입 (데이터 분석의 재미를 위해)
df.loc[0, 'Test_Scores'] = 10 # 공부를 많이 했지만 점수가 매우 낮은 케이스
df.loc[1, 'Test_Scores'] = 150 # 말도 안 되게 높은 점수 케이스

# 한글 폰트 설정 (환경에 따라 설정이 필요할 수 있습니다)
plt.rc('font', family='NanumGothic') 

# 시각화 설정 (2x2 배열)
plt.figure(figsize=(14, 10))

# --- 그래프 1: 산점도 (Scatter Plot) ---
plt.subplot(2, 2, 1)
sns.scatterplot(x='Study_Hours', y='Test_Scores', data=df, color='blue')
plt.title('공부 시간과 시험 점수의 관계')
plt.xlabel('공부 시간 (h)')
plt.ylabel('시험 점수')

# --- 그래프 2: 히스토그램 (Histogram) ---
plt.subplot(2, 2, 2)
sns.histplot(df['Test_Scores'], kde=True, color='green')
plt.title('시험 점수 분포')
plt.xlabel('점수')
plt.ylabel('빈도수')

# --- 그래프 3: 박스 플롯 (Box Plot) ---
plt.subplot(2, 2, 3)
sns.boxplot(x=df['Test_Scores'], color='orange')
plt.title('시험 점수 이상치 확인')
plt.xlabel('점수')

# --- 그래프 4: 히트맵 (Heatmap) ---
plt.subplot(2, 2, 4)
sns.heatmap(df.corr(), annot=True, cmap='coolwarm', fmt=".2f")
plt.title('변수 간 상관계수 히트맵')

plt.tight_layout()
plt.show()
```

### 실행 결과 해설

1. **산점도(Scatter Plot):**
   - 점들이 우상향하는 패턴을 보입니다. 이는 **'양의 상관관계'**가 있음을 뜻합니다.
   - 특히, Y축의 아주 낮은 곳이나 아주 높은 곳에 홀로 떨어진 점들이 보일 것입니다. 이것이 바로 **이상치(Outlier)**입니다.

2. **히스토그램(Histogram):**
   - 점수들이 어디에 가장 많이 분포하는지 보여줍니다. `kde=True` 곡선을 통해 전반적인 데이터의 흐름(분포)을 파악할 수 있습니다.

3. **박스 플롯(Box Plot):**
   - 상자(Box)는 데이터의 중앙 50%가 모여 있는 구간을 나타냅니다.
   - 상자 밖으로 뻗어 나간 선(Whisker) 너머에 찍힌 점들이 바로 **이상치**입니다. "이 데이터들은 일반적인 경향에서 크게 벗어났으니, 모델 학습 전 제거하거나 수정해야겠다"라는 판단을 내릴 수 있게 합니다.

4. **히트맵(Heatmap):**
   - 숫자가 1에 가까울수록 강한 양의 상관관계를, -1에 가까울수록 강한 음의 상관관계를 의미합니다.
   - 'Study_Hours'와 'Test_Scores' 사이의 숫자가 높다면, 공부 시간이 점수를 예측하는 데 매우 중요한 **특성(Feature)**이 된다는 것을 알 수 있습니다.

## 실무 활용 사례

실무에서 데이터 시각화는 다음과 같이 활용됩니다.

- **이커머스 기업:** 고객의 '방문 횟수'와 '구매 금액'을 산점도로 그려, 우수 고객군(VVIP)이 어디에 형성되어 있는지 분석하고 타겟 마케팅 전략을 세웁니다.
- **제조 공장:** 센서 데이터의 히스토그램과 박스 플롯을 통해 평소와 다른 수치(이상치)가 나타나는지 감시하여 기기 고장을 사전에 예측합니다.
- **금융권:** 여러 경제 지표(금리, 환율, 물가) 간의 상관관계를 히트맵으로 그려, 어떤 지표가 주가에 가장 큰 영향을 주는지 파악하여 예측 모델의 입력 변수를 선택합니다.

## 자주 하는 실수

1. **축 이름(Label) 생략:** 그래프만 그려놓고 X축과 Y축이 무엇을 의미하는지 적지 않는 경우가 많습니다. 시각화의 목적은 '소통'입니다. 반드시 `plt.xlabel()`, `plt.ylabel()`을 사용하세요.
2. **너무 많은 색상 사용:** 한 그래프에 너무 많은 색상을 쓰면 오히려 가독성이 떨어집니다. 강조하고 싶은 부분에만 색을 쓰고 나머지는 무채색 계열을 사용하는 것이 좋습니다.
3. **스케일 무시:** Y축의 시작점이 0이 아니거나, 서로 다른 두 그래프의 축 범위가 다를 때 왜곡된 해석을 내릴 수 있습니다. 항상 축의 범위를 확인하세요.

## 핵심 요약

- **데이터 시각화**는 숫자로 된 데이터를 그림으로 바꾸어 패턴과 이상치를 찾는 과정이다.
- **EDA(탐색적 데이터 분석)**는 모델 학습 전 데이터를 이해하고, 전처리 방향(이상치 제거, 변수 선택 등)을 결정하는 필수 단계이다.
- **Matplotlib**은 세밀한 조정이 가능한 기초 도구이며, **Seaborn**은 쉽고 아름다운 통계 그래프 도구이다.
- **산점도**는 관계를, **히스토그램**은 분포를, **박스 플롯**은 이상치를, **히트맵**은 변수 간 상관관계를 확인하는 데 유용하다.

## 정답 및 해설

1. **정답: 산점도(Scatter Plot)**
   - 해설: 두 변수의 값을 각각 X축과 Y축에 점으로 표시하여, 한 변수가 변할 때 다른 변수가 어떻게 변하는지(추세)를 가장 잘 보여줍니다.
2. **정답: 사용법이 더 간단하고, Pandas 데이터프레임과 잘 연동되며, 기본 디자인이 더 세련되었다.**
   - 해설: Matplotlib으로 수십 줄 써야 할 코드를 Seaborn은 한두 줄로 구현할 수 있게 해줍니다.
3. **정답: 히스토그램(Histogram)**
   - 해설: 특정 구간(Bin)에 데이터가 몇 개나 포함되어 있는지를 막대 형태로 보여주어 분포를 파악하기 좋습니다.
4. **정답: 이상치(Outlier)**
   - 해설: 일반적인 데이터의 범위(사분위수 범위)를 크게 벗어난 값들을 의미하며, 분석 시 제거하거나 특별 관리해야 할 대상입니다.
