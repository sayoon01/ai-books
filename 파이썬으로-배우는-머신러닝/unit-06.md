# 6. 지도학습

## 이번 장에서 배우는 내용

이번 장에서는 머신러닝의 가장 대표적인 방법론인 **지도학습(Supervised Learning)**에 대해 배웁니다. 정답이 주어진 데이터를 통해 컴퓨터를 학습시키는 원리를 이해하고, 지도학습의 두 가지 큰 줄기인 '회귀'와 '분류'의 차이점을 파악합니다. 마지막으로 파이썬의 `scikit-learn` 라이브러리를 이용해 간단한 예측 모델을 직접 만들어 보겠습니다.

---

## 실생활 비유: 문제집과 정답지

여러분은 학창 시절, 수학 문제집을 풀며 공부했던 기억이 있을 것입니다. 문제집에는 **'문제'**가 있고, 책 뒷면에는 그 문제에 대한 **'정답'**이 적혀 있습니다.

우리는 먼저 문제를 풀고, 내가 낸 답이 정답지와 일치하는지 확인합니다. 만약 틀렸다면 "왜 틀렸지?"라고 고민하며 정답에 다가가기 위한 논리를 수정합니다. 이 과정을 수백 번 반복하다 보면, 나중에는 정답지가 없어도 새로운 문제를 보았을 때 정답을 맞힐 수 있는 '능력'이 생깁니다.

지도학습은 바로 이 과정과 똑같습니다. 컴퓨터에게 **'문제(데이터)'**와 **'정답(레이블)'**을 함께 주고, 컴퓨터가 스스로 문제와 정답 사이의 규칙을 찾아내게 만드는 학습 방법입니다.

---

## 개념 설명: 정답이 있는 학습

머신러닝에서 지도학습이란 **레이블(Label)**이 포함된 데이터셋을 사용하여 모델을 학습시키는 방식입니다.

여기서 **레이블**이란 우리가 예측하고자 하는 '정답'을 의미합니다. 예를 들어, 집값 예측 모델을 만든다면 '집의 크기, 위치, 연식'은 문제(특성, Feature)가 되고, 실제 '매매 가격'은 정답(레이블, Label)이 됩니다.

**지도학습의 흐름:**
1. **데이터 준비:** 문제(X)와 정답(y)이 짝지어진 데이터를 수집합니다.
2. **학습(Training):** 모델이 $\text{문제} \rightarrow \text{정답}$으로 가는 규칙(함수)을 찾습니다.
3. **예측(Prediction):** 학습이 끝난 모델에 정답이 없는 새로운 문제를 입력하여 결과를 예측합니다.

---

## 기술 설명: 회귀(Regression)와 분류(Classification)

지도학습은 정답의 형태에 따라 크게 **회귀**와 **분류** 두 가지로 나뉩니다.

### 1. 회귀 (Regression)
정답이 **연속적인 숫자**일 때 사용합니다. "얼마나(How much)?"에 대한 답을 찾는 과정입니다.
- **특징:** 출력값이 수치형입니다.
- **예시:** 내일의 기온 예측, 주식 가격 예측, 아파트 시세 예측.

### 2. 분류 (Classification)
정답이 **특정 카테고리(범주)**일 때 사용합니다. "어떤 것(Which one)?"에 대한 답을 찾는 과정입니다.
- **특징:** 출력값이 이산적인 클래스(Yes/No, A/B/C)입니다.
- **예시:** 스팸 메일 여부 판별(스팸/정상), 필기체 숫자 인식(0~9), 암 진단(양성/음성).

| 구분 | 회귀 (Regression) | 분류 (Classification) |
| :--- | :--- | :--- |
| **정답 형태** | 연속적인 숫자 (Continuous) | 이산적인 범주 (Discrete) |
| **목표** | 수치 예측 | 그룹 판별 |
| **결과 예시** | 75.5kg, 1억 2천만 원 | '고양이', '스팸 메일' |

---

## 파이썬 코드 실습: 공부 시간에 따른 성적 예측하기

가장 직관적인 지도학습인 '선형 회귀'를 이용해 공부 시간에 따라 시험 점수가 어떻게 변하는지 예측하는 모델을 만들어 보겠습니다.

```python
import numpy as np
from sklearn.linear_model import LinearRegression
import matplotlib.pyplot as plt

# 1. 데이터 준비 (문제 X, 정답 y)
# X: 공부 시간 (특성) - 2차원 배열 형태여야 하므로 reshape 사용
X = np.array([1, 2, 3, 4, 5]).reshape(-1, 1) 
# y: 시험 점수 (레이블)
y = np.array([40, 55, 70, 85, 100])

# 2. 모델 생성 및 학습
# LinearRegression: 선형 회귀 모델
model = LinearRegression()
model.fit(X, y) # fit 메서드가 '학습'을 수행합니다.

# 3. 새로운 데이터로 예측
# 6시간 공부했을 때의 점수는 몇 점일까?
hours_new = np.array([[6]])
prediction = model.predict(hours_new)

print(f"6시간 공부했을 때 예상 점수: {prediction[0]:.2f}점")

# 4. 시각화
plt.scatter(X, y, color='blue', label='Actual Data') # 실제 데이터
plt.plot(X, model.predict(X), color='red', label='Regression Line') # 예측 직선
plt.xlabel('Hours of Study')
plt.ylabel('Score')
plt.legend()
plt.show()
```

### 실행 결과 해설
- **`model.fit(X, y)`**: 컴퓨터가 $X$(시간)와 $y$(점수) 사이의 관계를 분석하여 "1시간 공부할 때마다 점수가 약 15점씩 오르는구나!"라는 규칙(기울기)을 찾아내는 과정입니다.
- **`model.predict([[6]])`**: 찾아낸 규칙에 6시간을 대입하여 결과를 도출합니다. 실행 결과는 `115.00점` 혹은 데이터 경향에 따른 수치로 출력됩니다. (실제 데이터가 선형적이기 때문에 정확한 직선상의 값이 나옵니다.)
- **그래프**: 파란 점(실제 데이터)들을 가장 잘 설명하는 빨간 직선(모델)이 그려진 것을 확인할 수 있습니다.

## 실무 활용 사례

지도학습은 현재 산업 현장에서 가장 활발하게 사용되는 머신러닝 방식입니다.

- **금융권 (회귀):** 고객의 신용 점수, 소득, 소비 패턴을 분석하여 대출 한도 금액을 예측합니다.
- **이커머스 (분류):** 사용자의 구매 이력을 바탕으로 이 고객이 특정 상품을 '구매할 것인가(Yes)' 아니면 '구매하지 않을 것인가(No)'를 분류하여 타겟 광고를 보냅니다.
- **의료분야 (분류):** MRI 영상을 분석하여 종양이 '악성'인지 '양성'인지 판별합니다.

---

## 자주 하는 실수

**❌ 과적합(Overfitting)의 함정**
입문자들이 가장 많이 하는 실수는 모델을 **'너무 많이'** 학습시키는 것입니다. 
비유하자면, 문제집의 원리를 이해하는 것이 아니라 **문제와 정답을 통째로 외워버린 상태**입니다. 이 경우 학습 데이터(기존 문제집)에서는 100점을 맞지만, 새로운 문제(실전 시험)를 주면 전혀 풀지 못하는 현상이 발생합니다.

**✅ 해결 방법:**
- 학습 데이터의 양을 늘립니다.
- 모델의 복잡도를 낮춥니다.
- 데이터를 학습용(Training)과 검증용(Test)으로 나누어, 학습에 사용하지 않은 데이터로 모델의 성능을 확인합니다.

---

## 핵심 요약
- **지도학습**은 정답(레이블)이 있는 데이터를 통해 학습하는 방법이다.
- **특성(Feature)**은 문제에 해당하며, **레이블(Label)**은 정답에 해당한다.
- 정답이 연속적인 숫자면 **회귀(Regression)**, 정답이 범주형이면 **분류(Classification)**라고 한다.
- `scikit-learn`의 `fit()`은 학습을, `predict()`는 예측을 수행한다.
