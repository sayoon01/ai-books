## 실생활 비유: 친구에게 영화를 추천받는 두 가지 방법

우리가 친구에게 "볼만한 영화 좀 추천해 줘"라고 말할 때, 친구는 보통 두 가지 방식으로 대답합니다.

**첫 번째 방법: "너 저번에 '어벤져스' 재밌게 봤잖아. 이것도 마블 영화인데 비슷해!"**
이것은 영화의 **'특성(장르, 감독, 배우 등)'**에 집중하는 방식입니다. 당신이 좋아하는 요소가 무엇인지 파악하고, 그와 비슷한 특성을 가진 다른 영화를 찾는 것이죠.

**두 번째 방법: "내 주변에 너랑 취향이 진짜 비슷한 친구가 있는데, 그 친구가 '인셉션'을 인생 영화로 꼽더라고. 너도 좋아할 것 같아."**
이것은 영화 자체가 아니라 **'사람(사용자)'**에 집중하는 방식입니다. 나와 취향이 비슷한 다른 사람들의 데이터를 분석해, 그들이 좋아했지만 나는 아직 보지 않은 영화를 추천하는 것입니다.

## 개념 설명: 콘텐츠 기반 필터링 vs 협업 필터링

위의 비유처럼 머신러닝의 추천 시스템은 크게 두 가지 방향으로 나뉩니다.

### 1. 콘텐츠 기반 필터링 (Content-Based Filtering)
아이템 자체의 특성(Content)을 분석합니다. 
- **원리**: 사용자가 과거에 높게 평가한 아이템과 유사한 특성을 가진 다른 아이템을 추천합니다.
- **특징**: 다른 사용자의 데이터가 필요 없으며, 사용자의 명확한 취향을 반영할 수 있습니다.
- **한계**: 사용자가 이미 좋아하는 것과 비슷한 것만 추천하게 되어, 새로운 취향을 발견하는 즐거움(**Serendipity**)이 부족하며, 소위 '필터 버블'에 갇힐 수 있다는 단점이 있습니다.

### 2. 협업 필터링 (Collaborative Filtering)
많은 사용자의 행동 데이터(Collaborative)를 분석합니다.
- **원리**: '사용자-아이템 행렬(User-Item Matrix)'을 통해 사용자 간의 유사한 패턴을 찾습니다. 
    - **사용자-아이템 행렬이란?** 행(Row)에는 사용자 이름을, 열(Column)에는 아이템 이름을 두고, 각 칸에는 사용자가 아이템에 남긴 평점이나 클릭 여부를 기록한 표입니다.

| 사용자 \ 영화 | 어벤져스 | 인셉션 | 극한직업 |
| :--- | :---: | :---: | :---: |
| **사용자 A** | 5 | 4 | 1 |
| **사용자 B** | 4 | 5 | 2 |
| **사용자 C** | 1 | 2 | 5 |

- **작동 방식**: 위 표에서 사용자 A와 B는 '어벤져스'와 '인셉션'에 모두 높은 점수를 주었습니다. 시스템은 "A와 B는 취향이 비슷하다"고 판단합니다. 만약 B가 '인터스텔라'라는 영화를 보고 5점을 줬는데 A는 아직 보지 않았다면, A에게 '인터스텔라'를 추천하는 방식입니다.
- **특징**: 아이템의 세부 특성을 몰라도 추천이 가능하며, 사용자가 예상치 못했던 새로운 취향의 아이템을 발견하게 해줍니다.

## 기술 설명: 코사인 유사도 (Cosine Similarity)

추천 시스템의 핵심은 **"얼마나 유사한가?"**를 숫자로 계산하는 것입니다. 이때 가장 많이 사용되는 지표가 바로 **코사인 유사도**입니다.

### 직관적 이해
데이터를 좌표평면 위의 '화살표(벡터)'라고 생각해보세요. 두 화살표가 가리키는 방향이 얼마나 일치하는지를 측정하는 것이 코사인 유사도입니다.

- **방향이 완전히 일치하면 (각도 0°)** $\rightarrow$ 유사도 **1** (매우 유사)
- **방향이 직각이면 (각도 90°)** $\rightarrow$ 유사도 **0** (상관없음)
- **방향이 정반대면 (각도 180°)** $\rightarrow$ 유사도 **-1** (매우 다름)

**참고**: 영화 장르 점수나 평점과 같이 0 이상의 값만 가지는 데이터셋에서는 두 벡터 사이의 각도가 0도에서 90도 사이로 제한됩니다. 따라서 결과값 역시 **0에서 1 사이**로 나타나게 됩니다.

### 수학적 원리 (간략히)
두 벡터의 내적을 각 벡터의 크기로 나누어 계산합니다. 결과값이 1에 가까울수록 두 아이템은 성격이 비슷하다고 판단합니다.

$$\text{Cosine Similarity} = \frac{A \cdot B}{\|A\| \|B\|}$$

## 파이썬 코드 실습: 콘텐츠 기반 영화 추천 시스템

이번 실습에서는 **콘텐츠 기반 필터링**을 구현해 보겠습니다. 특히, 데이터의 척도가 서로 다를 때 왜 정규화가 필요한지 함께 확인해 보겠습니다.

```python
import pandas as pd
from sklearn.metrics.pairwise import cosine_similarity
from sklearn.preprocessing import MinMaxScaler

# 1. 데이터셋 생성 (영화별 특성)
# 특성: [액션 점수(1~5), SF 점수(1~5), 누적 조회수(0~100만)]
# 조회수처럼 척도가 매우 큰 데이터가 섞여 있는 상황을 가정합니다.
data = {
    'movie': ['어벤져스', '아이언맨', '극한직업', '수상한 그녀', '인터스텔라', '그래비티'],
    'action': [5, 4, 2, 1, 2, 3],
    'scifi': [5, 5, 1, 1, 5, 5],
    'views': [1000000, 800000, 900000, 400000, 700000, 600000] 
}

df = pd.DataFrame(data)
df.set_index('movie', inplace=True)

print("--- 원본 영화 데이터셋 ---")
print(df)

# 2. 데이터 정규화 (Scaling)
# 코사인 유사도는 방향을 측정하지만, 특정 특성(조회수)의 수치가 압도적으로 크면
# 그 특성이 유사도 계산을 지배하게 됩니다. 따라서 0~1 사이로 범위를 맞춥니다.
scaler = MinMaxScaler()
scaled_data = scaler.fit_transform(df)
df_scaled = pd.DataFrame(scaled_data, index=df.index, columns=df.columns)

print("\n--- 정규화된 데이터셋 ---")
print(df_scaled)

# 3. 코사인 유사도 계산
similarity_matrix = cosine_similarity(df_scaled)
sim_df = pd.DataFrame(similarity_matrix, index=df.index, columns=df.index)

print("\n--- 코사인 유사도 행렬 ---")
print(sim_df)

# 4. 추천 함수 정의
def get_recommendations(movie_name, top_n=2):
    sim_scores = sim_df[movie_name].sort_values(ascending=False)
    recommendations = sim_scores.iloc[1:top_n+1]
    return recommendations

# 5. 결과 확인: '어벤져스'와 유사한 영화 추천
target_movie = '어벤져스'
recs = get_recommendations(target_movie)

print(f"\n['{target_movie}']와(과) 유사한 추천 영화:")
print(recs)
```

### 실행 결과 해설

**1. 정규화의 필요성**
위 코드에서 `views`(조회수) 데이터는 100만 단위인 반면, `action` 점수는 5점 만점입니다. 만약 정규화를 하지 않고 코사인 유사도를 계산한다면, 시스템은 액션/SF 점수 차이보다 조회수 차이를 훨씬 크게 인식하여 **사실상 '조회수가 비슷한 영화'를 추천**하게 됩니다. `MinMaxScaler`를 통해 모든 특성을 0~1 사이로 맞춤으로써, 모든 특성이 동등한 영향력을 갖게 했습니다.

**2. 유사도 행렬 해석**
출력된 `sim_df`를 보면 '어벤져스'와 '아이언맨'의 유사도 값이 매우 높게 나타납니다. 이는 두 영화가 액션과 SF 점수가 모두 높고, 조회수 규모도 비슷하기 때문입니다.

**3. 추천 결과 해석**
'어벤져스'를 입력했을 때 '아이언맨'과 '인터스텔라' 등이 추천되었다면, 시스템이 영화의 특성 벡터 방향을 정확히 분석해낸 결과입니다.

## 실무 활용 사례

실제 기업들은 하나의 방식만 사용하지 않고 **하이브리드 추천 시스템(Hybrid Recommendation System)**을 사용합니다.

- **넷플릭스(Netflix)**: 사용자가 시청한 콘텐츠의 특성을 분석(콘텐츠 기반)함과 동시에, 비슷한 시청 패턴을 가진 다른 사용자들의 데이터를 결합(협업 필터링)하여 추천 리스트를 구성합니다.
- **유튜브(YouTube)**: 영상의 태그, 설명뿐만 아니라 "이 영상을 본 사람이 다음에 본 영상"이라는 시퀀스 데이터를 분석하여 다음 영상을 추천합니다.

## 자주 하는 실수

**1. 데이터 스케일링의 오해**
"코사인 유사도는 방향만 보니까 정규화가 필요 없다"고 생각하기 쉽습니다. 하지만 이는 **모든 특성의 척도가 이미 동일할 때만** 맞는 말입니다. 평점(1~5)과 조회수(0~100만)처럼 척도가 다른 데이터가 섞여 있다면, 반드시 `MinMaxScaler` 등으로 범위를 맞춰야 합니다. 그렇지 않으면 수치가 큰 특성이 유사도 결과를 왜곡하게 됩니다.

**2. 콜드 스타트(Cold Start) 문제**
새로운 사용자가 가입했거나 새로운 영화가 등록되었을 때는 데이터가 없어 추천이 불가능한 현상이 발생합니다. 
- **해결책**: 신규 사용자에게는 초기 설문 조사를 통해 취향을 묻거나, 가장 인기 있는 콘텐츠(Popularity-based)를 먼저 추천하는 방식을 사용합니다.

## 핵심 요약

- **콘텐츠 기반 필터링**: 아이템의 특성을 분석하여 유사한 아이템을 추천. (단, 새로운 취향 발견의 어려움이 있음)
- **협업 필터링**: 사용자 간의 행동 패턴(사용자-아이템 행렬)을 분석하여 유사한 사용자가 좋아하는 아이템을 추천.
- **코사인 유사도**: 두 벡터 사이의 각도를 이용해 유사성을 측정하며, 1에 가까울수록 유사함. (양수 데이터의 경우 0~1 사이 값)
- **하이브리드 방식**: 두 방식의 장점을 결합해 정확도를 높이고 콜드 스타트 문제를 보완함.

## 정답 및 해설

1. **정답**: 콘텐츠 기반 필터링은 **아이템 자체의 특성**을 분석하고, 협업 필터링은 **사용자들의 행동 패턴**을 분석합니다.
2. **정답**: 두 아이템의 특성 벡터가 서로 직교함을 의미하며, 서로 **상관관계가 거의 없다(유사하지 않다)**고 볼 수 있습니다.
3. **정답**: **콜드 스타트(Cold Start)** 문제라고 하며, 인기 아이템을 추천하거나 가입 시 선호 장르를 선택하게 함으로써 해결할 수 있습니다.
