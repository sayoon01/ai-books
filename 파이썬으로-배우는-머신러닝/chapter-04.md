## 1. Matplotlib: 시각화의 기초 체력

### 1.1 비유: 도화지와 붓
Matplotlib을 사용하는 과정은 하얀 도화지를 펴놓고 붓으로 그림을 그리는 것과 비슷합니다. 내가 어디에 선을 그을지, 어떤 색의 붓을 사용할지, 축의 이름은 무엇으로 정할지를 하나하나 세밀하게 결정할 수 있습니다. 매우 강력하고 자유도가 높지만, 그만큼 세세하게 설정해줘야 한다는 특징이 있습니다.

### 1.2 직관: 무엇을 그리고 싶은가?
데이터 시각화의 핵심은 **'데이터의 특성에 맞는 그래프 선택'**에 있습니다.
- **변화의 흐름**을 보고 싶다면? $\rightarrow$ **선 그래프(Line Plot)**
- **두 변수 사이의 관계**를 보고 싶다면? $\rightarrow$ **산점도(Scatter Plot)**
- **데이터의 분포(빈도)**를 보고 싶다면? $\rightarrow$ **히스토그램(Histogram)**

### 1.3 기술 설명: Matplotlib의 기본 구조
Matplotlib의 가장 핵심적인 개념은 `Figure`와 `Axes`입니다. 이 둘의 관계를 이해하는 것이 Matplotlib 정복의 첫걸음입니다.

- **Figure**: 전체 그림이 그려지는 도화지입니다. 모든 그래프 요소들을 담는 가장 큰 틀입니다.
- **Axes**: 도화지 안에 그려지는 개별 그래프(축)입니다. 하나의 Figure 안에 여러 개의 Axes를 배치하여 여러 개의 그래프를 동시에 보여줄 수 있습니다.

> **[그림 4-1: Matplotlib의 계층 구조 도식]**
> - 가장 바깥쪽의 큰 테두리를 **Figure**로 표시
> - Figure 내부에 배치된 개별 그래프 영역을 **Axes**로 표시
> - Axes 내부의 x축과 y축 선을 **Axis**로 표시하여 `Figure` $\rightarrow$ `Axes` $\rightarrow$ `Axis` 순의 계층 구조를 시각화

#### [실습 1] 기본 그래프 그리기
가장 먼저, 간단한 데이터를 생성하여 선 그래프와 산점도를 그려보겠습니다.

```python
import matplotlib.pyplot as plt
import numpy as np

# 1. 데이터 준비
x = np.array([1, 2, 3, 4, 5])
y = np.array([2, 3, 5, 7, 11]) # 소수(Prime numbers) 데이터

# 2. 그래프 생성
plt.figure(figsize=(10, 5)) # 도화지 크기 설정 (가로 10, 세로 5)

# 첫 번째 서브플롯: 선 그래프
plt.subplot(1, 2, 1) # 1행 2열 중 첫 번째
plt.plot(x, y, color='blue', marker='o', linestyle='--', linewidth=2)
plt.title("Line Plot: Prime Numbers")
plt.xlabel("Index")
plt.ylabel("Value")
plt.grid(True)

# 두 번째 서브플롯: 산점도
plt.subplot(1, 2, 2) # 1행 2열 중 두 번째
plt.scatter(x, y, color='red', s=100)
plt.title("Scatter Plot: Prime Numbers")
plt.xlabel("Index")
plt.ylabel("Value")
plt.grid(True)

plt.tight_layout() # 그래프 간 간격 자동 조정
plt.show()
```

**[실행 결과 해석]**
- **왼쪽 선 그래프**: 점들이 선으로 연결되어 있어, 값이 인덱스가 증가함에 따라 전반적으로 상승하는 '추세'를 한눈에 확인할 수 있습니다.
- **오른쪽 산점도**: 각 데이터 포인트가 개별적인 점으로 표시됩니다. 데이터 간의 간격이나 밀집도를 확인하기에 유리합니다.

## 2. Seaborn: 쉽고 아름다운 고수준 시각화

### 2.1 비유: 전문가의 템플릿
Matplotlib이 붓과 물감으로 하나하나 그리는 작업이라면, Seaborn은 이미 잘 만들어진 **'전문가용 템플릿'**을 사용하는 것과 같습니다. Matplotlib을 기반으로 만들어졌기 때문에 더 정교한 제어가 가능하면서도, 복잡한 통계 그래프를 단 한 줄의 코드로 그려낼 수 있게 도와줍니다.

### 2.2 직관: 데이터프레임과의 찰떡궁합
Seaborn의 최대 장점은 Pandas의 DataFrame과 완벽하게 연동된다는 점입니다. 컬럼 이름만 지정해주면 Seaborn이 알아서 축 이름을 설정하고, 범례(Legend)를 생성하며, 색상을 배분합니다. 머신러닝에서는 데이터의 상관관계를 분석하는 것이 매우 중요한데, Seaborn은 이를 위한 강력한 도구들을 제공합니다.

### 2.3 기술 설명: 핵심 시각화 도구

#### (1) 히트맵(Heatmap)과 상관계수
머신러닝 모델을 만들기 전, 어떤 특성(Feature)이 타겟 값과 밀접한 관계가 있는지 파악하는 것이 중요합니다. 이때 사용하는 것이 **상관계수(Correlation Coefficient)**와 이를 시각화한 **히트맵**입니다.

- **상관계수**: -1부터 1 사이의 값을 가지며, 1에 가까울수록 강한 양의 상관관계, -1에 가까울수록 강한 음의 상관관계를 의미합니다.

#### [실습 2] 상관관계 분석하기
실제 머신러닝에서 자주 쓰이는 붓꽃(Iris) 데이터를 활용해 보겠습니다.

```python
import seaborn as sns
import pandas as pd
import matplotlib.pyplot as plt

# 1. 데이터 로드
iris = sns.load_dataset('iris')

# 2. 상관계수 계산
# numeric_only=True를 설정하여 숫자형 데이터만 계산합니다.
corr = iris.corr(numeric_only=True)

# 3. 히트맵 그리기
plt.figure(figsize=(8, 6))
sns.heatmap(corr, annot=True, fmt=".2f", cmap='coolwarm', linewidths=0.5)
plt.title("Iris Feature Correlation Heatmap")
plt.show()
```

**[실행 결과 해석]**
- **해석 방법**: 색이 붉을수록 양의 상관관계가 강하고, 푸를수록 음의 상관관계가 강합니다.
- **분석**: `petal_length`와 `petal_width` 사이의 상관계수가 매우 높게(약 0.96) 나타납니다. 이는 꽃잎의 길이가 길수록 너비도 넓어진다는 것을 의미하며, 머신러닝 모델 학습 시 두 변수가 매우 유사한 정보를 제공하고 있음을 짐작할 수 있게 합니다.

#### (2) 박스 플롯(Box Plot)과 이상치(Outlier)
데이터에 말도 안 되게 크거나 작은 값(이상치)이 섞여 있으면 머신러닝 모델의 성능이 떨어집니다. 박스 플롯은 데이터의 4분위수를 시각화하여 이상치를 찾아내는 데 최적입니다.

> **[그림 4-2: 박스 플롯(Box Plot)의 구조 상세도]**
> - **중앙선**: 박스 내부의 가로선 $\rightarrow$ **중앙값(Median)**
> - **박스 영역**: 1사분위수(Q1)부터 3사분위수(Q3)까지의 구간 $\rightarrow$ **IQR (Interquartile Range, 데이터의 중앙 50%)**
> - **수염(Whisker)**: 박스 위아래로 뻗은 선 $\rightarrow$ **정상 범위의 최댓값과 최솟값**
> - **점(Dots)**: 수염 밖에 위치한 개별 점 $\rightarrow$ **이상치(Outlier)**

#### [실습 3] 박스 플롯으로 이상치 확인하기

```python
plt.figure(figsize=(10, 6))
sns.boxplot(x='species', y='sepal_length', data=iris)
plt.title("Sepal Length Distribution by Species")
plt.show()
```

**[실행 결과 해석]**
- 각 품종별로 꽃받침 길이(`sepal_length`)의 분포가 다름을 알 수 있습니다.
- 만약 박스 위아래로 멀리 떨어진 점들이 보인다면, 해당 데이터는 일반적인 범위를 벗어난 이상치일 가능성이 큽니다. 모델 학습 전 이러한 데이터를 제거하거나 보정하는 작업이 필요합니다.

#### (3) 페어 플롯(Pair Plot)
변수가 여러 개일 때, 모든 변수 쌍의 관계를 한꺼번에 보고 싶다면 페어 플롯이 정답입니다.

```python
sns.pairplot(iris, hue='species', markers=["o", "s", "D"])
plt.suptitle("Pair Plot of Iris Dataset", y=1.02)
plt.show()
```

**[실행 결과 해석]**
- 대각선 방향의 그래프는 각 변수의 분포(KDE)를 보여줍니다.
- 나머지 그래프들은 두 변수 간의 산점도를 보여줍니다.
- **핵심 발견**: `petal_length`와 `petal_width`를 축으로 하는 그래프를 보면, 세 품종이 매우 명확하게 구분되는 것을 볼 수 있습니다. 이는 머신러닝 모델이 이 두 특성을 사용하면 품종을 매우 정확하게 분류할 수 있을 것임을 암시합니다.

## 3. 실무 활용 사례: 탐색적 데이터 분석(EDA)

현업 데이터 분석가들은 모델을 만들기 전 **EDA(Exploratory Data Analysis, 탐색적 데이터 분석)** 과정을 거칩니다. 시각화는 EDA의 핵심입니다.

**[실무 시나리오: 고객 이탈 예측 분석]**
어떤 서비스의 고객 이탈(Churn) 여부를 예측하는 프로젝트를 맡았다고 가정해 봅시다. 데이터에는 '사용 기간', '월 결제 금액', '고객 센터 문의 횟수', '이탈 여부' 등의 컬럼이 있습니다.

1. **히스토그램 분석**: '월 결제 금액'의 분포를 그려봅니다. $\rightarrow$ 특정 금액대에 고객이 몰려 있는지, 아니면 소수의 고액 결제자가 있는지 확인합니다.
2. **박스 플롯 분석**: '이탈자'와 '유지자' 그룹으로 나누어 '문의 횟수'를 비교합니다. $\rightarrow$ 이탈자의 문의 횟수가 현저히 높다면, '문의 횟수'는 이탈을 예측하는 매우 중요한 특성(Feature)이 됩니다.
3. **히트맵 분석**: 모든 숫자 변수 간의 상관관계를 봅니다. $\rightarrow$ '사용 기간'과 '총 결제 금액'이 너무 강한 상관관계를 가진다면, 둘 중 하나만 사용해도 충분하겠다고 판단하여 모델을 단순화(Feature Selection)할 수 있습니다.

## 4. 초보자가 자주 하는 실수와 해결 방법

### 4.1 "그래프에 한글이 깨져요!"
Matplotlib은 기본적으로 영문 폰트를 사용합니다. 한글을 입력하면 네모 모양(`□`)으로 깨져서 출력됩니다.

**[해결 방법]**
운영체제에 맞는 폰트를 설정해주어야 합니다. (Windows 기준)

```python
import matplotlib.pyplot as plt
from matplotlib import rc

# 한글 폰트 설정 (Windows: Malgun Gothic, Mac: AppleGothic)
rc('font', family='Malgun Gothic')
# 마이너스 기호 깨짐 방지
plt.rcParams['axes.unicode_minus'] = False
```

### 4.2 "그래프가 너무 겹쳐서 안 보여요!"
여러 개의 그래프를 그릴 때, 축 이름이나 제목이 서로 겹치는 경우가 많습니다.

**[해결 방법]**
- `plt.tight_layout()`을 호출하여 요소 간의 간격을 자동으로 최적화합니다.
- `plt.figure(figsize=(가로, 세로))`를 통해 도화지 크기를 충분히 키웁니다.

### 4.3 "어떤 그래프를 써야 할지 모르겠어요."
데이터의 성격에 따라 선택하세요. 아래 표를 참고하십시오.

| 분석 목적 | 추천 그래프 | 이유 |
| :--- | :--- | :--- |
| **시간에 따른 변화** | Line Plot | 연속적인 흐름을 파악하기 좋음 |
| **두 변수의 상관관계** | Scatter Plot | 점들의 분포를 통해 관계(선형/비선형) 파악 가능 |
| **단일 변수의 분포/빈도** | Histogram | 데이터가 어디에 밀집되어 있는지 확인 가능 |
| **그룹 간의 통계적 차이** | Box Plot | 중앙값, 사분위수, 이상치를 한눈에 비교 가능 |
| **변수 간 전체 관계** | Pair Plot | 여러 변수 간의 조합을 빠르게 훑어볼 수 있음 |

## 5. 요약 및 마무리

이번 장에서는 데이터의 정체를 밝혀내는 강력한 도구인 Matplotlib과 Seaborn을 학습했습니다.

- **Matplotlib**은 도화지에 직접 그리는 세밀한 제어가 가능한 기초 라이브러리입니다.
- **Seaborn**은 Matplotlib을 기반으로 하며, Pandas 데이터프레임과 연동되어 복잡한 통계 시각화를 쉽게 구현하게 해줍니다.

머신러닝 모델에 데이터를 넣기 전, 시각화를 통해 데이터를 충분히 이해하는 과정(EDA)은 모델의 성능을 높이는 가장 빠른 길입니다. 이제 우리는 데이터를 '보는' 눈을 갖게 되었습니다. 다음 장에서는 이렇게 분석한 데이터를 바탕으로, 머신러닝의 꽃이라고 할 수 있는 '모델 학습'의 세계로 들어가겠습니다.
