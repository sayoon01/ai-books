### 1. 학습 목표
데이터 분석의 핵심은 단순히 숫자를 계산하는 것이 아니라, 그 속에 숨겨진 **'패턴'**을 찾아내는 것입니다.

*   **Matplotlib**: 파이썬 시각화의 가장 기본이 되는 로우 레벨(Low-level) 라이브러리
*   **Seaborn**: Matplotlib을 기반으로 통계적 시각화를 쉽고 아름답게 구현하는 하이 레벨(High-level) 라이브러리
*   **주요 그래프**: 산점도(Scatter plot), 히스토그램(Histogram), 박스 플롯(Box plot), 히트맵(Heatmap)
*   **핵심 개념**: 데이터 분포 파악, 변수 간 상관관계 분석, 이상치(Outlier) 탐지

---

### 2. 실생활 비유: 장부와 대시보드
여러분은 한 달 동안 쓴 가계부를 기록하고 있습니다.

**방법 A (텍스트 분석):** 31일치 지출 내역이 적힌 수천 줄의 텍스트 장부를 한 줄 한 줄 읽으며 "내가 어디에 돈을 많이 썼지?"라고 분석합니다. 숫자의 나열 속에서 패턴을 찾으려면 엄청난 집중력과 시간이 필요하며, 전체적인 흐름을 놓치기 쉽습니다.

**방법 B (시각화 분석):** 지출 카테고리별(식비, 교통비, 쇼핑 등)로 묶어 하나의 **원형 그래프(Pie Chart)**나 **막대 그래프**로 그려봅니다. 이 경우, 단 1초 만에 "아, 이번 달은 쇼핑에 너무 많은 돈을 썼구나!"라는 **인사이트(Insight)**를 즉각적으로 얻을 수 있습니다.

머신러닝에서도 마찬가지입니다. 수만 개의 행과 열로 이루어진 표(DataFrame)를 텍스트로 보는 것보다, 적절한 그래프 한 장을 보는 것이 데이터의 본질을 훨씬 빠르게 이해하게 해줍니다.

### 3. 직관적 이해: EDA(탐색적 데이터 분석)란?
데이터 시각화의 궁극적인 목적은 **EDA(Exploratory Data Analysis)**를 수행하는 것입니다. 

EDA는 복잡한 머신러닝 모델을 적용하기 전, 분석가가 직접 데이터를 '탐색'하며 데이터의 정체성을 파악하는 과정입니다. 마치 요리를 하기 전 식재료의 상태를 꼼꼼히 살피는 것과 같습니다. 시각화를 통해 우리는 다음과 같은 질문에 답을 찾을 수 있습니다.

1.  **결측치 확인**: "데이터에 빈 곳이 많아 분석이 불가능한 수준인가?"
2.  **이상치 발견**: "평균에서 너무 멀리 떨어진, 말도 안 되는 값이 섞여 있는가?"
3.  **상관관계 파악**: "정답($y$)에 결정적인 영향을 주는 핵심 변수($x$)는 무엇인가?"
4.  **분포 확인**: "데이터가 특정 구간에 쏠려 있는가, 아니면 고르게 퍼져 있는가?"

### 4. 기술 설명

#### (1) Matplotlib vs Seaborn
파이썬 시각화 생태계는 크게 두 라이브러리가 양분하고 있습니다.

*   **Matplotlib**: '도화지와 붓'입니다. 그래프의 모든 요소(축, 색상, 폰트, 선 굵기 등)를 세밀하게 조정할 수 있지만, 코드가 길고 기본 디자인이 투박합니다.
*   **Seaborn**: Matplotlib 위에 씌워진 '세련된 필터'이자 '자동 템플릿'입니다. Pandas 데이터프레임과 완벽하게 호환되며, 복잡한 통계 그래프를 단 한 줄의 코드로 구현할 수 있어 실무에서 매우 선호됩니다.

#### (2) 상황별 그래프 선택 가이드
데이터의 특성과 분석 목적에 따라 적절한 그래프를 선택하는 것이 중요합니다.

| 분석 목적 | 추천 그래프 | 직관적 의미 | 기술적 특징 |
| :--- | :--- | :--- | :--- |
| **두 변수의 관계** | **산점도 (Scatter Plot)** | "A가 커지면 B도 커질까?" | x, y축에 두 변수를 배치해 점으로 표현 |
| **한 변수의 분포** | **히스토그램 (Histogram)** | "어느 구간에 데이터가 몰려 있지?" | 데이터를 구간별로 나누어 빈도수를 막대로 표현 |
| **이상치 및 분포** | **박스 플롯 (Box Plot)** | "평균적인 범위는 어디고, 튀는 값은 뭐야?" | 사분위수를 이용해 중앙값과 이상치를 시각화 |
| **전체 변수 간 상관도** | **히트맵 (Heatmap)** | "어떤 변수들끼리 서로 친할까?" | 상관계수 수치를 색상의 진하기로 표현 |

### 5. 파이썬 코드 실습
Seaborn에 내장된 `tips`(식당 팁 데이터) 데이터셋을 사용하여 네 가지 핵심 그래프를 한 번에 그려보겠습니다.

```python
import pandas as pd
import matplotlib.pyplot as plt
import seaborn as sns

# 1. 데이터 로드
tips = sns.load_dataset('tips') 

# 한글 폰트 설정 (환경에 따라 'Malgun Gothic' 또는 'AppleGothic' 등으로 변경)
plt.rc('font', family='NanumBarunGothic') 

# 시각화 영역 설정 (2x2 배열)
plt.figure(figsize=(15, 12))

# [그래프 1] 산점도: 총 금액과 팁의 관계
plt.subplot(2, 2, 1)
sns.scatterplot(data=tips, x='total_bill', y='tip', hue='time', style='time')
plt.title('총 금액 vs 팁 (시간대별)')
plt.xlabel('총 식사 금액 ($)')
plt.ylabel('팁 금액 ($)')

# [그래프 2] 히스토그램: 총 금액의 분포
plt.subplot(2, 2, 2)
sns.histplot(data=tips, x='total_bill', kde=True, color='skyblue')
plt.title('총 식사 금액 분포')
plt.xlabel('총 식사 금액 ($)')
plt.ylabel('빈도수')

# [그래프 3] 박스 플롯: 요일별 팁의 분포
plt.subplot(2, 2, 3)
sns.boxplot(data=tips, x='day', y='tip', palette='Set3')
plt.title('요일별 팁 분포')
plt.xlabel('요일')
plt.ylabel('팁 금액 ($)')

# [그래프 4] 히트맵: 수치형 변수 간 상관관계
plt.subplot(2, 2, 4)
# 수치형 데이터만 추출하여 상관계수 계산
corr = tips.select_dtypes(include=['float64', 'int64']).corr()
sns.heatmap(corr, annot=True, cmap='coolwarm', fmt=".2f", linewidths=0.5)
plt.title('변수 간 상관계수 히트맵')

plt.tight_layout()
plt.show()
```

---

### 6. 실행 결과 및 해석

**1. 산점도 (Scatter Plot)**
*   **결과**: 점들이 우상향하는 직선 형태로 분포합니다.
*   **해석**: `total_bill`이 증가할수록 `tip`도 함께 증가하는 **강한 양의 상관관계**가 있음을 알 수 있습니다. 또한 색상을 통해 점심보다 저녁 시간대에 높은 금액의 결제가 더 많이 일어남을 확인 가능합니다.

**2. 히스토그램 (Histogram)**
*   **결과**: 10~20달러 구간에 가장 많은 데이터가 몰려 있으며, 오른쪽으로 갈수록 완만하게 낮아집니다.
*   **해석**: 데이터가 정규분포보다는 **오른쪽 꼬리가 긴 분포(Right-skewed)**를 보입니다. 대부분의 손님은 적당한 금액을 지출하지만, 소수의 손님이 매우 높은 금액을 지출함을 의미합니다.

**3. 박스 플롯 (Box Plot)**
*   **결과**: 요일별로 상자의 높이와 위치가 다르며, 상자 위쪽으로 점들이 찍혀 있습니다.
*   **해석**: 토요일과 일요일의 팁 중앙값이 평일보다 높게 형성되어 있습니다. 특히 상자 밖의 점들은 **이상치(Outlier)**로, 해당 요일에 유독 팁을 많이 준 '통 큰 손님'이 존재했음을 보여줍니다.

**4. 히트맵 (Heatmap)**
*   **결과**: `total_bill`과 `tip` 사이의 칸이 붉은색이며 `0.68`이라는 수치가 적혀 있습니다.
*   **해석**: 상관계수가 1에 가까울수록 강한 양의 상관관계를 의미합니다. `0.68`은 두 변수가 매우 밀접하게 연관되어 있어, 식사 금액을 알면 팁 금액을 어느 정도 예측할 수 있음을 수치적으로 증명합니다.

### 7. 실무 활용 사례: 특성 선택(Feature Selection)
실무에서 데이터 사이언티스트는 모델을 구축하기 전, 시각화를 통해 **어떤 변수를 모델에 넣고 뺄지** 결정합니다.

*   **상황**: '아파트 가격 예측 모델'을 개발 중입니다.
*   **분석**: 
    *   `방의 개수` $\times$ `집값` $\rightarrow$ **산점도**를 그렸더니 뚜렷한 우상향 패턴 발견 $\rightarrow$ **"중요한 변수이므로 유지"**
    *   `집주인의 취미` $\times$ `집값` $\rightarrow$ **산점도**를 그렸더니 아무런 패턴 없이 점들이 무작위로 흩어짐 $\rightarrow$ **"예측에 도움이 안 되는 변수이므로 제거"**
*   **결과**: 불필요한 변수를 제거함으로써 모델의 복잡도를 낮추고, 과적합(Overfitting)을 방지하여 **예측 정확도를 향상**시킵니다.

### 8. 자주 하는 실수

**❌ 실수: 서로 다른 스케일의 데이터를 하나의 축에 그리기**
*   **상황**: '나이(0~100)' 변수와 '연봉(0~1억)' 변수를 하나의 y축을 공유하는 막대 그래프로 그리는 경우.
*   **결과**: 연봉 막대는 화면 끝까지 솟아오르지만, 나이 막대는 바닥에 붙어 거의 보이지 않게 됩니다. 데이터의 차이가 너무 커서 시각화의 의미가 사라집니다.
*   **해결**: 
    1.  **서브플롯(Subplot)**을 사용하여 축을 분리합니다.
    2.  **정규화(Scaling)**를 통해 두 변수의 범위를 0~1 사이로 맞춥니다.
    3.  **로그 변환(Log Transform)**을 적용하여 큰 값의 격차를 줄입니다.

### 9. 핵심 요약
*   **EDA**는 모델 학습 전 데이터의 패턴, 이상치, 관계를 파악하는 필수적인 탐색 과정이다.
*   **Matplotlib**은 세밀한 조정이 가능한 기본 도구이며, **Seaborn**은 통계 시각화에 최적화된 고수준 도구이다.
*   **그래프 선택**: 관계 $\rightarrow$ 산점도, 분포 $\rightarrow$ 히스토그램, 이상치 $\rightarrow$ 박스플롯, 상관계수 $\rightarrow$ 히트맵.
*   시각화는 단순히 그림을 그리는 것이 아니라, **불필요한 변수를 제거하고 유의미한 가설을 세우기 위한 전략적 단계**이다.

---

### 11. 정답 및 해설
**정답:** 
수염 밖의 점들은 **'이상치(Outlier)'**를 의미합니다.

**해설:** 
분석가는 이상치를 발견했을 때 무조건 삭제하는 것이 아니라, 다음과 같은 논리적 판단을 내려야 합니다.
1.  **데이터 오류인가?**: (예: 나이가 200살로 입력됨) $\rightarrow$ 단순 입력 실수이므로 **제거하거나 수정**합니다.
2.  **희귀하지만 실제 존재하는 값인가?**: (예: 억만장자의 소비 패턴) $\rightarrow$ 분석 목적에 따라 **유지**하거나, 일반 데이터와 분리하여 **별도의 그룹으로 분석**합니다.
이상치를 잘못 처리하면 모델이 왜곡되거나(그대로 둘 경우), 중요한 특이 케이스를 놓칠 수(무작정 지울 경우) 있으므로 신중한 판단이 필요합니다.
