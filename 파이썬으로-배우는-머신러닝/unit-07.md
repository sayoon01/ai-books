## 실생활 비유: "경험으로 때려 맞히는 규칙"

우리는 일상생활에서 무의식중에 '회귀'를 사용하고 있습니다. 예를 들어, 여러분이 카페 사장님이라고 가정해 봅시다. 

지난 1년간의 데이터를 보니, **"기온이 1도 올라갈 때마다 아이스 아메리카노가 평균 5잔 더 팔리더라"**라는 규칙을 발견했습니다. 그렇다면 내일 기온이 오늘보다 3도 더 높다면, 아메리카노가 평소보다 약 15잔 정도 더 팔릴 것이라고 예상할 수 있겠죠.

여기서 '기온'은 원인이 되고, '판매량'은 결과가 됩니다. 이처럼 **원인과 결과 사이의 일정한 패턴을 찾아내어 선(Line)으로 그려내고, 그 선을 통해 미래의 값을 예측하는 것**이 바로 회귀의 핵심입니다.

## 개념 설명: 회귀란 무엇인가?

**회귀(Regression)**란 여러 개의 독립 변수($X$)와 한 개의 종속 변수($y$) 사이의 상관관계를 모델링하는 것입니다.

- **독립 변수 (Independent Variable, $X$):** 영향을 주는 변수. 예측의 근거가 되는 값입니다. (예: 집의 평수, 공부 시간, 기온)
- **종속 변수 (Dependent Variable, $y$):** 영향을 받는 변수. 우리가 최종적으로 알고 싶은 예측값입니다. (예: 집값, 시험 점수, 매출액)

회귀의 목표는 데이터들을 가장 잘 설명하는 **'최적의 직선'**을 찾는 것입니다. 

> **[도식화 가이드]**
> - 좌표평면 위에 흩뿌려진 점(데이터)들을 상상해 보세요.
> - 그 점들의 한가운데를 가로지르는 직선 하나가 그려집니다.
> - 이 직선이 실제 점들과의 거리가 전체적으로 가장 가깝게 위치할 때, 우리는 이 직선을 '최적의 모델'이라고 부릅니다.

새로운 $X$값이 들어왔을 때, 이 최적의 직선 위에서 대응하는 $y$값을 읽어내면 그것이 바로 우리의 예측값이 됩니다.

## 기술 설명: 선형 회귀(Linear Regression)

가장 기본이 되는 **선형 회귀**는 데이터의 관계를 직선 형태로 표현합니다. 중학교 수학 시간에 배운 일차함수 식과 매우 비슷합니다.

$$\text{예측값}(\hat{y}) = w \times x + b$$

- **$w$ (Weight, 가중치/기울기):** $x$가 $y$에 주는 영향력의 크기를 나타냅니다. (예: 평수가 1평 늘어날 때 집값이 얼마나 오르는가?)
- **$b$ (Bias, 편향/절편):** $x$가 0일 때의 기본값입니다. (예: 집 평수가 0이라도 기본적으로 가지고 있는 땅값)

### 어떻게 '최적의 선'을 찾을까요?
컴퓨터는 처음에는 무작위로 직선을 긋습니다. 그 후, **실제 값과 예측 값의 차이(오차)**를 계산합니다. 이 오차를 수치화한 것이 **손실 함수(Loss Function)**이며, 선형 회귀에서는 주로 **MSE(Mean Squared Error, 평균 제곱 오차)**를 사용합니다.

$$\text{MSE} = \frac{1}{n} \sum (y_{\text{실제}} - \hat{y}_{\text{예측}})^2$$

**여기서 왜 '제곱'을 할까요?**
1. **음수 제거:** 오차가 -10이든 +10이든 똑같이 '큰 오차'로 취급하기 위해서입니다.
2. **큰 오차에 패널티 부여:** 오차가 2배 커지면 제곱 값은 4배가 됩니다. 즉, 아주 크게 틀린 예측에 대해 더 강한 경고를 주어 모델이 빠르게 수정되도록 유도하는 것입니다.

**주의할 점: 단위의 문제와 RMSE**
하지만 MSE는 오차를 제곱했기 때문에 **단위가 변한다는 문제**가 있습니다. 예를 들어 집값 단위가 '억 원'이라면, MSE의 단위는 '억 원의 제곱'이 되어 직관적으로 얼마나 틀렸는지 해석하기 어렵습니다. 이를 해결하기 위해 MSE에 다시 루트(Root)를 씌워 원래 단위로 되돌린 것이 바로 **RMSE(Root Mean Squared Error)**입니다.

컴퓨터는 이 오차(MSE) 값이 최소가 되도록 $w$와 $b$를 계속해서 수정합니다. 마치 산 정상에서 가장 낮은 골짜기(오차가 최소인 지점)를 향해 내려가는 것과 비슷합니다.

## 파이썬 코드 실습: 집값 및 매출 예측 모델 만들기

이제 `scikit-learn` 라이브러리를 사용하여 수치를 예측하는 모델을 만들어 보겠습니다. 먼저 집 평수에 따른 집값을 예측해 보고, 이를 응용해 매출액까지 예측해 보겠습니다.

```python
import numpy as np
import matplotlib.pyplot as plt
from sklearn.linear_model import LinearRegression
from sklearn.model_selection import train_test_split
from sklearn.metrics import mean_squared_error, r2_score

# [사례 1] 집값 예측 데이터 준비
X_house = np.array([10, 15, 20, 25, 30, 35, 40, 45, 50, 55, 60]).reshape(-1, 1)
y_house = np.array([2.1, 3.2, 3.8, 5.1, 5.9, 7.2, 8.1, 9.0, 10.2, 11.1, 12.5])

# 1. 모델 생성 및 학습
house_model = LinearRegression()
house_model.fit(X_house, y_house)

# 2. 예측 및 평가
y_house_pred = house_model.predict(X_house)
mse_house = mean_squared_error(y_house, y_house_pred)
rmse_house = np.sqrt(mse_house) # MSE에 루트를 씌워 RMSE 계산
r2_house = r2_score(y_house, y_house_pred)

print(f"[집값 모델] MSE: {mse_house:.4f}, RMSE: {rmse_house:.4f}, R2: {r2_house:.4f}")

# --- [응용] 사례 2: 매출 예측 모델 구현 ---
# 데이터: 방문객 수(X) -> 매출액(y, 단위: 만 원)
X_sales = np.array([120, 150, 110, 180, 200, 160, 140, 190, 130, 170]).reshape(-1, 1)
y_sales = np.array([45, 60, 40, 75, 85, 65, 55, 80, 50, 70])

sales_model = LinearRegression()
sales_model.fit(X_sales, y_sales)

# 새로운 데이터 예측: 방문객이 210명일 때 매출은?
new_visitor = np.array([[210]])
predicted_sales = sales_model.predict(new_visitor)

print(f"[매출 모델] 방문객 210명일 때 예상 매출: {predicted_sales[0]:.2f}만 원")
print(f"[매출 모델] R2 Score: {r2_score(y_sales, sales_model.predict(X_sales)):.4f}")

# 3. 집값 모델 시각화
plt.scatter(X_house, y_house, color='blue', label='Actual Data')
plt.plot(X_house, house_model.predict(X_house), color='red', label='Regression Line')
plt.xlabel('House Size (pyung)')
plt.ylabel('Price (100M KRW)')
plt.legend()
plt.show()
```

### 실행 결과 해설

1. **기울기($w$)와 절편($b$):** 모델 내부적으로 계산된 기울기는 독립 변수가 1단위 증가할 때 종속 변수가 얼마나 변하는지를 나타내며, 절편은 기본 시작값을 의미합니다.
2. **MSE와 RMSE:** MSE는 오차의 제곱 평균이며, **RMSE는 이를 다시 루트 씌워 실제 값과 동일한 단위로 맞춘 지표**입니다. 예를 들어 RMSE가 0.2라면, 모델의 예측값이 실제 집값과 평균적으로 약 0.2억 원 정도 차이가 난다고 직관적으로 이해할 수 있습니다.
3. **$R^2$ Score (결정 계수):** 이 수치는 **"단순히 모든 데이터를 평균값으로 예측했을 때보다 우리 모델이 얼마나 더 정확한가"**를 나타내는 상대적 지표입니다. 
   - 단순히 평균으로 예측하는 것은 데이터의 전체 변동성(분산)을 그대로 두는 것입니다.
   - $R^2$가 0.95라면, 데이터가 가진 전체 변동성 중 95%를 모델이 논리적으로 설명해내고 있다는 뜻입니다. 1에 가까울수록 성능이 뛰어납니다.
4. **시각화 결과:** 파란색 점들이 빨간색 직선에 가깝게 붙어 있을수록 선형 회귀 모델이 데이터의 경향성을 잘 파악한 것입니다.

## 실무 활용 사례

회귀 모델은 실무에서 "특정 수치를 예측"해야 하는 거의 모든 영역에서 기초가 됩니다.

- **이커머스 매출 예측:** 마케팅 비용 지출액($X$)에 따른 다음 달 예상 매출액($y$) 예측 $\rightarrow$ 예산 최적화에 활용.
- **제조 공정 품질 관리:** 원료의 온도나 압력($X$)에 따른 제품의 강도($y$) 예측 $\rightarrow$ 불량률 감소에 활용.
- **금융 시장 분석:** 금리 변동($X$)에 따른 주가 지수($y$)의 흐름 예측 $\rightarrow$ 투자 전략 수립에 활용.
- **에너지 수요 예측:** 외부 기온($X$)에 따른 전력 소모량($y$) 예측 $\rightarrow$ 전력 발전량 조절 및 에너지 효율화에 활용.

## 자주 하는 실수

**1. 상관관계와 인과관계를 혼동하는 경우**
- **실수:** "아이스크림 판매량이 늘어나니 익사 사고가 늘어났다. 따라서 아이스크림이 익사 사고의 원인이다!"라고 결론 내리는 것입니다.
- **해결:** 회귀 모델은 두 변수 사이의 '수치적 관계'를 보여줄 뿐, 반드시 하나가 다른 하나의 '원인'임을 보장하지 않습니다. 위 사례의 실제 원인은 '여름철 기온 상승'이라는 제3의 변수(잠재 변수)입니다. 데이터 분석 시에는 항상 도메인 지식을 바탕으로 인과관계를 신중히 판단해야 합니다.

**2. 외삽(Extrapolation)의 위험**
- **실수:** 10평~60평까지의 데이터로 학습한 모델에 1,000평짜리 빌딩의 가격을 예측하라고 시키는 것입니다.
- **해결:** 모델은 학습한 데이터의 범위 내에서 가장 정확합니다. 범위를 크게 벗어난 데이터를 예측할 때는 직선의 경향성이 유지되지 않을 가능성이 높으므로, 결과값이 부정확할 수 있음을 인지하고 주의해야 합니다.

## 핵심 요약

- **회귀**는 연속적인 숫자 값을 예측하는 지도학습 방법이다.
- **선형 회귀**는 $y = wx + b$라는 직선 방정식을 통해 데이터의 경향성을 파악한다.
- **MSE**는 오차의 제곱 평균이며, 단위 문제를 해결하기 위해 루트를 씌운 **RMSE**를 함께 사용한다.
- **$R^2$ Score**는 전체 분산 대비 모델이 설명하는 분산의 비율을 나타내며, 1에 가까울수록 성능이 좋다.

## 정답 및 해설

1. **정답:** 예측하려는 결과값의 형태입니다. 분류는 'A냐 B냐'와 같은 **범주(Label)**를 예측하고, 회귀는 '몇 점인가, 얼마인가'와 같은 **연속적인 수치(Value)**를 예측합니다.
2. **정답:** $w$는 가중치(Weight)로 독립 변수가 종속 변수에 주는 영향력(기울기)을 의미하며, $b$는 편향(Bias)으로 독립 변수가 0일 때의 기본값(y절편)을 의미합니다.
3. **정답:** MSE는 오차를 제곱하여 평균 낸 값으로, 단위가 제곱되어 해석이 어렵습니다. RMSE는 여기에 루트를 씌워 원래 데이터와 동일한 단위로 되돌린 값으로, 실제 오차가 어느 정도인지 직관적으로 파악하기 위해 사용합니다.
