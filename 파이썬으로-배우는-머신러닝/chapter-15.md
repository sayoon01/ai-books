# 챕터 15: 실전 프로젝트 - 영화 추천 시스템

우리는 지금까지 데이터를 분류하고 숫자를 예측하는 다양한 머신러닝 모델을 배웠습니다. 이제 이 모든 지식을 총동원하여 실무에서 가장 사랑받는 기능 중 하나인 **'추천 시스템(Recommendation System)'**을 만들어 보겠습니다.

추천 시스템은 단순히 정답을 맞히는 것이 아니라, 사용자의 취향을 분석해 "당신이 좋아할 만한 것"을 제안하는 예술과 기술의 결합입니다. 이 장을 마치고 나면, 여러분은 면접관 앞에서 **"추천 시스템은 결국 데이터 간의 '유사도'를 측정하여 공간상의 거리를 계산하는 과정입니다"**라고 자신 있게 설명할 수 있게 될 것입니다.

---

### 1. 실생활 비유: "취향 저격 추천 친구"

여러분 주변에 영화를 정말 많이 보는 '영화 박사' 친구가 있다고 가정해 봅시다. 이 친구는 두 가지 방식으로 영화를 추천해 줍니다.

**첫 번째 방식: "너 액션 영화 좋아하잖아!" (콘텐츠 기반)**
여러분이 '어벤져스'를 재밌게 봤다면, 그 영화의 특징(액션, 슈퍼히어로, 마블)을 분석해 비슷한 특징을 가진 '아이언맨'이나 '캡틴 아메리카'를 추천하는 방식입니다. 즉, **영화라는 '물건' 자체가 가진 속성**에 집중하는 것입니다.

**두 번째 방식: "내 다른 친구들도 너랑 취향이 비슷하던데, 이거 꼭 봐!" (협업 필터링)**
여러분의 취향이 '철수'라는 친구와 매우 비슷하다는 것을 발견했습니다. 철수가 '인셉션'을 보고 극찬했다면, 여러분도 '인셉션'을 좋아할 확률이 높다고 보고 추천하는 방식입니다. 이는 물건의 속성이 아니라 **사용자들의 '행동 패턴'**에 집중하는 것입니다.

---

### 2. 개념 설명: 데이터의 좌표화와 직관적 거리

추천 시스템의 핵심은 **"A와 B가 얼마나 비슷한가?"**를 측정하는 것입니다. 컴퓨터는 '취향'이라는 추상적인 개념을 이해하지 못하므로, 이를 **벡터(Vector)**라는 숫자의 나열(좌표)로 변환해야 합니다.

**[직관적 이해: 취향의 지도]**
1. **벡터화:** 영화의 장르나 사용자의 평점을 숫자로 바꿉니다. 
   - 예: [액션: 5, 로맨스: 1, 코미디: 2] $\rightarrow$ 이 숫자는 3차원 공간의 한 점 $(5, 1, 2)$가 됩니다.
2. **공간상의 거리:** 모든 영화를 이런 식으로 좌표평면에 점으로 찍으면, 비슷한 취향의 영화나 사용자는 서로 **가까운 위치**에 모이게 됩니다.
3. **유사도 측정:** 두 점 사이의 거리가 가까울수록 "유사도가 높다"고 판단합니다. 추천 시스템은 결국 내가 지금 보고 있는 점(영화)에서 가장 가까운 곳에 있는 다른 점(영화) $K$개를 찾아내는 과정입니다.

---

### 3. 기술 설명: 코사인 유사도와 필터링 전략

#### (1) 코사인 유사도 (Cosine Similarity)
단순히 두 점 사이의 직선 거리(유클리드 거리)를 잴 수도 있지만, 추천 시스템에서는 주로 **코사인 유사도**를 사용합니다. 이는 두 벡터 사이의 **'각도'**를 측정하는 방식입니다.

- **왜 각도인가요?** 
  사용자 A는 모든 영화에 평점을 후하게(4~5점) 주고, 사용자 B는 매우 짜게(1~2점) 줄 수 있습니다. 하지만 두 사람 모두 '액션'에는 상대적으로 높은 점수를 주고 '로맨스'에는 낮은 점수를 줬다면, 두 사람의 **취향(방향)**은 일치하는 것입니다. 코사인 유사도는 값의 절대적 크기보다 **방향의 일치성**을 보기 때문에 훨씬 정확한 취향 분석이 가능합니다.
- **값의 범위:** -1부터 1까지이며, **1에 가까울수록 방향이 완전히 일치(매우 유사)**함을 의미합니다.

#### (2) 콘텐츠 기반 필터링 vs 협업 필터링
| 구분 | 콘텐츠 기반 필터링 (Content-Based) | 협업 필터링 (Collaborative Filtering) |
| :--- | :--- | :--- |
| **핵심 아이디어** | 아이템의 특징(장르, 감독 등) 분석 | 사용자들의 행동 기록(평점, 구매 등) 분석 |
| **장점** | 사용자 데이터가 적어도 추천 가능 (Cold Start 완화) | 아이템 특징을 몰라도 추천 가능, 의외의 발견 가능 |
| **단점** | 비슷한 것만 추천함 (필터 버블/과적합 위험) | 신규 사용자/아이템 추천 불가 (Cold Start 문제) |

### 4. 파이썬 코드 실습: 콘텐츠 기반 영화 추천 엔진 구현

영화의 장르 가중치 데이터를 활용해, 특정 영화와 가장 유사한 영화를 추천하는 엔진을 구현해 보겠습니다.

```python
import pandas as pd
from sklearn.metrics.pairwise import cosine_similarity

# 1. 데이터 생성 (영화 제목과 장르 가중치)
# 각 수치는 해당 장르의 특성이 얼마나 강한지를 나타내는 가중치입니다.
data = {
    'movie_title': ['어벤져스', '아이언맨', '라라랜드', '어바웃 타임', '인셉션', '인터스텔라'],
    'action': [5, 5, 1, 1, 4, 3],
    'romance': [1, 1, 5, 5, 1, 2],
    'scifi': [5, 4, 1, 1, 5, 5]
}

df = pd.DataFrame(data)
df.set_index('movie_title', inplace=True)

print("--- [1] 영화 특징 데이터프레임 ---")
print(df)

# 2. 코사인 유사도 계산
# cosine_similarity는 모든 행(영화) 간의 유사도를 계산하여 행렬로 반환합니다.
similarity_matrix = cosine_similarity(df)

# 결과 확인을 위해 데이터프레임 형태로 변환
similarity_df = pd.DataFrame(similarity_matrix, index=df.index, columns=df.index)

print("\n--- [2] 영화 간 코사인 유사도 행렬 ---")
print(similarity_df.round(2))

# 3. 특정 영화 기반 추천 함수 정의
def get_recommendations(movie_name, similarity_df, top_k=2):
    # 해당 영화와 다른 영화들 간의 유사도를 가져와 내림차순 정렬
    sim_scores = similarity_df[movie_name].sort_values(ascending=False)
    
    # 자기 자신(유사도 1.0)은 제외하고 상위 k개 추출
    recommendations = sim_scores.iloc[1:top_k+1]
    return recommendations

# 4. 실행: '어벤져스'와 유사한 영화 추천받기
target_movie = '어벤져스'
recs = get_recommendations(target_movie, similarity_df)

print(f"\n--- [3] '{target_movie}'와(과) 유사한 추천 영화 ---")
print(recs)
```

2. **유사도 행렬 분석:**

   - **라라랜드 $\leftrightarrow$ 어바웃 타임 (1.00):** 두 영화의 특징 벡터 방향이 완전히 일치하여 유사도가 1로 계산되었습니다.
   - **어벤져스 $\leftrightarrow$ 라라랜드 (0.26):** 두 벡터의 방향이 크게 다르므로 낮은 유사도를 보입니다.

### 6. 실무 활용 사례

- **넷플릭스(Netflix):** 사용자가 시청한 콘텐츠의 특징(장르, 배우)과 다른 사용자의 시청 패턴을 모두 결합한 **'하이브리드 추천 시스템'**을 사용합니다.
- **유튜브(YouTube):** 영상의 태그(콘텐츠 기반)와 유사한 시청 기록을 가진 다른 사용자가 본 영상(협업 필터링)을 딥러닝 모델(Deep Neural Networks)로 분석해 실시간으로 추천합니다.
- **쿠팡/아마존:** "이 상품을 구매한 분들이 함께 구매한 상품" 섹션은 전형적인 **협업 필터링**의 사례로, 아이템의 속성을 몰라도 구매 패턴만으로 추천을 수행합니다.

### 7. 자주 하는 실수

1. **데이터 스케일 무시:** 어떤 사용자는 평점을 1~5점으로 주고, 어떤 사용자는 1~100점으로 준다면 유사도 계산에 왜곡이 생깁니다. 반드시 **정규화(Normalization)** 또는 **표준화(Standardization)** 과정을 거쳐야 합니다.
2. **콜드 스타트(Cold Start) 문제 간과:** 신규 사용자가 가입했을 때 추천할 데이터가 없는 현상입니다. 실무에서는 이를 해결하기 위해 가입 시 "선호 장르"를 선택하게 하거나, 전체 사용자에게 인기 있는 "베스트셀러"를 먼저 추천합니다.
3. **희소 행렬(Sparse Matrix) 메모리 문제:** 사용자가 수백만 명이고 상품이 수만 개일 때, 대부분의 칸은 비어있게 됩니다. 이를 일반 데이터프레임으로 처리하면 메모리 부족(OOM)이 발생하므로 `scipy.sparse`와 같은 희소 행렬 전용 라이브러리를 사용해야 합니다.

### 8. 핵심 요약

- **추천 시스템**은 데이터 간의 **유사도**를 측정하여 사용자에게 최적의 아이템을 제안하는 시스템이다.
- **콘텐츠 기반 필터링**은 아이템의 **특성**을, **협업 필터링**은 사용자의 **행동**을 분석한다.
- **코사인 유사도**는 두 벡터의 **각도**를 측정하여 방향의 일치성을 확인하는 지표이며, 1에 가까울수록 유사하다.
- **추천 프로세스:** 데이터 수집 $\rightarrow$ 벡터화 $\rightarrow$ 유사도 계산 $\rightarrow$ 상위 $K$개 추천.

### 9. 확인 문제

**Q1.** 코사인 유사도가 0.1인 영화 A, B와 코사인 유사도가 0.9인 영화 C, D가 있습니다. 어떤 영화 쌍이 더 서로 비슷하다고 볼 수 있으며, 그 이유는 무엇인가요?

**Q2.** 신규 가입자가 한 명도 영화를 보지 않은 상태입니다. 이때 '협업 필터링'만으로 추천을 제공할 수 없는 이유는 무엇이며, 이 현상을 무엇이라 부르는지 쓰시오.

**Q3.** 유클리드 거리(Euclidean Distance)보다 코사인 유사도가 추천 시스템에서 더 선호되는 이유는 무엇인가요?

### 10. 정답 및 해설

**A1. 영화 C, D가 더 비슷합니다.** 코사인 유사도는 1에 가까울수록 두 벡터의 방향이 일치함을 의미하므로, 0.9인 C, D가 0.1인 A, B보다 훨씬 유사한 특성을 가졌다고 판단합니다.

**A2. 협업 필터링은 '다른 사용자의 행동 데이터'를 기반으로 추천하기 때문입니다.** 신규 사용자는 평점이나 시청 기록이 전혀 없으므로 비교 대상이 존재하지 않습니다. 이 문제를 **'콜드 스타트(Cold Start)'** 문제라고 합니다.

**A3. 코사인 유사도는 값의 절대적 크기가 아닌 '방향(각도)'을 측정하기 때문입니다.** 평점을 짜게 주는 사람과 후하게 주는 사람이 동일한 취향(방향)을 가졌을 때, 유클리드 거리는 두 점 사이의 거리가 멀게 나오지만, 코사인 유사도는 방향이 같으므로 가깝게 나옵니다.
