## 이번 장에서 배우는 내용
머신러닝의 세계에 오신 것을 환영합니다! 첫 번째 장에서는 우리가 앞으로 배울 '머신러닝'이 정확히 무엇인지, 그리고 왜 지금 이 기술이 중요한지를 다룹니다.

*   **머신러닝의 정의:** 머신러닝이 기존의 프로그래밍 방식과 어떻게 다른지 이해합니다.
*   **AI, 머신러닝, 딥러닝의 관계:** 서로 비슷해 보이는 세 개념의 포함 관계를 명확히 정리합니다.
*   **실생활 사례:** 우리 주변에서 머신러닝이 어떻게 활용되고 있는지(추천 시스템, 스팸 필터 등) 살펴봅니다.
*   **맛보기 실습:** 파이썬 코드를 통해 데이터에서 규칙을 찾아내는 머신러닝의 기본 원리를 체험합니다.

## 실생활 비유: 아이에게 '사과'를 가르치는 방법
여러분은 어린아이에게 '사과'가 무엇인지 어떻게 가르치시나요? 아마 다음과 같은 방법 중 하나를 선택하실 겁니다.

**방법 A (전통적인 방식):** 
"사과란 빨간색이고, 둥근 모양이며, 위에 작은 꼭지가 달려 있고, 단단한 과육을 가진 과일이란다."라고 **정확한 정의와 규칙**을 알려줍니다. 하지만 아이가 초록색 사과(아오리 사과)를 보게 되면, "빨간색이 아니니까 이건 사과가 아니야!"라고 판단하는 오류를 범하게 됩니다.

**방법 B (머신러닝 방식):** 
빨간 사과, 초록 사과, 깎아 놓은 사과, 작은 사과 등 **수많은 사과 사진을 보여주며** "이게 다 사과야"라고 말해줍니다. 아이는 여러 장의 사진을 보면서 스스로 '아, 색깔은 다를 수 있지만 공통적으로 이런 형태를 띠는구나'라는 **패턴**을 찾아냅니다. 나중에 처음 보는 사과 사진을 봐도 "이건 사과네!"라고 맞힐 수 있게 되죠.

머신러닝은 바로 이 **'방법 B'**와 같습니다. 사람이 일일이 규칙을 정해주는 것이 아니라, 컴퓨터가 데이터를 통해 스스로 규칙을 찾아내게 만드는 것입니다.

---

## 개념 설명: 전통적 프로그래밍 vs 머신러닝
우리가 지금까지 알고 있던 일반적인 프로그래밍과 머신러닝의 결정적인 차이는 **'규칙을 누가 만드느냐'**에 있습니다.

### 1. 전통적인 프로그래밍 (Rule-based)
전통적인 방식에서는 개발자가 문제 해결을 위한 '명확한 규칙(Rule)'을 직접 작성합니다.
*   **입력값(Data) + 규칙(Rule) $\rightarrow$ 결과값(Answer)**
*   예: "이메일 제목에 '광고'라는 단어가 있으면 $\rightarrow$ 스팸함으로 보내라."

### 2. 머신러닝 (Data-driven)
머신러닝에서는 데이터와 정답을 컴퓨터에게 주고, 컴퓨터가 그 사이의 규칙을 찾아내게 합니다.
*   **입력값(Data) + 결과값(Answer) $\rightarrow$ 규칙(Rule/Model)**
*   예: "지난 1년간 스팸으로 분류된 이메일 1만 건의 데이터를 줄게. 여기서 스팸 메일들의 공통적인 특징(규칙)을 찾아내 봐."

---

## 기술 설명: AI, 머신러닝, 딥러닝의 관계
뉴스나 책을 보면 인공지능(AI), 머신러닝(ML), 딥러닝(DL)이라는 용어가 혼용되어 사용됩니다. 하지만 이들은 서로 별개의 기술이 아니라, **포함 관계**에 있습니다.

![AI-ML-DL 관계 도식]
*(그림 설명: 가장 큰 원이 AI, 그 안에 ML이 있고, ML 안에 가장 작은 원으로 DL이 위치한 벤 다이어그램 형태)*

1.  **인공지능 (Artificial Intelligence):** 인간의 지능을 흉내 내는 모든 기술을 통칭하는 가장 넓은 개념입니다. (예: 체스 프로그램, 단순한 규칙 기반 챗봇)
2.  **머신러닝 (Machine Learning):** AI의 한 분야로, 명시적으로 프로그래밍 되지 않고 데이터로부터 학습하여 성능을 개선하는 알고리즘을 말합니다.
3.  **딥러닝 (Deep Learning):** 머신러닝의 한 종류로, 인간의 뇌 구조를 모방한 '인공신경망(Artificial Neural Networks)'을 층층이 쌓아 대량의 데이터를 학습하는 기술입니다. (예: 알파고, ChatGPT)

## 파이썬 코드 실습: 데이터에서 규칙 찾기
머신러닝이 어떻게 규칙을 찾는지 아주 간단한 예제로 확인해 보겠습니다. 우리는 **"입력값에 2를 곱한 값이 출력값으로 나온다"**라는 아주 단순한 규칙을 컴퓨터가 스스로 찾게 만들 것입니다.

```python
# 필요한 라이브러리 설치: pip install scikit-learn numpy
import numpy as np
from sklearn.linear_model import LinearRegression

# 1. 데이터 준비 (입력값 X, 정답 y)
# X: 공부 시간, y: 시험 점수라고 가정해 봅시다. (실제로는 y = 2 * X 의 관계)
X = np.array([[1], [2], [3], [4], [5]]) 
y = np.array([2, 4, 6, 8, 10])

# 2. 머신러닝 모델 생성 (선형 회귀 모델)
model = LinearRegression()

# 3. 학습 진행 (데이터와 정답을 주고 규칙을 찾게 함)
model.fit(X, y)

# 4. 새로운 데이터로 예측해보기
new_data = np.array([[10]]) # 10시간 공부했다면 점수는 몇 점일까?
prediction = model.predict(new_data)

print(f"입력값 10에 대한 예측 결과: {prediction[0]}")
print(f"모델이 찾아낸 규칙(기울기): {model.coef_[0]}")
```

### 실행 결과 해설
**결과:**
```text
입력값 10에 대한 예측 결과: 20.0
모델이 찾아낸 규칙(기울기): 2.0
```
*   **해석:** 우리는 모델에게 `y = 2 * X`라는 공식을 알려준 적이 없습니다. 단지 `[1, 2, 3, 4, 5]`와 `[2, 4, 6, 8, 10]`이라는 데이터 뭉치만 주었을 뿐입니다.
*   컴퓨터는 `fit()` 과정에서 데이터를 분석하여 **"아, 입력값에 2를 곱하면 정답이 나오는구나!"**라는 규칙(`coef_ = 2.0`)을 스스로 찾아냈습니다.
*   그 결과, 처음 본 데이터인 `10`을 넣었을 때 규칙에 따라 `20`이라는 정확한 예측값을 내놓은 것입니다.

## 실무 활용 사례
머신러닝은 이미 우리 일상 깊숙이 들어와 있습니다.

*   **스팸 메일 필터:** 수백만 개의 스팸 메일 텍스트를 학습하여, 특정 단어의 조합이나 발신 패턴을 분석해 스팸 여부를 판별합니다.
*   **넷플릭스/유튜브 추천 시스템:** 사용자가 시청한 영상 목록(데이터)과 시청 시간(결과)을 분석하여, 이 사용자가 좋아할 만한 다른 영상의 특징(규칙)을 찾아 추천합니다.
*   **금융 이상 거래 탐지 (FDS):** 평소 사용자의 결제 패턴을 학습한 뒤, 갑자기 평소와 전혀 다른 지역에서 거액이 결제되면 '이상 징후'로 판단하여 차단합니다.

## 자주 하는 실수
**"데이터만 많으면 무조건 성능이 좋아질 것이다?"**
초보자들이 가장 많이 하는 오해입니다. 머신러닝에서 중요한 것은 데이터의 **'양'**보다 **'질'**입니다.

*   **GIGO (Garbage In, Garbage Out):** 쓰레기가 들어가면 쓰레기가 나옵니다. 잘못된 데이터, 편향된 데이터를 학습시킨 모델은 아무리 데이터 양이 많아도 엉터리 결과를 내놓습니다. 
*   **해결 방법:** 모델을 돌리기 전, 데이터에 빈 값이 없는지, 말도 안 되는 수치(예: 나이가 500살)가 섞여 있지는 않은지 확인하는 '데이터 전처리' 과정이 필수적입니다.

## 핵심 요약
*   **전통적 프로그래밍**은 사람이 규칙을 정해주지만, **머신러닝**은 데이터로부터 컴퓨터가 규칙을 찾아냅니다.
*   **AI $\supset$ 머신러닝 $\supset$ 딥러닝** 순의 포함 관계를 가집니다.
*   머신러닝의 핵심 프로세스는 **[데이터 준비 $\rightarrow$ 학습(규칙 찾기) $\rightarrow$ 예측]**입니다.
*   좋은 모델을 만들기 위해서는 양질의 데이터가 필요합니다.

## 정답 및 해설
1. **정답:** 규칙(Rule)을 생성하는 주체입니다. 전통적 방식은 사람이 직접 규칙을 작성하지만, 머신러닝은 컴퓨터가 데이터를 통해 스스로 규칙을 찾아냅니다.
2. **정답:** 하위 개념입니다. (AI $\rightarrow$ 머신러닝 $\rightarrow$ 딥러닝 순으로 범위가 좁아집니다.)
3. **정답:** 데이터는 '이메일의 텍스트 내용/발신자 정보' 등이 되고, 정답은 '스팸 여부(스팸이다/아니다)'가 됩니다.
