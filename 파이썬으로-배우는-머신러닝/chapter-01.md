# 챕터 1: 머신러닝이란 무엇인가

# 챕터 1. 머신러닝이란 무엇인가

우리는 이미 머신러닝의 시대에 살고 있습니다. 아침에 일어나 스마트폰의 얼굴 인식으로 잠금을 해제하고, 유튜브가 추천해 주는 영상을 보며 시간을 보내며, 스팸 메일함에 자동으로 분류된 광고 메일들을 무심히 지웁니다. 이 모든 일상의 편리함 뒤에는 '머신러닝'이라는 거대한 기술적 흐름이 자리 잡고 있습니다.

하지만 '머신러닝'이라는 단어를 들었을 때, 많은 이들이 복잡한 수학 공식이나 천재 과학자들의 전유물이라고 생각하며 심리적 장벽을 느낍니다. 결론부터 말씀드리자면, 머신러닝은 수학의 영역이기 이전에 '학습하는 방식'에 대한 철학의 영역입니다.

---

## 1.1 전통적 프로그래밍 vs 머신러닝

### 레시피대로 요리하기 vs 맛을 보며 레시피 만들기

요리를 처음 배우는 사람을 상상해 봅시다. 가장 쉬운 방법은 검증된 '레시피'를 그대로 따르는 것입니다. "소금 5g, 설탕 10g을 넣고 10분간 끓이세요"라는 명확한 지시사항이 있다면, 누가 요리하더라도 거의 동일한 맛의 결과물을 얻을 수 있습니다. 여기서 레시피는 일종의 '규칙'입니다.

반면, 어떤 요리사는 레시피 없이 수많은 음식을 먹어보며 스스로 맛의 원리를 깨닫습니다. "아, 이 음식은 약간 짭짤하면서 끝맛이 달콤하구나. 아마 소금과 설탕이 이 정도 비율로 들어갔겠지?"라고 추론하는 식입니다. 이 요리사는 정해진 규칙을 따른 것이 아니라, 수많은 '데이터(음식의 맛)'를 통해 스스로 '규칙(레시피)'을 찾아낸 것입니다.

전통적인 프로그래밍과 머신러닝의 차이가 바로 여기에 있습니다.

### 명시적 규칙 기반과 데이터 기반 시스템

전통적인 프로그래밍(Traditional Programming)은 **명시적 규칙 기반(Rule-based)** 시스템입니다. 개발자가 컴퓨터에게 "A라는 상황이 오면 B라고 행동해"라고 일일이 규칙을 정의해 주는 방식입니다. 컴퓨터는 그저 입력된 규칙을 충실히 수행하는 계산기에 불과합니다.

반면, 머신러닝(Machine Learning)은 **데이터 기반(Data-driven)** 시스템입니다. 컴퓨터에게 규칙을 알려주는 대신, 방대한 양의 데이터와 그 결과값을 제공합니다. 그러면 컴퓨터는 그 데이터들 사이의 통계적 패턴을 분석하여 스스로 규칙을 찾아냅니다. 즉, 사람이 규칙을 만드는 것이 아니라, 컴퓨터가 데이터로부터 규칙을 '학습'하는 것입니다.

| 구분 | 전통적 프로그래밍 | 머신러닝 |
| :--- | :--- | :--- |
| **입력값** | 데이터 + **규칙(Rule)** | 데이터 + **결과(Answer)** |
| **출력값** | 결과(Answer) | **규칙(Rule/Model)** |
| **핵심** | 사람이 규칙을 정의함 | 컴퓨터가 규칙을 찾아냄 |

### 코드로 보는 차이점: 스팸 메일 분류기

간단한 스팸 필터를 만든다고 가정해 봅시다. '광고', '무료', '당첨'이라는 단어가 들어있으면 스팸으로 처리하는 기능을 구현해 보겠습니다.

#### [전통적 방식] `if-else` 문을 이용한 규칙 정의
전통적인 방식에서는 개발자가 직접 "어떤 단어가 들어있어야 스팸인가"라는 규칙을 정해야 합니다.

```python
# 전통적 프로그래밍 방식: 명시적 규칙 정의
def spam_filter(text):
    # 개발자가 직접 정의한 스팸 키워드 리스트 (규칙)
    spam_keywords = ['광고', '무료', '당첨', '최저가', '이벤트']
    
    for keyword in spam_keywords:
        if keyword in text:
            return "스팸 메일입니다."
    
    return "정상 메일입니다."

# 테스트
email1 = "축하합니다! 이벤트에 당첨되어 무료 쿠폰을 드립니다."
email2 = "안녕하세요, 내일 회의 시간 변경되었습니다."

print(f"메일 1: {spam_filter(email1)}") # 결과: 스팸 메일입니다.
print(f"메일 2: {spam_filter(email2)}") # 결과: 정상 메일입니다.
```

이 방식의 치명적인 단점은 '변화'에 취약하다는 것입니다. 만약 스팸 발송자가 '광고'라는 단어 대신 '광.고'나 'ㄱㅘㅇㄱㅗ'라고 쓴다면, 개발자는 매번 새로운 규칙을 추가해야 합니다.

#### [머신러닝 방식] 데이터로부터 규칙 학습
머신러닝 방식에서는 규칙을 직접 짜지 않습니다. 대신 "이런 메일들은 스팸이었고, 저런 메일들은 정상이었다"라는 데이터를 주고 학습시킵니다.

```python
from sklearn.feature_extraction.text import CountVectorizer
from sklearn.naive_bayes import MultinomialNB

# 1. 데이터 준비: [메일 내용]과 [정답(Label)]
emails = [
    "축하합니다! 이벤트에 당첨되어 무료 쿠폰을 드립니다.",
    "최저가 보장! 지금 바로 클릭하세요.",
    "안녕하세요, 내일 회의 시간 변경되었습니다.",
    "이번 주말에 같이 점심 식사 하실래요?"
]
labels = [1, 1, 0, 0] # 1: 스팸, 0: 정상

# 2. 텍스트 데이터를 숫자로 변환 (벡터화)
vectorizer = CountVectorizer()
X = vectorizer.fit_transform(emails)

# 3. 모델 생성 및 학습 (데이터를 통해 스스로 규칙을 찾음)
model = MultinomialNB()
model.fit(X, labels)

# 4. 새로운 데이터로 예측
new_email = ["무료 쿠폰 당첨 안내드립니다."]
new_email_vectorized = vectorizer.transform(new_email)
prediction = model.predict(new_email_vectorized)

print(f"새로운 메일 예측 결과: {'스팸' if prediction[0] == 1 else '정상'}")
```

> **핵심 요약:** 전통적 프로그래밍은 사람이 정한 '규칙'을 입력하여 결과를 얻는 것이고, 머신러닝은 '데이터'와 '결과'를 입력하여 컴퓨터가 스스로 '규칙'을 찾아내게 하는 것입니다.

## 1.2 정답이 있는 공부: 지도학습(Supervised Learning)

### 문제집과 정답지를 함께 공부하는 학생

우리가 학생 시절 공부했던 가장 일반적인 방법은 '문제집'을 푸는 것입니다. 문제집의 각 문제 아래에는 정답이 적혀 있거나, 뒷부분에 정답지가 별도로 마련되어 있습니다. 우리는 문제를 풀고 정답과 비교하며 "아, 이런 유형의 문제는 이렇게 풀어야 정답이 나오는구나"라고 깨닫습니다.

이렇게 정답이 함께 제공되는 상태에서 학습하는 것을 머신러닝에서는 **지도학습(Supervised Learning)**이라고 합니다. 여기서 '지도(Supervised)'라는 말은 선생님이 옆에서 정답을 알려주며 가르치는 것과 같다는 뜻입니다.

### 레이블(Label)과 학습 과정

지도학습의 핵심은 **레이블(Label)**입니다. 레이블이란 데이터에 붙어 있는 '정답'을 의미합니다. 예를 들어, 강아지 사진 1,000장과 고양이 사진 1,000장이 있을 때, 각 사진에 "이것은 강아지입니다", "이것은 고양이입니다"라고 이름표를 붙여주는 것이 바로 레이블링(Labeling)입니다.

컴퓨터는 [입력 데이터(사진) $\rightarrow$ 정답(레이블)]의 쌍을 반복해서 보면서, 강아지 사진에는 공통적으로 '처진 귀'가 있고, 고양이 사진에는 '뾰족한 귀'가 있다는 특징을 찾아냅니다. 지도학습은 크게 두 가지 유형으로 나뉩니다.

1.  **분류(Classification):** 출력값이 '예/아니오' 혹은 'A/B/C'처럼 정해진 범주(Category) 중 하나로 떨어지는 경우입니다. (예: 스팸 메일 여부 판별, 암 진단 여부)
2.  **회귀(Regression):** 출력값이 연속적인 숫자(Continuous Value)로 나오는 경우입니다. (예: 내일의 기온 예측, 아파트 가격 예측)

### 코드로 보는 지도학습: 결정 트리 분류기

`scikit-learn` 라이브러리의 **결정 트리(Decision Tree)** 알고리즘을 사용하여 간단한 분류 모델을 만들어 보겠습니다. 결정 트리는 스무고개처럼 질문을 던져 정답을 찾아가는 알고리즘입니다.

```python
from sklearn.tree import DecisionTreeClassifier

# 1. 데이터 준비 (특성: [메일 길이, 특수문자 개수], 정답: [스팸여부])
X = [
    [150, 5], [200, 10], [40, 1], [50, 2], [300, 15], [60, 0]
]
# 레이블(Label): 1(스팸), 0(정상)
y = [1, 1, 0, 0, 1, 0]

# 2. 모델 생성 (결정 트리 분류기)
clf = DecisionTreeClassifier()

# 3. 학습 (문제 X와 정답 y를 함께 제공)
clf.fit(X, y)

# 4. 새로운 데이터로 예측
new_mail = [[250, 12]]
prediction = clf.predict(new_mail)

print(f"예측 결과: {'스팸' if prediction[0] == 1 else '정상'}")
```

> **핵심 요약:** 지도학습은 '문제(데이터)'와 '정답(레이블)'을 함께 제공하여, 컴퓨터가 새로운 문제가 들어왔을 때 정답을 맞힐 수 있도록 학습시키는 방법입니다.

## 1.3 스스로 특징 찾기: 비지도학습(Unsupervised Learning)

### 색깔별로 레고 블록 정리하기

어린아이에게 수천 개의 레고 블록이 섞여 있는 상자를 준다고 생각합시다. 이때 부모님이 "빨간색은 이쪽에, 파란색은 저쪽에 모아줘"라고 알려주지 않아도, 아이는 본능적으로 비슷한 색깔끼리, 혹은 비슷한 모양끼리 블록을 모으기 시작합니다.

아이는 '빨간색'이라는 정답(레이블)을 배운 적은 없지만, 블록들을 관찰하며 "이것들은 서로 비슷하게 생겼네"라는 **패턴(Pattern)**을 발견한 것입니다. 이것이 바로 비지도학습의 본질입니다.

### 정답 없는 데이터의 구조 분석

**비지도학습(Unsupervised Learning)**은 정답(레이블)이 없는 데이터만을 가지고 학습하는 방식입니다. 컴퓨터에게 정답을 알려주지 않기 때문에, 컴퓨터는 데이터 자체의 특성을 분석하여 스스로 구조를 파악해야 합니다.

가장 대표적인 비지도학습 기법은 **군집화(Clustering)**입니다. 군집화는 데이터들 사이의 거리를 측정하여 유사한 특성을 가진 데이터들끼리 그룹으로 묶는 작업입니다. 넷플릭스의 추천 시스템이 좋은 예입니다. 넷플릭스는 사용자가 시청한 영상들의 목록을 분석하여, 취향이 비슷한 사용자들을 하나의 그룹으로 묶고 그 그룹 내에서 인기 있는 영상을 추천합니다.

### 코드로 보는 비지도학습: 고객 군집화

가장 대중적인 군집화 알고리즘인 **K-평균(K-Means)**을 사용하여 유사한 성향의 고객을 그룹핑해 보겠습니다.

```python
from sklearn.cluster import KMeans
import numpy as np

# 1. 데이터 준비: [연간 구매 금액, 방문 횟수] (정답/레이블 없음)
X = np.array([
    [100, 2], [110, 3], [120, 2],  # 그룹 1: 구매액 높음, 방문 적음 (VIP)
    [20, 15], [25, 18], [15, 20],  # 그룹 2: 구매액 낮음, 방문 잦음 (단골)
    [10, 2], [15, 1], [12, 3]      # 그룹 3: 구매액/방문 모두 적음 (신규/이탈)
])

# 2. 모델 생성 (3개의 그룹으로 나누겠다고 설정)
kmeans = KMeans(n_clusters=3, random_state=42, n_init='auto')

# 3. 학습 (정답 y 없이 X만 입력)
kmeans.fit(X)

# 4. 각 데이터가 어떤 그룹(Cluster)에 속하는지 확인
labels = kmeans.labels_
print(f"각 고객의 그룹 할당 결과: {labels}")

# 5. 새로운 고객의 그룹 예측
new_customer = [[115, 2]]
cluster = kmeans.predict(new_customer)
print(f"새로운 고객의 그룹: {cluster[0]}")
```

> **핵심 요약:** 비지도학습은 정답 없이 데이터 속에 숨겨진 '끼리끼리'의 법칙(패턴)을 찾아내어 데이터를 구조화하는 방법입니다.

## 1.4 시행착오를 통한 성장: 강화학습(Reinforcement Learning)

### 강아지 훈련시키기

강아지에게 '앉아'를 가르치는 과정을 생각해 봅시다. 강아지는 처음에 '앉아'라는 말이 무슨 뜻인지 모릅니다. 하지만 우연히 엉덩이를 바닥에 붙였을 때, 주인이 "착하다!"라고 칭찬하며 맛있는 간식을 줍니다.

강아지는 생각합니다. '어? 내가 방금 한 행동을 하니까 맛있는 게 나오네?' 이후 강아지는 간식이라는 **보상(Reward)**을 더 많이 받기 위해, 주인이 '앉아'라고 말할 때 엉덩이를 바닥에 붙이는 행동을 더 자주 하게 됩니다.

강화학습은 이처럼 정답을 알려주는 대신, 행동의 결과에 따른 '보상'을 통해 최적의 행동 전략을 학습하는 방식입니다.

### 에이전트와 환경, 그리고 보상

강화학습의 메커니즘은 다음과 같은 구성 요소로 이루어집니다.

1.  **에이전트(Agent):** 학습의 주체 (예: 강아지, 게임 AI, 자율주행 자동차)
2.  **환경(Environment):** 에이전트가 상호작용하는 세계 (예: 거실, 게임 맵, 도로 상황)
3.  **행동(Action):** 에이전트가 환경에서 취하는 행동 (예: 앉기, 왼쪽으로 이동, 가속 페달 밟기)
4.  **보상(Reward):** 행동의 결과로 받는 피드백 (예: 간식, 게임 점수, 사고 면함)

에이전트는 처음에는 무작위로 행동하다가, 보상을 받는 행동을 발견하면 그 행동을 강화하고 벌칙을 받는 행동은 피합니다. 이 과정을 반복하며 보상의 합계를 최대화하는 **정책(Policy)**을 수립합니다. 알파고(AlphaGo)가 대표적인 사례로, 수많은 대국을 통해 승리 확률이 높은 최적의 수를 스스로 깨우친 것입니다.

### 코드로 보는 강화학습: 보상 체계 시뮬레이션

실제 강화학습 알고리즘은 매우 복잡하지만, 그 핵심 원리인 '보상 체계'를 간단한 파이썬 코드로 시뮬레이션해 보겠습니다. 에이전트가 보물상자가 있는 위치를 찾아가는 과정입니다.

```python
import random

# 환경 설정
treasure_location = 5  # 보물상자는 5번 위치에 있음
agent_position = 0     # 에이전트는 0번 위치에서 시작
learning_rate = 0.1
q_table = [0] * 10     # 각 위치에서의 가치(Q-value)를 저장하는 테이블

# 학습 루프
for episode in range(1000): # 1000번의 시행착오
    agent_position = 0
    while agent_position != treasure_location:
        # 행동 결정: 왼쪽(-1) 또는 오른쪽(+1)으로 이동
        action = random.choice([-1, 1])
        next_position = agent_position + action
        
        if 0 <= next_position < 10:
            # 보상 설정
            if next_position == treasure_location:
                reward = 100  # 보물 발견! 큰 보상
            else:
                reward = -1   # 보물을 못 찾고 이동함 (비용 발생)
            
            # 가치 업데이트 (단순화된 Q-learning 개념)
            q_table[agent_position] += learning_rate * (reward - q_table[agent_position])
            agent_position = next_position

print(f"학습된 가치 테이블: \n{q_table}")
print(f"가장 가치가 높은 위치: {q_table.index(max(q_table))}")
```

> **핵심 요약:** 강화학습은 정답 대신 '보상'이라는 피드백을 통해, 어떤 상황에서 어떤 행동을 하는 것이 가장 유리한지 최적의 전략을 스스로 깨우치게 하는 방법입니다.

## 챕터 1 마무리: 나에게 맞는 학습 방법은?

지금까지 머신러닝의 정의와 세 가지 주요 학습 방식에 대해 알아보았습니다. 이제 우리는 어떤 상황에 어떤 머신러닝 기법을 적용해야 하는지 판단할 수 있는 기준을 갖게 되었습니다.

- **"데이터에 정답이 있고, 미래의 값을 예측하거나 분류하고 싶다"** $\rightarrow$ **지도학습**
  - 예: 스팸 메일 분류, 집값 예측, 이미지 인식
- **"정답은 모르겠지만, 데이터의 숨겨진 특징이나 그룹을 찾고 싶다"** $\rightarrow$ **비지도학습**
  - 예: 고객 세그먼트 분석, 추천 시스템, 데이터 압축
- **"정답은 없지만, 보상을 통해 최적의 행동 순서를 결정하고 싶다"** $\rightarrow$ **강화학습**
  - 예: 자율주행 자동차, 게임 AI, 로봇 제어

머신러닝은 마법이 아닙니다. 결국은 **'데이터 속에 숨겨진 패턴을 찾는 수학적 과정'**입니다. 하지만 그 수학적 복잡함은 이제 파이썬의 강력한 라이브러리들이 대신 처리해 줍니다. 우리는 어떤 데이터를 준비하고, 어떤 학습 방식을 선택하느냐라는 '전략적 사고'에 더 집중하면 됩니다.
