# 챕터 1: 머신러닝이란 무엇인가

## 1. [비유] 레시피대로 요리하기 vs 맛보고 레시피 추론하기

여러분은 요리 초보자입니다. 세상에서 가장 맛있는 떡볶이를 만들고 싶을 때, 두 가지 접근 방법이 있습니다.

**방법 A: 레시피 북을 그대로 따라 하기 (전통적 프로그래밍)**
유명 셰프가 쓴 레시피 북을 펼칩니다. *"고추장 2큰술, 설탕 1큰술, 물 500ml를 넣고 10분간 끓이세요."* 
여기서 레시피는 **'명시적인 규칙'**입니다. 규칙대로만 하면 항상 일정한 맛이 나지만, 만약 고추장 대신 쌈장을 넣어야 하는 상황이 오거나 재료의 상태가 바뀌면 레시피를 처음부터 다시 써야 합니다. 규칙을 만든 사람이 모든 상황을 예측해서 적어줘야만 작동하는 방식입니다.

**방법 B: 맛집의 맛을 보고 레시피를 추론하기 (머신러닝)**
레시피 북이 없습니다. 대신 유명 맛집의 떡볶이 100그릇을 직접 맛봅니다. 
*"음, 단맛이 강한 집은 설탕이 많이 들어갔겠군. 매운맛이 강한 집은 고춧가루 비율이 높겠어."* 
여러분은 수많은 맛(데이터)을 경험하며 **'맛있는 떡볶이가 되기 위한 규칙'을 스스로 찾아냅니다.** 정답(맛있는 떡볶이)과 재료(데이터)를 대조하며 그 사이의 상관관계를 깨닫는 것, 이것이 바로 머신러닝의 본질입니다.

## 2. [직관] 패턴 인식: "정답"에서 "규칙"을 찾아내는 힘

전통적인 프로그래밍은 사람이 컴퓨터에게 **"이렇게 해!"**라고 일일이 명령을 내리는 방식입니다. 하지만 세상의 모든 현상을 규칙으로 정의하기에는 한계가 있습니다. 예를 들어, '강아지 사진'을 구별하는 프로그램을 만든다고 가정해 봅시다.

*"귀가 뾰족해야 해", "털이 복슬복슬해야 해"* $\rightarrow$ 하지만 귀가 처진 강아지도 있고, 털이 없는 강아지도 있습니다. 모든 강아지의 특징을 규칙으로 만들려면 수만 가지의 `if-else` 문이 필요할 것입니다.

**머신러닝은 관점을 완전히 바꿉니다.**
규칙을 직접 만드는 대신, 수만 장의 강아지 사진을 컴퓨터에게 보여줍니다. 그러면 컴퓨터는 우리가 가르쳐주지 않아도 사진 속에서 공통적인 **패턴(Pattern)**을 찾아냅니다. 
*"아, 강아지 사진들은 공통적으로 코의 위치가 이렇고, 눈의 간격이 저렇구나!"* 
이렇게 데이터 속에서 스스로 규칙을 발견하고 이를 일반화하는 능력을 우리는 **'학습(Learning)'**이라고 부릅니다.

## 3. [기술 설명] 머신러닝의 정의와 AI $\rightarrow$ ML $\rightarrow$ DL의 관계

### 3.1 머신러닝의 기술적 정의
머신러닝(Machine Learning)은 명시적으로 프로그래밍되지 않고도 컴퓨터가 데이터를 통해 학습하고 성능을 향상시킬 수 있도록 하는 인공지능의 한 분야입니다. 가장 핵심적인 차이는 **'규칙(Rule)'을 누가 생성하느냐**에 있습니다.

| 구분 | 전통적 프로그래밍 (Rule-based) | 머신러닝 (Machine Learning) |
| :--- | :--- | :--- |
| **입력값** | 데이터 + **명시적 규칙** | 데이터 + **결과값(정답)** |
| **출력값** | 결과값 | **명시적 규칙 (모델/Model)** |
| **핵심 메커니즘** | 사람이 정의한 로직에 따라 결과 도출 | 데이터 간의 통계적 패턴을 찾아 모델 생성 |

### 3.2 AI, ML, DL의 포함 관계
많은 이들이 이 세 용어를 혼용하지만, 실제로는 다음과 같은 **포함 관계(Subset)**를 가집니다.

1. **인공지능 (Artificial Intelligence)**: 인간의 지능을 흉내 내는 모든 기술의 총칭. (가장 넓은 개념)
2. **머신러닝 (Machine Learning)**: AI의 하위 집합. 데이터를 통해 스스로 학습하여 성능을 높이는 알고리즘.
3. **딥러닝 (Deep Learning)**: ML의 하위 집합. 인간의 뇌 구조를 모방한 '인공신경망(Artificial Neural Networks)'을 사용하여 복잡하고 비정형적인 데이터(이미지, 음성 등)를 처리하는 기술.

**[ 관계도: AI $\supset$ ML $\supset$ DL ]**

## 4. 파이썬 코드 실습: 스팸 메일 분류기 만들기

'광고'라는 단어가 포함되면 스팸으로 처리하는 **전통적 방식**과, 단어들의 출현 빈도를 통해 학습하는 **머신러닝 방식**을 비교해 보겠습니다.

```python
# 필요한 라이브러리 설치: pip install scikit-learn
from sklearn.feature_extraction.text import CountVectorizer
from sklearn.naive_bayes import MultinomialNB

# 1. 데이터 준비 (메일 내용과 스팸 여부: 1은 스팸, 0은 정상)
emails = [
    "안녕하세요, 내일 회의 시간 변경되었습니다.", 
    "지금 바로 클릭해서 무료 쿠폰을 받으세요!", 
    "이번 주말에 같이 영화 볼래?", 
    "최저가 보장! 지금 즉시 구매하세요!", 
    "보고서 제출 기한이 오늘까지입니다."
]
labels = [0, 1, 0, 1, 0] # 0: 정상(Ham), 1: 스팸(Spam)

# -----------------------------------------------------------------
# 방법 1: 전통적인 규칙 기반 프로그래밍 (Rule-based)
# -----------------------------------------------------------------
def rule_based_filter(text):
    # 사람이 직접 정의한 '스팸 키워드' 규칙
    spam_keywords = ['무료', '최저가', '클릭', '구매']
    for word in spam_keywords:
        if word in text:
            return "스팸(Spam)"
    return "정상(Ham)"

print("--- [규칙 기반 결과] ---")
for email in emails:
    print(f"메일: {email} -> 결과: {rule_based_filter(email)}")


# -----------------------------------------------------------------
# 방법 2: 머신러닝 기반 프로그래밍 (ML-based)
# -----------------------------------------------------------------
# [단계 1] 텍스트 데이터를 숫자로 변환 (단어 빈도수 계산)
vectorizer = CountVectorizer()
X = vectorizer.fit_transform(emails)

# [단계 2] 모델 생성 및 학습 (나이브 베이즈 분류기 사용)
# 데이터(X)와 정답(labels)을 함께 넣어 규칙(모델)을 스스로 찾게 함
model = MultinomialNB()
model.fit(X, labels)

print("\n--- [머신러닝 기반 결과] ---")
# 새로운 메일 데이터로 테스트 (학습 데이터에 없던 문장)
test_emails = ["무료 쿠폰 증정", "내일 회의해요"]
test_X = vectorizer.transform(test_emails)
predictions = model.predict(test_X)

for email, pred in zip(test_emails, predictions):
    result = "스팸(Spam)" if pred == 1 else "정상(Ham)"
    print(f"메일: {email} -> 결과: {result}")
```

## 5. 실행 결과 및 해석

### 실행 결과
```text
--- [규칙 기반 결과] ---
메일: 안녕하세요, 내일 회의 시간 변경되었습니다. -> 결과: 정상(Ham)
메일: 지금 바로 클릭해서 무료 쿠폰을 받으세요! -> 결과: 스팸(Spam)
메일: 이번 주말에 같이 영화 볼래? -> 결과: 정상(Ham)
메일: 최저가 보장! 지금 즉시 구매하세요! -> 결과: 스팸(Spam)
메일: 보고서 제출 기한이 오늘까지입니다. -> 결과: 정상(Ham)

--- [머신러닝 기반 결과] ---
메일: 무료 쿠폰 증정 -> 결과: 스팸(Spam)
메일: 내일 회의해요 -> 결과: 정상(Ham)
```

### 결과 해석
1. **규칙 기반 방식**: 개발자가 미리 정의한 `spam_keywords` 리스트에 의존합니다. 매우 빠르고 명확하지만, 스팸 발송자가 "ㅁㅜ료 쿠폰"처럼 단어를 살짝 바꾸면 규칙을 일일이 수정해야 하는 유지보수의 어려움이 있습니다.
2. **머신러닝 방식**: `CountVectorizer`가 텍스트를 수치화하고, `MultinomialNB` 모델이 "스팸 메일에는 주로 어떤 단어들이 어떤 확률로 등장하는가"라는 **통계적 패턴**을 학습했습니다. 새로운 메일이 들어오면 학습된 확률 분포를 바탕으로 스팸 여부를 예측하므로, 규칙을 일일이 지정하지 않아도 유연하게 대응할 수 있습니다.

## 6. 실무 활용 사례

- **콘텐츠 추천 시스템 (Netflix, YouTube)**: 사용자의 시청 기록, '좋아요' 클릭, 머문 시간 등의 데이터를 학습하여 사용자가 좋아할 만한 영상을 예측해 추천합니다.
- **금융 부정 결제 탐지 (FDS)**: 평소 사용자의 결제 위치, 금액, 시간대 패턴을 학습합니다. 갑자기 평소와 전혀 다른 패턴(예: 새벽 3시, 해외 고액 결제)이 감지되면 이를 '이상치'로 판단하여 결제를 차단합니다.
- **이메일 스팸 필터 (Gmail)**: 단순 키워드 매칭을 넘어, 발신자의 평판, 메일의 구조, 수신자의 반응 등 수천 개의 특징(Feature)을 학습하여 정교하게 스팸을 걸러냅니다.

## 7. 전문가의 조언: Garbage In, Garbage Out

머신러닝을 처음 접하는 분들이 가장 많이 하는 실수는 `model.fit()`이라는 함수 하나로 모든 것이 해결될 것이라고 믿는 것입니다. 하지만 머신러닝 세계에는 **"쓰레기가 들어가면 쓰레기가 나온다(Garbage In, Garbage Out)"**라는 절대 원칙이 있습니다.

- **데이터 부족**: 학습 데이터가 너무 적으면 모델은 일반적인 규칙이 아닌 '우연한 일치'를 학습합니다(과적합).
- **데이터 편향**: 스팸 메일만 1,000장 있고 정상 메일이 1장뿐이라면, 모델은 모든 메일을 스팸이라고 판단하는 단순한 규칙을 학습하게 됩니다.

결국 머신러닝의 성패는 화려한 알고리즘보다 **'얼마나 양질의 데이터를 준비했는가'**에 달려 있습니다.

## 8. 핵심 요약
- **머신러닝**은 명시적인 규칙 없이 데이터에서 스스로 패턴을 찾아내는 기술이다.
- **전통적 프로그래밍**은 `데이터 + 규칙 $\rightarrow$ 결과` / **머신러닝**은 `데이터 + 결과 $\rightarrow$ 규칙(모델)`의 구조를 가진다.
- **AI $\supset$ ML $\supset$ DL** 순으로 포함 관계가 형성되며, 딥러닝은 인공신경망을 이용한 ML의 한 종류이다.
- 머신러닝의 성능은 알고리즘 자체보다 **데이터의 품질과 양**에 결정적으로 의존한다.

## 10. 정답 및 해설

1. **정답**: 전통적 프로그래밍은 사람이 직접 규칙(Rule)을 작성하여 컴퓨터에 입력하는 방식이지만, 머신러닝은 데이터와 정답을 입력하면 컴퓨터가 그 사이의 패턴을 분석하여 스스로 규칙을 찾아내는 방식입니다.
2. **정답**: 인공지능이 가장 포괄적인 개념이며, 그 안에 데이터를 이용해 학습하는 머신러닝이 포함되고, 머신러닝 안에 인간의 뇌 구조를 모방한 인공신경망 기반의 딥러닝이 포함됩니다. (AI $\supset$ ML $\supset$ DL)
3. **정답**: 데이터 속에 숨겨진 반복적인 패턴이나 변수 간의 상관관계를 수학적으로 찾아내어, 새로운 데이터가 입력되었을 때 결과를 예측할 수 있는 '모델(함수)'을 생성하는 과정을 의미합니다.
