## 2. 실생활 비유: 이름표 없는 과일 바구니 정리하기
이름표가 하나도 붙어 있지 않은 과일 100개가 섞여 있는 바구니가 있다고 상상해 보세요. 과일들의 정확한 이름은 모르지만, 다음과 같은 특징을 관찰할 수 있습니다.

- **빨갛고 둥근 것들** $\rightarrow$ A 그룹
- **길쭉하고 노란 것들** $\rightarrow$ B 그룹
- **작고 보라색이며 송이로 뭉쳐있는 것들** $\rightarrow$ C 그룹

여기서 중요한 점은 "이것은 사과다"라는 정답을 알고 묶은 것이 아니라, 오직 **"모양과 색깔이 비슷하다"**라는 기준(특징)만으로 그룹을 나누었다는 것입니다. 이것이 바로 비지도학습의 **군집화(Clustering)**입니다.

---

## 3. 직관적 이해: "가까운 것끼리 뭉쳐라"
비지도학습의 핵심은 **'데이터 간의 거리'**입니다. 머신러닝에서는 색깔이나 모양 같은 기준을 **'특성(Feature)'**이라고 부릅니다.

데이터를 좌표 평면 위의 점으로 생각한다면, 서로 가까이 있는 점들은 성격이 비슷하고, 멀리 떨어져 있는 점들은 성격이 다르다고 판단합니다. 군집화의 직관적인 목표는 다음과 같습니다.
- **내부 응집도 최대화:** 같은 그룹에 속한 데이터들끼리는 최대한 가깝게 모여 있어야 한다.
- **외부 분리도 최대화:** 서로 다른 그룹끼리는 최대한 멀리 떨어져 있어야 한다.

---

## 4. 기술 설명: K-Means 알고리즘

K-Means는 가장 단순하면서도 강력한 군집화 알고리즘입니다. 여기서 **K**는 나누고자 하는 **그룹의 개수**를 의미합니다.

### ⚙️ 작동 원리 (4단계)
1. **중심점 초기화:** 데이터 공간에 무작위로 $K$개의 중심점(Centroid)을 배치합니다.
2. **그룹 할당:** 모든 데이터 포인트는 가장 가까운 중심점에 할당됩니다. 이때 두 점 사이의 직선 거리인 **유클리드 거리(Euclidean Distance)**를 사용합니다.
3. **중심점 업데이트:** 각 그룹에 할당된 데이터들의 산술 평균 위치(Mean)를 계산하여, 중심점을 그 위치로 이동시킵니다.
4. **반복:** 중심점이 더 이상 변하지 않거나, 설정한 최대 반복 횟수에 도달할 때까지 2~3단계를 반복합니다.

### 📈 최적의 K를 찾는 방법: 엘보우 방법(Elbow Method)
K 설정에 따라 결과가 완전히 달라지므로, 객관적인 기준인 **엘보우 방법**을 사용합니다.
- **관성(Inertia):** 각 데이터와 자신이 속한 군집의 중심점 사이의 거리의 제곱 합입니다. 군집화가 촘촘하게 잘 될수록 이 값은 작아집니다.
- **판단 기준:** $K$값을 1부터 차례대로 늘려가며 관성 값을 그래프로 그립니다. $K$가 커질수록 관성은 줄어들지만, 어느 지점부터는 감소 폭이 급격히 완만해집니다. 이 꺾이는 지점이 마치 **사람의 팔꿈치(Elbow)**처럼 보이며, 이곳이 효율성과 성능의 균형이 맞는 최적의 $K$값이 됩니다.

## 5. 파이썬 코드 실습: 고객 구매 패턴 분석
가상의 쇼핑몰 고객 데이터(연간 소득과 지출 점수)를 이용해 고객을 최적의 그룹으로 나누어 보겠습니다.

```python
import numpy as np
import pandas as pd
import matplotlib.pyplot as plt
from sklearn.cluster import KMeans
from sklearn.preprocessing import StandardScaler

# 1. 가상 데이터 생성 (연간 소득, 지출 점수)
np.random.seed(42)
# 4개의 서로 다른 특성을 가진 그룹 생성
group1 = np.random.randn(50, 2) * [5, 5] + [20, 20] # 저소득 저지출
group2 = np.random.randn(50, 2) * [5, 5] + [80, 20] # 고소득 저지출
group3 = np.random.randn(50, 2) * [5, 5] + [20, 80] # 저소득 고지출
group4 = np.random.randn(50, 2) * [5, 5] + [80, 80] # 고소득 고지출
data = np.vstack([group1, group2, group3, group4])

df = pd.DataFrame(data, columns=['Annual Income', 'Spending Score'])

# 2. 데이터 전처리 (스케일링)
# K-Means는 거리 기반 알고리즘이므로 반드시 스케일링이 필요합니다.
scaler = StandardScaler()
df_scaled = scaler.fit_transform(df)

# 3. 엘보우 방법을 통한 최적의 K 찾기
inertia = []
for k in range(1, 11):
    kmeans = KMeans(n_clusters=k, random_state=42, n_init=10)
    kmeans.fit(df_scaled)
    inertia.append(kmeans.inertia_)

# 시각화 1: 엘보우 그래프
plt.figure(figsize=(12, 5))
plt.subplot(1, 2, 1)
plt.plot(range(1, 11), inertia, marker='o', color='b')
plt.title('Elbow Method for Optimal K')
plt.xlabel('Number of clusters (K)')
plt.ylabel('Inertia')
plt.grid(True)

# 4. 최적의 K(엘보우 지점인 4)로 모델 학습
k_optimal = 4
kmeans = KMeans(n_clusters=k_optimal, random_state=42, n_init=10)
df['Cluster'] = kmeans.fit_predict(df_scaled)

# 시각화 2: 군집화 결과
plt.subplot(1, 2, 2)
colors = ['red', 'blue', 'green', 'purple']
for i in range(k_optimal):
    cluster_data = df[df['Cluster'] == i]
    plt.scatter(cluster_data['Annual Income'], cluster_data['Spending Score'], 
                c=colors[i], label=f'Cluster {i}', edgecolors='k')

plt.title(f'Customer Segments (K={k_optimal})')
plt.xlabel('Annual Income')
plt.ylabel('Spending Score')
plt.legend()
plt.grid(True)
plt.tight_layout()
plt.show()
```

### 📋 실행 결과 및 해석
1. **엘보우 그래프 해석:** 
   - $K=1$에서 $K=4$까지는 관성(Inertia) 값이 급격하게 떨어지지만, $K=4$ 이후부터는 감소 폭이 매우 완만해집니다. 
   - 따라서 이 데이터의 최적 군집 수는 **$K=4$**임을 알 수 있습니다.
2. **군집화 결과 해석:** 
   - 산점도 그래프를 보면 데이터가 네 개의 뚜렷한 영역으로 구분된 것을 확인할 수 있습니다.
   - 정답 라벨이 없었음에도 불구하고, 알고리즘이 소득과 지출의 상관관계를 분석하여 유사한 성향의 고객들을 성공적으로 묶어냈습니다.

## 6. 실무 활용 사례
- **마케팅 타겟팅 (Customer Segmentation):** 고객을 구매 성향별로 군집화하여, 'VIP 그룹'에게는 프리미엄 혜택을, '이탈 위험 그룹'에게는 강력한 할인 쿠폰을 보내는 맞춤형 CRM 전략을 수립합니다.
- **이미지 압축 (Color Quantization):** 이미지의 수백만 가지 색상 중 유사한 색상끼리 $K$개의 그룹으로 묶어 대표색으로 대체함으로써 이미지 용량을 획기적으로 줄입니다.
- **이상치 탐지 (Anomaly Detection):** 대부분의 데이터가 특정 군집에 밀집해 있을 때, 어떤 군집의 중심점과도 거리가 매우 먼 데이터를 '이상치'로 판단하여 신용카드 부정 결제(Fraud Detection)를 탐지합니다.

## 7. 자주 하는 실수 및 주의사항
- **스케일링 생략:** K-Means는 **유클리드 거리**를 사용합니다. '연봉(단위: 만원)'과 '나이(단위: 세)'를 그대로 넣으면, 숫자의 범위가 훨씬 큰 연봉 데이터가 거리 계산을 지배하게 됩니다. **반드시 `StandardScaler` 등을 사용하여 모든 특성의 단위를 맞춰야 합니다.**
- **K값의 맹신:** 엘보우 방법이 항상 명확한 '팔꿈치'를 보여주지는 않습니다. 이 경우 비즈니스 목적(예: 마케팅 팀의 운영 가능 인원)이나 실무적인 제약 조건을 고려하여 $K$를 결정해야 합니다.
- **초기값 민감도:** 처음에 중심점을 어디에 잡느냐에 따라 최종 군집 결과가 달라질 수 있습니다. `scikit-learn`의 `n_init` 옵션은 여러 번의 초기화를 시도하여 가장 좋은 결과를 선택함으로써 이 문제를 완화합니다.

## 8. 핵심 요약
- **비지도학습**은 정답 없이 데이터 자체의 패턴과 구조를 찾아내는 학습법이다.
- **K-Means**는 중심점(Centroid)과 데이터 간의 거리를 최소화하며 그룹을 묶는 알고리즘이다.
- **작동 순서:** 중심점 무작위 배치 $\rightarrow$ 가까운 중심점에 할당 $\rightarrow$ 중심점 위치 업데이트 $\rightarrow$ 반복.
- **엘보우 방법**은 관성(Inertia)의 감소 폭이 급격히 줄어드는 지점을 찾아 최적의 $K$를 결정하는 기법이다.
- **주의사항:** 거리 기반 알고리즘이므로 반드시 **데이터 스케일링**을 수행해야 한다.
