# 9. 비지도학습과 군집화

## 이번 장에서 배우는 내용

지금까지 우리는 정답(Label)이 주어진 데이터를 통해 학습하는 '지도학습'에 대해 배웠습니다. 하지만 현실 세계의 데이터 중에는 정답이 없는 경우가 훨씬 많습니다. 이번 장에서는 정답지 없이 데이터 스스로의 패턴을 찾아내는 **비지도학습(Unsupervised Learning)**의 개념을 이해하고, 그 중 가장 대표적인 알고리즘인 **K-Means 군집화(Clustering)**를 통해 데이터를 의미 있는 그룹으로 묶는 방법을 학습합니다.

---

## 정답 없는 학습: 비지도학습의 개념

### 📖 실생활 비유: 정답지가 있는 문제집 vs 스스로 관찰하는 탐험가
지도학습이 선생님이 옆에서 "이 사진은 고양이야", "이 사진은 강아지야"라고 알려주는 **'정답지가 있는 문제집'**을 푸는 과정이라면, 비지도학습은 아무런 정보 없이 낯선 숲에 들어간 **'탐험가'**와 같습니다.

탐험가는 누가 무엇이라고 알려주지 않아도, "이 나무들은 잎이 넓고 키가 크네", "저 나무들은 잎이 뾰족하고 키가 작네"라며 스스로 공통점과 차이점을 발견해 나무들을 분류하기 시작합니다. 여기서 중요한 점은 탐험가가 이 나무들의 정확한 '이름(정답)'은 모르지만, **'서로 비슷하게 생겼다'**는 패턴을 찾아냈다는 것입니다.

### 💡 직관적으로 이해하기
비지도학습은 데이터 속에 숨겨진 **'내재적 구조'**를 찾아내는 작업입니다. 정답이 없기 때문에 "이것은 무엇이다"라고 정의 내리는 대신, "이것들은 서로 비슷하다" 혹은 "이것은 다른 것들과 아주 다르다"라는 관계를 찾아내는 것이 핵심입니다.

### 🛠️ 기술 설명
비지도학습의 주요 목적은 크게 세 가지로 나뉩니다.
1. **군집화(Clustering):** 유사한 특성을 가진 데이터끼리 그룹으로 묶는 것 (예: 고객 세그먼테이션)
2. **차원 축소(Dimension Reduction):** 핵심 특징만 남기고 데이터의 복잡도를 줄이는 것 (예: PCA)
3. **연관 규칙 학습(Association Rule Learning):** 데이터 간의 흥미로운 관계를 찾는 것 (예: "맥주를 사는 사람은 기저귀도 함께 산다")

## 끼리끼리 묶기: K-Means 군집화의 원리

### 📖 실생활 비유: 마을의 중심지 정하기
어느 넓은 평원에 흩어져 사는 주민들이 있다고 가정해 봅시다. 이 주민들을 효율적으로 관리하기 위해 $K$개의 '마을 회관'을 지으려고 합니다.

1. 처음에는 무작위로 $K$개의 장소에 회관을 짓습니다.
2. 주민들은 **자신과 가장 가까운 회관**으로 가서 등록합니다.
3. 회관 관리자는 등록한 주민들의 위치를 모두 고려해, **주민들의 정중앙 지점**으로 회관을 옮깁니다.
4. 회관 위치가 바뀌었으니, 주민들은 다시 **가장 가까운 회관**을 찾아 이동합니다.
5. 더 이상 회관의 위치가 변하지 않을 때까지 이 과정을 반복합니다.

결국, 주민들은 자연스럽게 서로 가까운 사람들끼리 그룹을 이루게 됩니다.

### 💡 직관적으로 이해하기
K-Means는 **"가까운 것들끼리는 같은 그룹일 확률이 높다"**라는 단순한 아이디어에서 출발합니다. 여기서 '가깝다'는 기준은 수학적으로 **유클리드 거리(Euclidean Distance)**, 즉 두 점 사이의 직선거리를 의미합니다.

### 🛠️ 기술 설명: K-Means 작동 프로세스
K-Means 알고리즘은 다음과 같은 반복적인 최적화 과정을 거칩니다.

1. **중심점 초기화:** 데이터 공간에 임의로 $K$개의 중심점(Centroid)을 배치합니다.
2. **군집 배정:** 모든 데이터 포인트에 대해 가장 가까운 중심점을 찾아 해당 군집으로 할당합니다.
3. **중심점 업데이트:** 각 군집에 속한 데이터들의 **산술 평균 위치(각 데이터의 좌표값을 모두 더해 데이터 개수로 나눈 지점)**를 계산하여 중심점을 그 위치로 이동시킵니다.
4. **반복:** 중심점의 위치가 더 이상 변하지 않거나, 설정한 최대 반복 횟수에 도달할 때까지 2~3단계를 반복합니다.

## 파이썬으로 구현하는 K-Means 군집화

이제 Scikit-learn 라이브러리를 사용하여 실제로 데이터를 군집화해 보겠습니다.

### 💻 파이썬 코드 실습

```python
import numpy as np
import matplotlib.pyplot as plt
from sklearn.cluster import KMeans
from sklearn.datasets import make_blobs
from sklearn.preprocessing import StandardScaler

# 1. 가상의 데이터 생성 (4개의 그룹이 섞여 있는 데이터)
X, _ = make_blobs(n_samples=300, centers=4, cluster_std=0.60, random_state=42)

# 2. 데이터 전처리: 스케일링 (K-Means는 거리 기반이므로 필수!)
scaler = StandardScaler()
X_scaled = scaler.fit_transform(X)

# 3. K-Means 모델 생성 및 학습
# n_clusters: 묶고 싶은 그룹의 수(K)
k = 4
kmeans = KMeans(n_clusters=k, init='k-means++', random_state=42)
y_kmeans = kmeans.fit_predict(X_scaled) # 학습과 동시에 군집 예측

# 4. 결과 시각화
plt.figure(figsize=(10, 6))

# 군집별 데이터 포인트 출력
plt.scatter(X_scaled[:, 0], X_scaled[:, 1], c=y_kmeans, s=50, cmap='viridis')

# 중심점(Centroids) 출력
centers = kmeans.cluster_centers_
plt.scatter(centers[:, 0], centers[:, 1], c='red', s=200, alpha=0.75, marker='X', label='Centroids')

plt.title(f"K-Means Clustering (K={k})")
plt.xlabel("Feature 1 (Scaled)")
plt.ylabel("Feature 2 (Scaled)")
plt.legend()
plt.show()

print(f"최종 중심점 좌표:\n{centers}")
```

### 📈 실행 결과 해설
- **시각화 결과:** 데이터들이 4개의 색상으로 명확하게 구분되어 나타납니다. 붉은색 'X' 표시가 각 그룹의 중심점(Centroid)입니다.
- **`fit_predict()`:** 모델이 데이터의 패턴을 학습하고, 동시에 각 데이터가 어떤 군집(0, 1, 2, 3)에 속하는지 결과를 반환합니다.
- **`cluster_centers_`:** 학습이 완료된 후 결정된 최종 중심점의 좌표입니다. 이 좌표는 해당 그룹의 '대표값'이라고 볼 수 있습니다.

## 최적의 K값 찾기: 엘보우 방법(Elbow Method)

현실에서는 데이터를 몇 개의 그룹($K$)으로 나눠야 할지 미리 알 수 없습니다. 이때 사용하는 객관적인 기준이 **엘보우 방법**입니다.

### 💡 직관적으로 이해하기
그룹의 수($K$)를 늘릴수록, 각 데이터와 중심점 사이의 거리는 점점 짧아집니다. 하지만 어느 순간부터는 $K$를 늘려도 거리의 감소 폭이 매우 작아지는 지점이 옵니다. 마치 팔을 굽혔을 때 꺾이는 부분인 **'팔꿈치(Elbow)'** 모양과 비슷하다고 하여 엘보우 방법이라 부릅니다.

### 🛠️ 기술 설명 및 구현
- **SSE (Sum of Squared Errors) / Inertia:** 각 데이터 포인트에서 자신이 속한 군집의 중심점까지의 거리의 제곱 합입니다. Scikit-learn에서는 이를 `inertia_`라는 속성으로 제공하며, 이 값이 작을수록 군집 내부의 응집도가 높다는 뜻입니다.
- **판단 기준:** $K$값을 1부터 차례대로 늘리며 `inertia_`를 측정합니다. 값이 급격하게 줄어들다가 완만해지는 **그 꺾임 지점(Elbow Point)**이 가장 효율적인 $K$값입니다.

#### 💻 엘보우 방법 구현 코드

```python
# K값을 1부터 10까지 변화시키며 Inertia 값 측정
inertia_list = []
K_range = range(1, 11)

for k in K_range:
    kmeans = KMeans(n_clusters=k, init='k-means++', random_state=42)
    kmeans.fit(X_scaled)
    inertia_list.append(kmeans.inertia_) # SSE 값 저장

# 엘보우 그래프 시각화
plt.figure(figsize=(8, 5))
plt.plot(K_range, inertia_list, marker='o')
plt.title("Elbow Method for Optimal K")
plt.xlabel("Number of Clusters (K)")
plt.ylabel("Inertia (SSE)")
plt.xticks(K_range)
plt.grid(True)
plt.show()
```

**결과 해석:** 그래프를 보면 $K=4$ 지점에서 기울기가 급격히 완만해지는 것을 확인할 수 있습니다. 따라서 이 데이터셋의 최적의 $K$값은 4라고 판단할 수 있습니다.

> **주의:** $K$를 너무 작게 잡으면 서로 다른 특성의 데이터가 한 그룹에 묶이고, 너무 크게 잡으면 의미 없는 세분화(과적합과 유사한 상태)가 일어납니다.

## 비지도학습의 실무 활용 사례

K-Means는 정답이 없는 상태에서 인사이트를 뽑아내야 하는 비즈니스 환경에서 매우 강력합니다.

1. **고객 세그먼테이션 (Customer Segmentation):** 
   - 구매 금액, 방문 빈도, 체류 시간 등의 데이터를 기반으로 고객을 'VIP', '잠재 충성 고객', '이탈 위험 고객' 등으로 자동 분류하여 맞춤형 마케팅 전략을 세웁니다.
2. **이상치 탐지 (Anomaly Detection):**
   - 대부분의 데이터가 특정 군집에 모여 있는데, 어떤 군집의 중심점에서도 매우 멀리 떨어져 있는 데이터가 있다면 이를 '이상치(이상 거래, 장비 고장 등)'로 판단할 수 있습니다.
3. **이미지 압축 (Color Quantization):**
   - 수백만 가지의 색상 값을 K-Means로 묶어 대표 색상 $K$개로 단순화함으로써 이미지 용량을 줄이는 기술에 활용됩니다.

## 초보자가 자주 하는 실수와 해결책

### ⚠️ 거리 기반 알고리즘에서 스케일링을 생략하는 경우
**실수:** 키(cm)와 몸무게(kg) 데이터를 그대로 넣고 군집화를 수행합니다.
**문제:** 키는 150~190 사이지만, 몸무게는 40~120 사이입니다. 숫자의 범위(Scale)가 다르면, 범위가 큰 특성이 거리 계산에 압도적인 영향을 주어 결과가 왜곡됩니다.
**해결:** 반드시 `StandardScaler` 등을 사용하여 모든 특성의 평균을 0, 분산을 1로 맞춰주어야 합니다.

### ⚠️ 초기 중심점 위치에 따른 결과 변동
**실수:** 초기 중심점을 완전히 랜덤하게 잡았을 때, 실행할 때마다 결과가 달라지는 현상이 발생합니다.
**해결:** Scikit-learn의 `KMeans`는 기본적으로 `init='k-means++'` 옵션을 사용합니다. 이는 중심점들을 서로 최대한 멀리 떨어뜨려 배치하는 스마트한 초기화 전략으로, 학습 속도를 높이고 결과의 일관성을 보장합니다.

### ⚠️ 군집의 모양이 구형(Spherical)이 아닐 때
**한계:** K-Means는 거리를 기준으로 묶기 때문에, 결과적으로 원형(구형) 모양의 군집을 만드는 경향이 있습니다. 만약 데이터가 초승달 모양이나 길쭉한 형태로 분포되어 있다면 K-Means로는 제대로 분류할 수 없습니다. (이 경우 DBSCAN 같은 다른 알고리즘이 필요합니다.)

## 핵심 요약
- **비지도학습**은 정답(Label) 없이 데이터의 내재적 패턴과 구조를 찾는 학습 방식이다.
- **K-Means**는 중심점과 데이터 사이의 거리를 최소화하여 $K$개의 그룹으로 묶는 알고리즘이다.
- **엘보우 방법**은 SSE(Inertia)의 감소 폭이 완만해지는 지점을 찾아 최적의 $K$값을 결정하는 방법이다.
- 거리 기반 알고리즘이므로 **특성 스케일링(Feature Scaling)**이 필수적이다.

## 확인 문제
1. 지도학습과 비지도학습의 가장 결정적인 차이점은 무엇인가요?
2. K-Means 알고리즘에서 중심점을 업데이트하는 기준은 무엇인가요?
3. 왜 K-Means를 사용할 때 `StandardScaler`를 사용하는 것이 권장되나요?

## 정답 및 해설
1. **정답:** 학습 데이터에 '정답(Label)'이 포함되어 있느냐의 여부입니다. 지도학습은 정답을 통해 예측 모델을 만들고, 비지도학습은 정답 없이 데이터의 구조나 패턴을 발견합니다.
2. **정답:** 해당 군집으로 배정된 모든 데이터 포인트들의 산술 평균 위치(좌표값의 합을 개수로 나눈 지점)로 중심점을 이동시킵니다.
3. **정답:** K-Means는 유클리드 거리를 기반으로 군집을 나누기 때문에, 특성 간의 단위(Scale) 차이가 크면 값이 큰 특성이 결과에 지배적인 영향을 미쳐 왜곡이 발생하기 때문입니다.
