# 2. 파이썬 머신러닝 개발 환경 구축

## 이번 장에서 배우는 내용

머신러닝은 단순히 코드를 작성하는 것이 아니라, 데이터를 관찰하고 가설을 세우며 실험하는 과정의 반복입니다. 따라서 일반적인 소프트웨어 개발과는 다른 '실험실' 같은 환경이 필요합니다. 이번 장에서는 머신러닝 학습을 위한 최적의 디지털 실험실을 구축하는 방법을 배웁니다.

- 머신러닝 개발 환경이 일반 개발 환경과 어떻게 다른지 이해합니다.
- 파이썬을 설치하고, 프로젝트 간의 충돌을 방지하는 '가상환경'과 '커널'의 개념을 익힙니다.
- 데이터 과학자의 필수 도구인 '주피터 노트북(Jupyter Notebook)'과 'VS Code'를 설치하고 활용법을 배웁니다.

---

## 실생활 비유: 레스토랑 주방 vs 테스트 키친

우리가 일반적인 앱이나 프로그램을 만드는 것은 **'레스토랑의 주방'**에서 요리하는 것과 비슷합니다. 정해진 레시피(설계도)에 따라 재료를 준비하고 요리를 완성해 손님에게 내놓으면 끝납니다. 한 번 완성된 요리는 맛이 변하지 않으며, 정해진 순서대로 정확히 작동하는 것이 가장 중요합니다.

반면, 머신러닝 개발은 **'테스트 키친(실험실)'**에서 새로운 레시피를 개발하는 과정과 같습니다. 소금을 한 꼬집 넣어보고 맛을 본 뒤, "음, 조금 더 짜야겠는데?"라고 생각하며 다시 간을 맞춥니다. 불의 세기를 조금 높여보고 다시 맛을 보는 과정을 수백 번 반복하며 최적의 맛(모델의 성능)을 찾아냅니다.

머신러닝 환경은 바로 이 **'맛을 보며 수정하는 과정'**을 효율적으로 만들어주는 도구들의 집합입니다.

---

## 개념 설명: 왜 '대화형 환경'이 필요한가?

전통적인 프로그래밍 방식은 **스크립트(Script) 방식**입니다. 메모장에 코드를 모두 작성한 뒤, 실행 버튼을 눌러 처음부터 끝까지 한 번에 결과를 확인합니다. 만약 중간에 오타가 있거나 데이터가 예상과 다르다면, 다시 수정하고 처음부터 다시 실행해야 합니다.

하지만 머신러닝은 데이터의 형태를 확인하고, 그래프를 그려보고, 모델의 파라미터를 조금씩 수정하는 작업이 핵심입니다. 이때 필요한 것이 **대화형(Interactive) 방식**입니다.

- **스크립트 방식:** "모든 재료를 넣고 냄비를 닫은 뒤, 30분 후에 뚜껑을 열어 맛을 본다." $\rightarrow$ 맛이 없으면 처음부터 다시 요리해야 함.
- **대화형 방식:** "재료를 하나 넣고 맛을 본다 $\rightarrow$ 다음 재료를 넣고 또 맛을 본다." $\rightarrow$ 어느 단계에서 문제가 생겼는지 즉시 알 수 있고, 이전 단계의 결과를 유지한 채 다음 실험을 이어갈 수 있음.

특히 머신러닝에서는 **'상태 유지(State)'**라는 개념이 매우 중요합니다. 수 기가바이트(GB)에 달하는 대용량 데이터를 읽어오는 데 5분이 걸린다고 가정해 봅시다. 스크립트 방식은 코드를 수정할 때마다 매번 5분을 기다려 데이터를 다시 읽어야 하지만, 대화형 환경에서는 **한 번 로드한 데이터를 메모리에 올려둔 상태로 유지**할 수 있습니다. 덕분에 데이터는 그대로 둔 채, 분석 코드만 수정해 즉시 결과를 확인할 수 있어 실험 속도가 비약적으로 빨라집니다.

## 기술 설명

### 1. 파이썬 설치: 기초 공사

머신러닝의 기본 언어인 파이썬을 먼저 설치해야 합니다. 

- **설치 방법:** [python.org](https://www.python.org/) 공식 홈페이지에서 최신 안정 버전을 다운로드하여 설치합니다.
- **⚠️ 매우 중요한 주의사항:** 설치 창이 뜨면 하단에 있는 **`Add Python to PATH` 체크박스를 반드시 선택**하세요. 이 설정을 하지 않으면 터미널(CMD)에서 `python`이나 `pip` 명령어를 인식하지 못해 설치 후 실행 단계에서 오류가 발생합니다.

### 2. 패키지 관리자와 가상환경

머신러닝을 하려면 파이썬과 함께 수학 계산을 돕는 `NumPy`, 데이터 분석을 돕는 `Pandas`, 머신러닝 알고리즘이 구현된 `scikit-learn` 같은 **라이브러리(패키지)**가 필요합니다.

#### pip: 라이브러리 배달 서비스
`pip`는 파이썬의 패키지 관리자로, 인터넷에 공개된 수많은 라이브러리를 내 컴퓨터에 간단하게 설치해 주는 도구입니다. 터미널에서 `pip install 라이브러리이름`이라고 입력하면 자동으로 다운로드되어 설치됩니다.

#### 가상환경(Virtual Environment)과 커널(Kernel)
프로젝트 A에서는 `scikit-learn` 1.0 버전이 필요한데, 프로젝트 B에서는 2.0 버전이 필요할 수 있습니다. 파이썬은 기본적으로 하나의 버전을 설치하므로, 두 프로젝트를 동시에 진행하면 버전 충돌이 일어나 프로그램이 망가질 수 있습니다.

이를 해결하기 위해 **가상환경**을 사용합니다. 가상환경은 내 컴퓨터 안에 **'독립된 작은 방'**을 만드는 것과 같습니다. 
- **방 A:** 파이썬 3.9 + scikit-learn 1.0
- **방 B:** 파이썬 3.11 + scikit-learn 2.0

실제로 `python -m venv ml_env`라는 명령어를 실행하면, 현재 작업 중인 폴더에 **`ml_env`라는 이름의 실제 폴더**가 생성됩니다. 이 폴더가 바로 '방'의 실체이며, 전용 파이썬 실행 파일과 라이브러리들이 물리적으로 저장됩니다.

여기서 **커널(Kernel)**이라는 개념이 등장합니다. 가상환경이 라이브러리가 저장된 '방'이라면, 커널은 그 방 안에서 **사용자가 입력한 코드를 실제로 계산하여 결과를 돌려주는 '백엔드 프로세스(엔진)'**입니다. 우리가 가상환경을 만들고 커널을 등록하는 이유는, 주피터 노트북 같은 도구에게 "시스템 기본 엔진 말고, 내가 만든 이 방의 엔진(커널)을 사용해줘!"라고 지정하기 위해서입니다.

### 3. 주피터 노트북: 데이터 과학자의 스케치북

주피터 노트북은 '대화형 방식'을 구현한 대표적인 도구로, **'셀(Cell)'** 단위로 구성되어 있습니다.

- **코드 셀(Code Cell):** 파이썬 코드를 작성하고 실행하는 곳입니다. 결과가 셀 바로 아래에 즉시 출력됩니다.
- **마크다운 셀(Markdown Cell):** 메모, 설명, 수식, 이미지 등을 넣는 곳입니다. 

이 덕분에 주피터 노트북은 단순한 코드 파일이 아니라, [가설 설정 $\rightarrow$ 코드 실행 $\rightarrow$ 결과 확인 $\rightarrow$ 해석 및 결론]의 흐름을 담는 **'분석 리포트'**가 됩니다.

### 4. VS Code: 현대적인 통합 개발 환경(IDE)

최근의 데이터 과학자들은 주피터 노트북의 편리함과 전문 개발 도구의 강력함을 모두 누리기 위해 **VS Code(Visual Studio Code)**를 사용합니다.

- **통합 환경:** 가상환경 관리, Git 버전 관리, 코드 자동 완성 기능을 모두 제공합니다.
- **주피터 확장 프로그램:** VS Code에서 'Jupyter' 확장 프로그램을 설치하면, 웹 브라우저를 켜지 않고도 `.ipynb` 파일을 그대로 열어 코드 셀을 실행할 수 있습니다.
- **현대적인 흐름:** `실험(주피터 노트북) $\rightarrow$ 정제(파이썬 스크립트 파일 .py) $\rightarrow$ 배포`로 이어지는 전체 개발 흐름을 하나의 도구에서 처리할 수 있습니다.

## 파이썬 코드 실습

이제 실제로 머신러닝 실험실을 구축해 보겠습니다. (Windows 기준)

### Step 1: 가상환경 생성 및 활성화
터미널(명령 프롬프트)을 열고 다음 명령어를 입력하세요.

```bash
# 1. 머신러닝 프로젝트 폴더 생성 및 이동
mkdir ml_study
cd ml_study

# 2. 'ml_env'라는 이름의 가상환경 생성
python -m venv ml_env

# 3. 가상환경 활성화
# Windows:
ml_env\Scripts\activate
# macOS/Linux:
source ml_env/bin/activate
```

### Step 2: 필수 라이브러리 및 커널 등록
가상환경이 활성화된 상태(`(ml_env)` 표시가 뜬 상태)에서 라이브러리를 설치하고, 주피터 노트북이 이 환경을 인식할 수 있도록 **커널을 등록**해야 합니다.

```bash
# 최신 버전의 pip로 업데이트
python -m pip install --upgrade pip

# 머신러닝 필수 라이브러리 및 주피터 설치
pip install numpy pandas matplotlib scikit-learn jupyter

# [중요] 가상환경을 주피터 노트북의 커널로 등록하기 위한 패키지 설치
pip install ipykernel

# 가상환경을 'ML Environment'라는 이름의 커널로 등록
python -m ipykernel install --user --name ml_env --display-name "ML Environment"
```

### Step 3: VS Code 설정 및 실행
1. **VS Code 설치:** [code.visualstudio.com](https://code.visualstudio.com/)에서 설치합니다.
2. **확장 프로그램 설치:** 왼쪽 Extensions(Ctrl+Shift+X)에서 `Python`과 `Jupyter`를 검색하여 설치합니다.
3. **파일 생성:** `ml_study` 폴더를 열고, `test.ipynb` 파일을 생성합니다.
4. **커널 선택:** 오른쪽 상단의 `Select Kernel` $\rightarrow$ `Python Environments` $\rightarrow$ 우리가 등록한 **`ML Environment` (또는 ml_env)**를 선택합니다.

**[노트북 셀에 입력할 코드]**
```python
import sklearn
import pandas as pd
import numpy as np

print(f"scikit-learn 버전: {sklearn.__version__}")
print(f"Pandas 버전: {pd.__version__}")
print(f"NumPy 버전: {np.__version__}")
print("✅ 머신러닝 환경 구축 완료!")
```

## 실행 결과 해설

코드를 실행하면 다음과 유사한 결과가 출력됩니다.

```text
scikit-learn 버전: 1.3.0
Pandas 버전: 2.1.0
NumPy 버전: 1.26.0
✅ 머신러닝 환경 구축 완료!
```

- **버전 숫자:** 설치된 라이브러리의 버전입니다. 머신러닝 모델은 버전에 따라 결과가 미세하게 달라질 수 있어, 협업 시 이 정보를 공유하는 것이 중요합니다.
- **성공 메시지:** `ImportError` 없이 메시지가 출력되었다면, 파이썬이 가상환경 내의 커널을 통해 라이브러리들을 정확히 찾아내어 로드했다는 뜻입니다.

## 실무 활용 사례

실무 데이터 과학자들은 주피터 노트북과 VS Code를 다음과 같이 조합하여 사용합니다. 
1. **데이터 탐색(EDA):** VS Code 내의 `.ipynb` 파일에서 데이터를 불러와 결측치를 확인하고 시각화하며 가설을 세웁니다.
2. **실험 기록:** 마크다운 셀을 활용해 "왜 이 모델을 선택했는지", "파라미터를 바꿨을 때 성능이 어떻게 변했는지"를 기록하여 나중에 다시 봐도 이해할 수 있는 리포트로 만듭니다.
3. **모듈화:** 실험이 끝나고 성능이 검증된 코드는 `.py` 파일로 옮겨 실제 서비스에 적용할 수 있는 형태로 정제합니다.
4. **협업:** 완성된 노트북 파일을 팀원에게 공유하여, 팀원이 동일한 가상환경(커널) 설정만 한다면 내 실험 결과를 100% 재현할 수 있게 합니다.

## 자주 하는 실수

**❌ 파이썬 설치 시 'Add Python to PATH'를 체크하지 않은 경우**
- **증상:** 터미널에 `python`이라고 입력하면 "명령어를 찾을 수 없습니다"라는 오류가 발생합니다.
- **해결:** 파이썬 설치 프로그램을 다시 실행하여 'Modify'를 선택하고 PATH 추가 옵션을 체크하거나, 삭제 후 재설치하세요.

**❌ 가상환경을 활성화하지 않고 `pip install`을 하는 경우**
- **증상:** 분명히 설치했는데 주피터 노트북이나 VS Code에서 `ModuleNotFoundError`가 발생합니다.
- **원인:** 가상환경(`ml_env`)이 아닌 시스템 전체 파이썬 영역에 설치했기 때문입니다.
- **해결:** 터미널 프롬프트 앞에 `(ml_env)` 표시가 있는지 확인하고, 없다면 `activate` 명령어를 먼저 실행하세요.

**❌ 가상환경은 만들었지만 커널 등록(`ipykernel`)을 하지 않은 경우**
- **증상:** VS Code 커널 선택 목록에 내가 만든 가상환경이 나타나지 않거나, 선택해도 라이브러리를 인식하지 못합니다.
- **원인:** 가상환경(폴더)만 만들었을 뿐, 주피터 노트북이 사용할 수 있는 '엔진(커널)'으로 등록하지 않았기 때문입니다.
- **해결:** `pip install ipykernel` 설치 후 `python -m ipykernel install ...` 명령어를 통해 커널을 명시적으로 등록하세요.

## 핵심 요약

- **머신러닝 환경**은 결과물을 한 번에 내놓는 '제작 환경'이 아니라, 조금씩 수정하며 확인하는 **'대화형 실험 환경'**이다. 특히 메모리에 데이터를 유지하는 '상태 유지' 기능이 핵심이다.
- **가상환경**은 프로젝트별로 라이브러리 버전 충돌을 막기 위한 **독립된 공간(물리적 폴더)**이며, 그 안에서 코드를 실제로 계산해 결과를 돌려주는 백엔드 프로세스를 **커널**이라고 한다.
- **주피터 노트북**은 [가설 $\rightarrow$ 코드 $\rightarrow$ 결과 $\rightarrow$ 해석]의 흐름을 담는 **분석 리포트** 도구이며, **VS Code**는 이를 포함해 전문적인 개발 기능까지 제공하는 **통합 환경**이다.

## 정답 및 해설

1. **정답:** 스크립트 방식은 전체 코드를 한 번에 실행하여 결과를 확인하지만, 대화형 방식은 코드를 부분적으로 실행하고 그 결과를 즉시 확인하며 다음 단계를 진행할 수 있다는 점입니다.
2. **정답:** 한 번 로드한 대용량 데이터를 메모리에 유지할 수 있어, 코드를 수정할 때마다 데이터를 다시 읽어오는 시간을 낭비하지 않고 즉시 실험을 반복할 수 있기 때문입니다.
3. **정답:** 운영체제가 파이썬 실행 파일의 경로를 알지 못하므로, 터미널이나 명령 프롬프트에서 `python` 또는 `pip` 명령어를 사용할 수 없게 됩니다.
4. **정답:** 가상환경이 라이브러리들이 격리되어 저장된 '독립된 방'이라면, 커널은 그 방 안에서 실제로 파이썬 코드를 계산하고 결과를 돌려주는 '엔진(백엔드 프로세스)'과 같습니다.
5. **정답:** `ipykernel` 패키지를 설치한 후, `python -m ipykernel install` 명령어를 통해 해당 가상환경을 주피터 커널 목록에 등록해야 합니다.
