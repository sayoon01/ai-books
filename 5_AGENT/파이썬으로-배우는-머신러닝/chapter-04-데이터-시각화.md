## 실생활 비유: 엑셀 시트와 사진의 차이

여러분에게 1,000명의 키와 몸무게가 적힌 엑셀 시트가 있다고 가정해 봅시다. 이 표를 아무리 뚫어지게 쳐다봐도 "키가 커질수록 몸무게도 늘어나는 경향이 있구나"라는 것을 단번에 깨닫기는 어렵습니다. 한 줄 한 줄 읽으며 머릿속으로 계산해야 하기 때문입니다.

하지만 이 데이터를 **산점도(Scatter Plot)**라는 그래프로 그리는 순간, 상황은 완전히 달라집니다. 수천 개의 점이 오른쪽 위를 향해 쭉 뻗어 있는 '모양'을 보는 순간, 우리는 단 1초 만에 두 변수 사이의 관계를 파악할 수 있습니다.

**데이터 시각화는 수천 개의 숫자라는 '텍스트'를 하나의 '사진'으로 바꾸는 과정입니다.** 사진을 보면 어디에 이상한 점이 있는지, 전체적인 분위기가 어떤지 즉각적으로 알 수 있듯이, 시각화는 데이터의 '얼굴'을 확인하는 작업입니다.

## 데이터 시각화의 필요성: 왜 그래프를 그려야 하는가?

우리는 이전 장에서 Pandas의 `.head()`로 상위 데이터를 확인하고, `.describe()`로 평균과 표준편차 같은 통계량을 확인했습니다. 하지만 숫자만으로는 알 수 없는 정보들이 많습니다.

예를 들어, 평균값이 50인 데이터셋이 두 개 있다고 합시다.
- **데이터 A:** 모든 값이 45~55 사이에 밀집해 있음.
- **데이터 B:** 값들이 0과 100에 극단적으로 나뉘어 있음.

두 데이터의 평균은 모두 50이지만, 성격은 완전히 다릅니다. 만약 이 데이터를 그대로 머신러닝 모델에 넣는다면 모델은 매우 혼란스러워할 것입니다. 이처럼 **데이터의 분포, 이상치(Outlier), 변수 간의 관계**는 오직 시각화를 통해서만 직관적으로 파악할 수 있습니다. 이것이 바로 머신러닝 모델을 설계하기 전 반드시 거쳐야 하는 **탐색적 데이터 분석(EDA, Exploratory Data Analysis)**의 핵심입니다.

## Matplotlib: 데이터 시각화의 뼈대 만들기

### 1. 개념 설명: 도화지와 그래프
Matplotlib은 파이썬 시각화의 가장 기초가 되는 라이브러리입니다. 모든 시각화 도구의 '뼈대'라고 생각하면 됩니다. Matplotlib의 구조를 이해하려면 **Figure**와 **Axes**의 관계를 명확히 알아야 합니다.

- **Figure (도화지):** 그래프가 그려질 전체 영역입니다. 커다란 종이 한 장이라고 생각하세요. 하나의 Figure 안에 여러 개의 그래프를 배치할 수 있습니다.
- **Axes (그래프 영역):** 도화지 위에 그려지는 '개별 그래프'입니다. 좌표축(x축, y축)이 있고 실제 데이터가 그려지는 공간입니다.

우리가 흔히 사용하는 `plt.subplots()` 함수는 **"도화지(Figure)를 준비하고, 그 안에 그래프 영역(Axes)을 만들어라"**라는 명령입니다. 이 함수는 `fig`와 `ax`라는 두 개의 객체를 동시에 반환하며, 우리는 `ax`라는 개별 그래프 영역에 구체적인 그림을 그리게 됩니다.

### 2. 기술 설명 및 실습
가장 기본이 되는 선 그래프(`plot`)와 산점도(`scatter`)를 그려보겠습니다. 특히 한국어 환경에서는 폰트 깨짐 현상이 발생하므로, 한글 설정 코드를 반드시 포함해야 합니다.

```python
import matplotlib.pyplot as plt
import numpy as np

# 한글 폰트 설정 (Windows 기준, Mac은 'AppleGothic')
plt.rcParams['font.family'] = 'Malgun Gothic'
plt.rcParams['axes.unicode_minus'] = False

# 1. 데이터 준비
x = np.arange(0, 10, 1) # 0부터 9까지
y = [0, 1, 4, 9, 16, 25, 36, 49, 64, 81] # x의 제곱값

# 2. Figure(도화지)와 Axes(그래프 영역) 생성
fig, ax = plt.subplots(figsize=(8, 5))

# 3. Axes(ax)라는 그래프 영역에 그림 그리기
ax.plot(x, y, color='blue', marker='o', label='제곱 값') # 선 그래프
ax.scatter(x, y, color='red', s=30) # 산점도 (점만 찍기)

# 4. 세부 설정
ax.set_title('x와 y의 관계 시각화', fontsize=15)
ax.set_xlabel('입력 값 (x)')
ax.set_ylabel('결과 값 (y)')
ax.legend() 
ax.grid(True) 

plt.show()
```

**[실행 결과 해설]**
- 파란색 선과 빨간색 점이 함께 표시됩니다. 
- `plot`은 데이터 포인트들을 선으로 연결하여 '흐름'을 보여주고, `scatter`는 각 데이터의 '위치'를 보여줍니다.
- 결과 그래프를 통해 $y = x^2$라는 곡선 패턴이 명확하게 드러나는 것을 확인할 수 있습니다.

## Seaborn: 더 쉽고 아름답게 데이터 분석하기

### 1. 개념 설명: Matplotlib의 업그레이드 버전
Matplotlib이 세밀한 조정이 가능한 '수동 도구'라면, Seaborn은 복잡한 설정을 미리 최적화해 둔 '자동 도구'입니다. 특히 Pandas의 DataFrame과 호환성이 매우 높으며, 통계 분석에 특화된 그래프를 단 한 줄의 코드로 그려낼 수 있습니다.

### 2. 주요 그래프 실습 및 해석
입문자가 반드시 알아야 할 Seaborn의 핵심 그래프들을 하나씩 살펴보겠습니다.

#### ① 히스토그램 (`histplot`): 데이터의 분포 확인
데이터가 어디에 많이 몰려 있는지, 어떤 모양으로 퍼져 있는지를 확인합니다.

```python
import seaborn as sns
import matplotlib.pyplot as plt

iris = sns.load_dataset('iris')

plt.figure(figsize=(8, 5))
sns.histplot(data=iris, x='sepal_length', kde=True, color='skyblue')
plt.title('꽃받침 길이 분포')
plt.show()
```
- **해석:** `kde=True` 옵션으로 그려진 부드러운 곡선은 데이터의 밀도를 나타냅니다. 이를 통해 데이터가 정규분포 형태인지, 혹은 한쪽으로 치우쳤는지(Skewness) 확인할 수 있습니다.

#### ② 박스플롯 (`boxplot`): 이상치 확인
데이터의 통계적 요약(최솟값, 1사분위수, 중앙값, 3사분위수, 최댓값)을 한눈에 보여줍니다.

```python
plt.figure(figsize=(8, 5))
sns.boxplot(data=iris, x='species', y='sepal_length', palette='Set2')
plt.title('종별 꽃받침 길이 비교')
plt.show()
```
- **해석:** 박스 위아래로 뻗은 선(Whiskers) 밖의 점들이 **이상치(Outlier)**입니다. 보통 **IQR(박스 길이)의 1.5배**를 벗어난 값을 이상치로 판단하며, 이는 모델 학습 전 제거하거나 수정해야 할 후보가 됩니다.

#### ③ 바플롯 (`barplot`): 그룹 간 평균 비교
범주형 변수에 따른 수치형 변수의 **평균값**을 비교할 때 사용합니다.

```python
plt.figure(figsize=(8, 5))
sns.barplot(data=iris, x='species', y='sepal_length', palette='Set2')
plt.title('종별 꽃받침 길이 평균')
plt.show()
```
- **해석:** `boxplot`이 데이터의 전체적인 '분포'와 '이상치'를 보여준다면, `barplot`은 오직 **'평균'**이라는 대표값에 집중합니다. 막대 상단의 검은 선은 신뢰구간을 나타내며, 이를 통해 평균값의 불확실성을 함께 파악할 수 있습니다.

#### ④ 산점도 (`scatterplot`): 두 변수 간의 상관관계 확인
두 수치형 변수가 서로 어떤 관계를 맺고 있는지 점으로 표시합니다.

```python
plt.figure(figsize=(8, 5))
sns.scatterplot(data=iris, x='sepal_length', y='sepal_width', hue='species')
plt.title('꽃받침 길이 vs 너비')
plt.show()
```
- **해석:** `hue` 옵션으로 색상을 구분하면, 특정 종이 특정 영역에 뭉쳐 있는 '군집' 패턴을 볼 수 있습니다. 이는 어떤 변수가 클래스를 구분하는 데 유용한지 판단하는 근거가 됩니다.

#### ⑤ 히트맵 (`heatmap`): 전체 변수 간 상관관계 시각화
여러 변수 간의 상관계수를 색상으로 표현하여 한눈에 파악합니다.

```python
plt.figure(figsize=(8, 6))
corr = iris.drop(columns=['species']).corr()
sns.heatmap(corr, annot=True, cmap='coolwarm', fmt=".2f")
plt.title('변수 간 상관관계')
plt.show()
```
- **해석:** 1에 가까울수록 강한 양의 상관관계, -1에 가까울수록 강한 음의 상관관계를 의미합니다. 0에 가까운 변수는 타겟 변수와 관계가 적으므로 제거 대상이 될 수 있습니다.

## 데이터의 성격에 맞는 그래프 선택법

분석 목적과 데이터의 타입에 따라 적절한 그래프를 선택하는 것이 중요합니다.

| 분석 목적 | 데이터 조합 | 추천 그래프 | 핵심 포인트 |
| :--- | :--- | :--- | :--- |
| **단일 변수의 분포** | 수치형 $\rightarrow$ 1개 | `histplot`, `kdeplot` | 데이터의 쏠림, 정규성 확인 |
| **그룹 간 비교(분포)** | 범주형 $\rightarrow$ 수치형 | `boxplot` | 중앙값 및 이상치 확인 |
| **그룹 간 비교(평균)** | 범주형 $\rightarrow$ 수치형 | `barplot` | 그룹 간 평균 차이 확인 |
| **두 변수의 관계** | 수치형 $\rightarrow$ 수치형 | `scatterplot`, `regplot` | 양/음의 상관관계, 선형성 확인 |
| **전체 변수 간 관계** | 수치형 $\rightarrow$ 수치형(다수) | `heatmap`, `pairplot` | 변수 간 얽힘, 다중공선성 확인 |

## 실무 활용 사례: 데이터 탐색적 분석(EDA)의 흐름

실무에서는 다음과 같은 유기적인 흐름으로 시각화를 진행합니다. 타이타닉 생존자 데이터셋을 예로 들어 보겠습니다.

```python
import seaborn as sns
import matplotlib.pyplot as plt

# 데이터 로드
df = sns.load_dataset('titanic')

# 1. 결측치 확인 (Missing Value Heatmap)
plt.figure(figsize=(10, 6))
sns.heatmap(df.isnull(), cbar=False, yticklabels=False, cmap='viridis')
plt.title('결측치 분포 확인')
plt.show()
```
**[EDA 단계별 상세 흐름]**
1. **결측치 확인:** 위 코드의 히트맵에서 노란색으로 표시되는 부분이 결측치(`True`)입니다. 특정 컬럼(예: `age`나 `deck`)에 **노란색 줄 형태의 빈 공간**이 길게 나타난다면, 해당 변수에 데이터 누락이 심각하다는 것을 직관적으로 알 수 있습니다.
2. **분포 확인:** `sns.histplot(df['age'])` 등을 통해 나이 분포를 확인합니다. 데이터가 한쪽으로 치우쳐 있다면 로그 변환이나 스케일링이 필요함을 판단합니다.
3. **상관관계 분석:** `sns.heatmap(df.corr())`를 통해 생존 여부(`survived`)와 가장 관계가 깊은 변수(예: 객실 등급 `pclass`)를 찾아냅니다.
4. **이상치 탐색:** `sns.boxplot(x='survived', y='fare', data=df)`를 통해 운임(`fare`) 데이터에서 상식을 벗어난 극단적인 고액 결제자가 있는지 확인하고 처리합니다.

이 과정을 거치지 않고 바로 모델을 학습시키면, **"쓰레기를 넣으면 쓰레기가 나온다(Garbage In, Garbage Out)"**는 원칙에 따라 성능이 낮은 모델이 만들어지게 됩니다.

## 시각화 과정에서 자주 하는 실수

### 1. 축 범위(Scale) 조작으로 인한 해석의 차이
Y축의 시작점을 0이 아닌 특정 값으로 설정하면, 아주 작은 차이가 매우 커 보이는 착시 현상이 발생할 수 있습니다. 
- **주의점:** 분석가는 자신의 의도가 독자에게 오해를 불러일으키지 않도록 축 범위를 명시적으로 표시하거나, 데이터의 전체 맥락을 고려하여 설정해야 합니다.

### 2. 과도한 색상 사용
너무 많은 색상을 사용하면 오히려 시선이 분산되어 핵심 패턴을 놓치게 됩니다. `hue` 옵션은 꼭 필요한 구분 기준에만 사용하세요.

### 3. 데이터 타입 무시
범주형 데이터(예: 도시 이름)를 숫자로 변환하지 않고 그대로 산점도에 넣으려 하면 에러가 발생합니다. 시각화 전 반드시 `df.info()`로 데이터 타입을 확인하세요.

## 핵심 요약
- 시각화는 숫자로 된 데이터를 '패턴'과 '모양'으로 바꾸어 직관적으로 이해하는 과정이다.
- **Matplotlib**은 기초 뼈대(Figure: 도화지, Axes: 그래프 영역)를 잡는 도구이며, **Seaborn**은 통계 분석에 최적화된 고수준 도구이다.
- **분포**는 히스토그램, **이상치**는 박스플롯, **평균 비교**는 바플롯, **관계**는 산점도와 히트맵으로 확인한다.
- 시각화 $\rightarrow$ 데이터 정제 $\rightarrow$ 모델링 순으로 이어지는 **EDA** 과정이 머신러닝 성능의 핵심이다.
