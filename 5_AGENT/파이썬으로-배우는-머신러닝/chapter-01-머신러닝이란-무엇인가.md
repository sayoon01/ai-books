# 1. 머신러닝이란 무엇인가

## 이번 장에서 배우는 내용

머신러닝이라는 단어를 들으면 보통 '똑똑한 로봇'이나 '복잡한 수학 공식'을 먼저 떠올리곤 합니다. 하지만 머신러닝의 본질은 생각보다 단순합니다. 이번 장에서는 머신러닝이 정확히 무엇인지, 그리고 우리가 기존에 해왔던 프로그래밍과는 어떻게 다른지 알아봅니다. 또한, 인공지능, 머신러닝, 딥러닝이라는 헷갈리는 용어들을 정리하고, 파이썬 코드를 통해 머신러닝이 데이터를 학습하고 예측하는 전체적인 흐름을 가볍게 경험해 보겠습니다.

---

## 실생활 비유: 요리 레시피 전수하기

여러분에게 '김치찌개 맛있게 끓이는 법'을 가르쳐준다고 가정해 봅시다. 여기에는 두 가지 방법이 있습니다.

**첫 번째 방법**은 아주 상세한 **레시피(규칙)**를 적어주는 것입니다. 
"김치 200g을 넣고, 물 500ml를 붓고, 10분간 끓인 뒤, 간장 1큰술을 넣어라." 
이 방법은 명확합니다. 하지만 재료의 상태(김치의 신맛 정도)나 불의 세기가 달라지면 맛이 변하게 됩니다. 이때마다 레시피를 수정해서 다시 알려줘야 하죠.

**두 번째 방법**은 선생님이 끓인 **맛있는 김치찌개 100그릇(데이터와 결과)**을 직접 먹어보게 하는 것입니다.
학생은 100그릇의 맛을 보며 "아, 김치가 이 정도로 신 상태에서 이만큼 끓였을 때 가장 맛있구나!"라는 **패턴(규칙)**을 스스로 깨닫습니다. 레시피를 직접 읽지 않았지만, 수많은 사례를 통해 '맛있어지는 법'을 스스로 학습한 것입니다.

여기서 두 번째 방법이 바로 **머신러닝(Machine Learning)**의 방식입니다. 사람이 일일이 규칙을 정해주는 것이 아니라, 컴퓨터가 데이터를 통해 스스로 규칙을 찾아내게 만드는 것이죠.

---

## 개념 설명: 전통적인 프로그래밍 vs 머신러닝

우리가 지금까지 배워온 일반적인 프로그래밍은 '명시적 프로그래밍(Explicit Programming)'입니다. 개발자가 `if-else` 문이나 `for` 문을 사용해 컴퓨터가 따라야 할 규칙을 하나하나 정해주는 방식입니다.

### 1. 전통적인 프로그래밍 (Rule-based)
*   **작동 방식:** 데이터와 규칙을 입력하면 결과가 나옵니다.
*   **공식:** `데이터 + 규칙 $\rightarrow$ 결과`
*   **특징:** 규칙이 명확한 작업(예: 계산기, 회원가입 폼 검증)에 매우 효율적입니다. 하지만 규칙이 너무 복잡하거나 계속 변하는 작업에는 한계가 있습니다.

### 2. 머신러닝 (Data-driven)
*   **작동 방식:** 데이터와 정답(결과)을 입력하면 컴퓨터가 그 사이의 규칙을 찾아냅니다.
*   **공식:** `데이터 + 결과 $\rightarrow$ 규칙`
*   **특징:** 사람이 일일이 규칙을 설명하기 어려운 복잡한 패턴(예: 사진 속 고양이 찾기, 주가 예측)을 해결하는 데 강력합니다.

| 구분 | 전통적 프로그래밍 | 머신러닝 |
| :--- | :--- | :--- |
| **핵심** | 사람이 규칙을 정의함 | 컴퓨터가 규칙을 학습함 |
| **입력값** | 데이터, 규칙 | 데이터, 결과(정답) |
| **출력값** | 결과 | 규칙(모델) |
| **접근 방식** | 명시적 프로그래밍 | 데이터 기반 학습 |

---

## 기술 설명: AI, 머신러닝, 딥러닝의 관계

뉴스나 인터넷을 보면 인공지능, 머신러닝, 딥러닝이라는 말이 혼용되어 쓰입니다. 하지만 이 세 가지는 서로 다른 개념이 아니라, **포함 관계**에 있습니다.

1.  **인공지능 (AI, Artificial Intelligence):** 가장 넓은 개념입니다. 인간의 지능을 모방하여 지적인 작업을 수행할 수 있게 하는 모든 기술을 통칭합니다. (예: 체스 프로그램, 단순한 챗봇 등)
2.  **머신러닝 (ML, Machine Learning):** AI의 한 분야로, 명시적으로 프로그래밍되지 않고 데이터로부터 패턴을 학습하여 성능을 개선하는 알고리즘을 말합니다.
3.  **딥러닝 (DL, Deep Learning):** 머신러닝의 한 종류로, 인간의 뇌 구조를 모방한 '인공신경망(ANN)'을 깊게 쌓아 학습하는 기술입니다. 이미지 인식이나 자연어 처리(ChatGPT 등)에서 압도적인 성능을 보입니다.

> **[도식화]**
> **인공지능(AI)** $\supset$ **머신러닝(ML)** $\supset$ **딥러닝(DL)**

## 머신러닝이 왜 필요한가? (실생활 사례)

왜 굳이 복잡하게 머신러닝을 쓸까요? 사람이 규칙을 짜는 것이 불가능에 가까운 영역이 있기 때문입니다.

**예: 스팸 메일 필터링**
전통적인 방식으로 스팸 메일을 거르려면 다음과 같이 코드를 짜야 할 것입니다.
`if "광고" in email_text or "무료" in email_text: spam = True`

하지만 스팸 메일 발송자들은 '광고'라는 단어를 피하기 위해 `광.고`, `광 고`, `Gwang-go` 처럼 변형해서 보냅니다. 사람이 이 모든 변형 패턴을 `if` 문으로 다 작성할 수 있을까요? 불가능합니다.

머신러닝은 수만 통의 '스팸 메일'과 '정상 메일' 데이터를 학습합니다. 이때 단순히 단어를 찾는 것이 아니라, **"특정 단어들이 함께 나타날 확률이 얼마나 높은지"** 혹은 **"발신 주소와 본문 패턴의 통계적 특성이 스팸과 얼마나 유사한지"**와 같은 확률적 패턴을 스스로 학습합니다. 우리가 가르쳐주지 않은 미세한 확률적 징후까지 잡아내는 것이 머신러닝의 진짜 힘입니다.

## 파이썬으로 맛보는 머신러닝의 흐름

이제 이론은 접어두고, 파이썬의 대표적인 머신러닝 라이브러리인 **Scikit-learn(사이킷런)**을 사용해 아주 간단한 예측 모델을 만들어 보겠습니다.

머신러닝의 핵심 프로세스는 **'학습 $\rightarrow$ 모델 생성 $\rightarrow$ 예측'**의 흐름으로 이어집니다.
*   **학습(`fit`):** 데이터 속에서 패턴을 찾아 **'모델'이라는 일종의 규칙 뭉치**를 만드는 과정입니다.
*   **예측(`predict`):** 이렇게 만들어진 **규칙 뭉치(모델)**에 새로운 데이터를 넣어 결과를 도출하는 과정입니다.

우리는 **'과일의 무게'**와 **'색상'** 데이터를 보고, 이 과일이 **'사과'**인지 **'오렌지'**인지 맞히는 모델을 만들어 보겠습니다.

### 실습 코드

```python
# 1. 필요한 라이브러리 불러오기
from sklearn import tree

# 2. 데이터 준비
# 특성(Feature): [무게(g), 색상(0: 빨강, 1: 주황)]
features = [[140, 0], [130, 0], [150, 1], [170, 1]]

# 정답(Label): [0: 사과, 1: 오렌지]
labels = [0, 0, 1, 1]

# 3. 모델 생성 (결정 트리 알고리즘 사용)
# 결정 트리는 스무고개처럼 질문을 던져 정답을 찾아가는 알고리즘입니다.
clf = tree.DecisionTreeClassifier()

# 4. 학습 (Training)
# fit 메서드는 데이터와 정답을 통해 '모델(규칙 뭉치)'을 생성합니다.
clf.fit(features, labels)

# 5. 예측 (Prediction)
# 생성된 모델(clf)에 새로운 데이터 [무게 160g, 색상 주황(1)]를 넣어 결과를 예측합니다.
new_fruit = [[160, 1]]
prediction = clf.predict(new_fruit)

# 결과 출력
fruit_name = "오렌지" if prediction[0] == 1 else "사과"
print(f"새로운 과일의 예측 결과: {fruit_name}")
```

### 실행 결과 해설
*   **결과:** `새로운 과일의 예측 결과: 오렌지`
*   **해설:** 
    *   `clf.fit(features, labels)` 단계에서 모델은 "무게가 140g 이하이면서 빨간색이면 사과고, 150g 이상이면서 주황색이면 오렌지구나!"라는 **규칙 뭉치(모델)**를 완성했습니다.
    *   그 후 `clf.predict([[160, 1]])`를 호출하자, 모델은 자신이 가진 규칙 뭉치를 바탕으로 160g의 주황색 과일은 '오렌지'라고 판단한 것입니다.

## 머신러닝의 학습 방식: 지도, 비지도, 강화학습

머신러닝은 학습하는 방식에 따라 크게 세 가지로 나뉩니다. 앞으로 우리가 배울 내용들의 지도라고 생각하세요.

1.  **지도학습 (Supervised Learning):** 
    *   **특징:** 문제(데이터)와 정답(레이블)을 함께 줍니다.
    *   **비유:** 선생님이 정답지를 주고 공부시키는 것.
    *   **예시:** 스팸 메일 분류, 집값 예측.
2.  **비지도학습 (Unsupervised Learning):** 
    *   **특징:** 정답 없이 문제(데이터)만 줍니다. 데이터 간의 **거리나 유사도**를 측정해 비슷한 특성을 가진 것끼리 묶습니다. 이를 **'군집화(Clustering)'**라고 합니다.
    *   **비유:** 정답지 없이 스스로 공통점을 찾아 분류하는 것.
    *   **예시:** 고객 세그먼트 분류(비슷한 구매 성향을 가진 고객끼리 묶기).
3.  **강화학습 (Reinforcement Learning):** 
    *   **특징:** 정답 대신 어떤 행동을 했을 때 '보상'을 줍니다. 수많은 **시행착오(Trial and Error)**를 겪으며, 보상을 최대화하기 위해 자신의 행동 전략을 계속해서 수정합니다.
    *   **비유:** 강아지에게 간식을 주며 훈련시키는 것.
    *   **예시:** 알파고(AlphaGo), 자율주행 자동차.

## 입문자가 흔히 하는 오해와 실수

머신러닝을 처음 접할 때 가장 위험한 생각은 **"모델만 좋으면 어떤 데이터든 마법처럼 해결해 줄 것이다"**라고 믿는 것입니다.

머신러닝 업계에는 **GIGO (Garbage In, Garbage Out)**라는 유명한 말이 있습니다. **"쓰레기가 들어가면 쓰레기가 나온다"**는 뜻입니다.

*   **실수 사례:** 아주 최신 딥러닝 모델을 사용했는데 예측 정확도가 엉망인 경우.
*   **원인:** 알고리즘의 문제가 아니라, 학습에 사용한 데이터에 오류가 많거나 양이 너무 적었기 때문일 확률이 높습니다.
*   **교훈:** 모델의 정교함보다 더 중요한 것은 **데이터의 품질**입니다. 깨끗하고 정확한 데이터를 준비하는 것이 머신러닝 성공의 80%를 결정합니다.

---

## 핵심 요약
*   **전통적 프로그래밍**은 `데이터 + 규칙 $\rightarrow$ 결과`이지만, **머신러닝**은 `데이터 + 결과 $\rightarrow$ 규칙`을 찾아내는 과정이다.
*   **AI $\supset$ 머신러닝 $\supset$ 딥러닝** 순의 포함 관계를 가진다.
*   머신러닝의 기본 프로세스는 **학습(`fit`) $\rightarrow$ 모델(규칙 뭉치) 생성 $\rightarrow$ 예측(`predict`)** 순으로 이루어진다.
*   학습 방식에는 정답이 있는 **지도학습**, 유사도를 기반으로 묶는 **비지도학습(군집화)**, 시행착오를 통해 보상을 최대화하는 **강화학습**이 있다.
*   **GIGO 원칙:** 데이터의 품질이 모델의 성능을 결정한다.
