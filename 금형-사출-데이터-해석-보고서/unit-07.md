# 7. 금형 식별과 패턴 구조 — 금형의 '지문'

## 금형 식별과 패턴 구조 — 금형의 '지문'

데이터 분석 결과, 수집된 센서 신호는 단순한 공정 수치를 넘어 각 금형의 물리적 특성을 대변하는 고유한 '지문(Fingerprint)' 역할을 하고 있음이 확인되었습니다.

### 1. 금형 식별 모델의 구성과 운영 의미
현재 시스템은 Gradient Boosting 모델을 통해 금형을 식별하고 있으며, 그 상세 구성은 다음과 같습니다.

| 모델 대상 | 알고리즘 | 사용 피처 수 | 클래스(분류) 수 | 비고 |
| :--- | :--- | :---: | :---: | :--- |
| **금형 식별 (moldid)** | Gradient Boosting | 45개 | 29개 | 금형별 고유 패턴 식별 |
| **사이클 유형 (cycletype)** | Gradient Boosting | 45개 | 데이터에 없음 | 운영 상태 분류 |
| **웜업 판별 (warmup)** | Logistic Regression | 33개 | 데이터에 없음 | 초기 가동 상태 판별 |

**[해석] 이 표는 단순히 금형을 구분하는 것을 넘어, 운영 상태와 초기 가동 여부를 함께 판별함으로써 분석 대상 데이터의 순도를 높이고 신뢰성을 확보하는 체계임을 보여줍니다.**

**[데이터 해석]**
45개의 피처(온도, 압력, 시간 등)를 활용해 29종의 금형을 구분해낸다는 것은, **금형마다 센서 데이터의 조합(Combination)이 명확하게 구분되는 고유한 패턴을 가지고 있음**을 의미합니다. 특히 금형 식별 모델과 함께 `cycletype` 및 `warmup` 모델이 동시에 운영되는 구조는 데이터 품질 관리 측면에서 필수적입니다. 예를 들어, `warmup(웜업)` 구간의 데이터는 정상 가동 상태와는 전혀 다른 패턴을 보이기 때문에, 이를 별도로 판별하여 분석 대상에서 제외하거나 분리 처리해야만 금형별 고유 패턴을 왜곡 없이 분석할 수 있기 때문으로 해석됩니다.

### 2. 123개 패턴 클러스터의 물리적 의미
전체 데이터에서 약 123개의 패턴 클러스터가 발견되었습니다. 이는 지도 학습 기반의 금형 식별 모델이 구분하는 클래스 수(29개)보다 훨씬 많은 수치입니다.

**[데이터 해석]**
이러한 차이는 지도 학습(정해진 금형 ID 분류)과 비지도 학습(데이터 자체의 유사성 기반 그룹화)의 특성 차이에서 기인합니다. 동일한 금형이라 하더라도 123개의 세부 클러스터로 나뉜다는 것은, **금형 하나가 단일한 고정 패턴을 가지는 것이 아니라, 운전 조건이나 상태 변화에 따라 여러 개의 '서브 패턴'을 형성함**을 뜻합니다.
* **원인:** 금형 내부의 온도 변화, 가동 시간에 따른 마모도, 혹은 외부 환경 온도 등에 따라 센서 반응이 미세하게 변하며, 이로 인해 동일 금형 내에서도 서로 다른 클러스터로 분류되는 것으로 추정됩니다.
* **결론:** 즉, 금형의 '지문'은 하나의 정지된 이미지가 아니라, 특정 범위 내에서 움직이는 '동적 패턴의 집합'으로 해석하는 것이 타당합니다.

### 3. 센서 데이터만으로 금형 식별이 가능한 메커니즘
별도의 금형 ID 입력 없이 온도(T)와 압력(P) 센서 데이터만으로 금형을 식별할 수 있는 이유는 금형의 **물리적 구조 차이**에 기인합니다.

* **열역학적 특성:** 금형마다 캐비티(Cavity)의 형상, 냉각 채널의 배치, 재질의 두께가 다릅니다. 이로 인해 `T*_Detect(레진 도달 시간)`와 `T*_Max(최고 온도)`의 분포가 물리적으로 다르게 나타납니다.
* **유체역학적 특성:** 게이트의 크기와 유로의 설계에 따라 내부 압력 `P*_Max(최대 압력)`의 전달 속도와 피크 값이 달라집니다.
* **결합 효과:** 이러한 온도와 압력의 복합적인 반응 패턴은 해당 금형의 설계 도면이 디지털 신호로 변환되어 나타나는 것과 같으며, Gradient Boosting 모델은 이 미세한 물리적 차이를 학습하여 금형을 구분해내는 것으로 해석됩니다.

### 4. 패턴 구조의 시사점
금형별 고유 패턴(지문)이 명확히 존재한다는 사실은 향후 공정 관리에 있어 다음과 같은 중요한 시사점을 제공합니다.

* **기준 패턴(Golden Pattern)의 정의:** 각 금형별로 가장 품질이 좋았던 시점의 센서 패턴을 '기준 지문'으로 설정할 수 있습니다.
* **이상 탐지의 정밀화:** 단순히 전체 평균에서 벗어난 값을 찾는 것이 아니라, **"해당 금형의 고유 패턴 범위"**를 벗어났는지를 판단함으로써, 금형별 특성이 반영된 초정밀 이상 탐지가 가능해집니다.
* **디지털 트윈의 기초:** 센서 데이터만으로 금형을 식별할 수 있다는 것은, 물리적 금형의 상태를 데이터로 완벽하게 투영할 수 있는 디지털 기반이 마련되었음을 의미합니다.

**핵심 해석**
* **물리적 고유성:** 45개 피처와 123개 클러스터는 금형의 설계 구조(캐비티, 냉각로 등)가 센서 데이터에 고스란히 반영되어 있음을 입증한다.
* **동적 지문:** 금형 식별은 단일 수치가 아닌 '패턴의 집합'을 통해 이루어지며, 이는 환경 변화에 따른 가변성까지 포함한 고유 지문으로 해석된다.
* **관리 패러다임 전환:** 금형별 고유 패턴의 존재는 '범용 관리'에서 '금형별 맞춤형 정밀 관리'로 전환할 수 있는 데이터 근거가 된다.
