# 7. 금형 식별과 패턴 구조 — 금형의 '지문'

## 금형 식별과 패턴 구조 — 금형의 '지문'

수만 개의 사이클 데이터 속에서 모델이 어떻게 금형을 구분해내는지, 그 비밀은 각 금형이 가진 고유한 '물리적 지문'에서 찾을 수 있습니다. 단순히 센서 값의 높고 낮음을 보는 것이 아니라, 여러 센서가 함께 움직이는 '패턴'이 금형마다 다르게 나타나기 때문입니다.

## 금형 식별 모델의 구성과 기술적 함의

본 데이터셋을 분석하기 위해 구축된 금형 식별 모델은 Gradient Boosting 알고리즘을 기반으로 하며, 총 45개의 피처(Feature)를 활용해 29개의 클래스(금형 모델)를 구분하도록 설계되었습니다. 또한, 이 모델은 단순한 금형 종류뿐만 아니라 `cycletype`이나 `warmup`과 같은 공정 상태까지 식별할 수 있는 능력을 갖추고 있습니다.

| 모델 구분 | 사용 알고리즘 | 활용 피처 수 | 식별 대상 (클래스) | 비고 |
| :--- | :--- | :--- | :--- | :--- |
| 금형 식별 모델 | Gradient Boosting | 45개 | 29개 금형 모델 | moldid 식별 |
| 상태 식별 모델 | Gradient Boosting | 45개 | Cycle Type | 공정 상태 구분 |
| 예열 식별 모델 | Logistic Regression | 33개 | Warmup 여부 | 초기 예열 단계 구분 |

**[해석]**
위 표에서 주목해야 할 점은 금형을 구분하기 위해 투입된 '45개'라는 피처의 수입니다. 단 몇 개의 대표 수치만으로 금형을 구분하는 것이 아니라, 45개에 달하는 다변량 데이터를 동시에 고려한다는 것은 금형의 정체성이 단일 지표가 아닌 **'복합적인 변수들의 조합'**으로 나타나고 있음을 의미합니다. 29개라는 비교적 많은 수의 클래스를 정밀하게 구분해낼 수 있다는 점은, 각 금형이 생성하는 데이터의 분포가 서로 겹치지 않고 고유한 영역을 형성하고 있다는 기술적 근거가 됩니다. 

더불어 `cycletype`이나 `warmup` 상태까지 구분 가능하다는 점은 매우 중요한 함의를 갖습니다. 이는 모델이 단순히 금형의 외형적 특성만 읽어내는 것이 아니라, 해당 금형이 현재 '정상 가동 중인지', '예열 중인지', 혹은 '에러 상태인지'와 같은 **동적인 공정 컨텍스트(Context)까지 데이터 패턴으로 인식**하고 있음을 뜻합니다. 결과적으로 이 모델은 금형이라는 물리적 자산의 식별을 넘어, 공정의 현재 상태를 실시간으로 진단할 수 있는 기반이 됩니다.

## 123개 패턴 클러스터의 의미: 구조적 패턴의 존재

데이터 분석 과정에서 발견된 `n_clusters: 123`이라는 수치는 이 보고서에서 가장 핵심적인 발견 중 하나입니다. 식별해야 할 금형의 종류는 29종이지만, 실제 데이터가 형성하는 패턴의 군집(Cluster)은 그보다 훨씬 많은 123개가 존재한다는 사실입니다.

**[해석]**
금형의 개수보다 클러스터의 수가 약 4배 이상 많다는 것은, 하나의 금형이 단 하나의 고정된 데이터 패턴만을 생성하는 것이 아님을 의미합니다. 이는 다음과 같은 물리적/운영적 원인으로 해석됩니다.

첫째, **운전 조건의 미세한 변동**입니다. 동일한 금형이라 하더라도 투입되는 레진의 특성, 주변 온도, 혹은 작업자의 설정값에 따라 센서 데이터의 분포가 미세하게 변하며, 이것이 서로 다른 클러스터로 분리되어 나타난 것으로 추정됩니다.
둘째, **금형의 상태 변화(마모 및 열화)**입니다. 금형은 사용 횟수(Shot 수)가 증가함에 따라 내부의 마모 상태나 열전달 효율이 변합니다. 이러한 물리적 변화가 데이터 패턴에 반영되어, 동일 모델 내에서도 '초기 상태'와 '안정화 상태', '노후 상태' 등의 서브 패턴이 형성되었을 가능성이 큽니다.
셋째, **공정 단계별 특성**입니다. `warmup` 단계와 `normal` 단계에서 발생하는 온도·압력의 거동은 완전히 다릅니다. 따라서 123개의 클러스터는 [금형 종류 $\times$ 공정 상태 $\times$ 운전 조건]이 결합되어 나타난 결과물이라고 해석할 수 있습니다.

결국 123개의 클러스터가 존재한다는 것은, 센서 데이터가 단순히 무작위로 흩어져 있는 것이 아니라 **매우 정교하고 구조적인 '패턴'을 가지고 움직이고 있음**을 증명합니다. 이는 데이터가 단순한 수치의 나열이 아니라, 금형의 현재 상태를 그대로 투영하는 '물리적 지문'으로서 작동하고 있다는 결정적인 근거가 됩니다.

## 금형 식별이 가능한 물리적 메커니즘 해석

그렇다면 구체적으로 어떤 물리적 메커니즘이 센서 데이터만으로 금형을 식별 가능하게 만드는 것일까요? 이는 금형마다 서로 다른 **센서 배치 구조와 수지의 흐름 경로(Flow Path)**에서 기인합니다.

본 데이터셋의 `field_dict`를 보면 T1~T8의 온도 센서와 P1~P8의 압력 센서가 배치되어 있습니다. 여기서 각 센서의 `Start`(사출 전 온도), `Max`(최대 온도), `End`(추출 전 온도) 및 `P_Max`(최대 압력) 값들은 금형의 기하학적 구조와 열용량을 그대로 반영합니다. 특히 센서 간의 상관관계를 분석하면 더욱 명확해집니다.

**[주요 센서 상관관계 분석]**
*   **T5_Start ↔ T6_Start (r = 0.962):** 매우 강력한 정적 상관관계를 보입니다.
*   **T5_Max ↔ T5_Start (r = 0.960) / T7_Max ↔ T7_Start (r = 0.956):** 개별 센서의 시작 온도와 최대 온도가 밀접하게 연동됩니다.
*   **T6_Max ↔ T7_Max (r = 0.944):** 서로 다른 위치의 센서들이 함께 움직이는 패턴을 보입니다.

**[메커니즘 해석]**
이러한 높은 상관관계는 금형 내부에서 특정 센서들이 **'하나의 열적/압력적 그룹'**으로 묶여 있음을 뜻합니다. 예를 들어 T5, T6, T7 센서가 강하게 연동되어 움직인다면, 이는 해당 센서들이 수지의 주 흐름 경로(Main Runner)에 인접해 있거나, 동일한 냉각 라인의 영향을 받는 영역에 배치되어 있음을 시사합니다.

금형마다 센서의 물리적 위치와 냉각 채널의 설계가 모두 다르기 때문에, A 금형에서는 [T5-T6-T7]이 한 묶음으로 움직이지만, B 금형에서는 [T1-T2-T4]가 한 묶음으로 움직이는 식의 차이가 발생합니다. 또한, `T_Detect`(레진 도달 시간) 값의 차이는 수지가 금형 내부를 채우는 속도와 경로의 차이를 나타내므로, 이는 금형의 내부 형상을 수치화한 것과 다름없습니다.

즉, 머신러닝 모델은 단순히 "온도가 몇 도인가"를 보는 것이 아니라, **"T5가 오를 때 T6와 T7이 어떤 비율로 함께 오르는가"**라는 **'상대적 거동 패턴'**을 포착하는 것입니다. 이것이 바로 금형마다 고유하게 나타나는 '물리적 지문'의 실체이며, 이를 통해 모델이 높은 정밀도로 금형을 식별할 수 있는 것입니다.

## 금형 '지문' 패턴의 시사점

금형별 고유 패턴의 존재와 이를 통한 자동 식별 가능성은 향후 공정 관리에 있어 다음과 같은 전략적 시사점을 제공합니다.

**1. 데이터 기반의 자동 자산 관리 및 검증**
기존에는 작업자가 어떤 금형을 장착했는지 수동으로 입력해야 했으나, 이제는 센서 데이터만으로 현재 가동 중인 금형을 자동으로 식별할 수 있습니다. 이는 휴먼 에러(입력 실수)를 원천적으로 차단하며, 설정된 금형 모델과 실제 데이터 패턴이 일치하는지 실시간으로 검증함으로써 오장착으로 인한 불량 발생을 예방할 수 있음을 뜻합니다.

**2. 금형 상태 모니터링의 정밀도 향상**
123개의 클러스터 분석에서 확인했듯이, 동일 금형 내에서도 상태에 따라 패턴이 세분화됩니다. 이를 활용하면 단순히 '정상/이상'을 나누는 것을 넘어, "현재 금형이 노후화 단계에 진입하여 패턴이 B 클러스터로 이동했다"는 식의 **예지 보전(Predictive Maintenance)** 관점이 가능해집니다. 즉, 패턴의 이동(Drift)을 추적함으로써 금형의 교체 시기나 세척 시기를 데이터 기반으로 결정할 수 있습니다.

**3. 공정 최적화의 기준점(Baseline) 확보**
금형별 고유 지문을 알고 있다는 것은, 각 금형이 가질 수 있는 '가장 이상적인 데이터 패턴(Golden Pattern)'을 정의할 수 있음을 의미합니다. 특정 금형의 최적 생산 조건에서 나타나는 센서 거동을 표준 지문으로 설정하고, 현재의 패턴이 이 표준에서 얼마나 벗어나는지를 측정함으로써 공정의 안정성을 정량적으로 관리할 수 있게 됩니다.

**[핵심 해석 요약]**
*   **물리적 지문의 실체:** 금형 식별은 단일 수치가 아닌, 45개 피처의 조합과 센서 간의 강한 상관관계(예: T5-T6-T7 그룹핑) 등 '구조적 패턴'을 통해 이루어진다.
*   **패턴의 다변성:** 29종의 금형이 123개의 클러스터로 나타나는 것은 운전 조건, 마모 상태, 공정 단계가 데이터에 세밀하게 투영되어 있음을 의미한다.
*   **관리적 가치:** 고유 패턴 식별 능력을 통해 금형 자동 인식 $\rightarrow$ 상태 변화 추적 $\rightarrow$ 최적 패턴 유지라는 정밀 공정 관리 체계 구축이 가능하다.

이렇게 금형별 고유 패턴을 통해 '누가' 생산하고 있는지 식별할 수 있게 되었다면, 이제는 이 데이터가 실제로 어떤 품질적 결과물로 이어지는지, 그 최종적인 상관관계를 분석해 보겠습니다.
