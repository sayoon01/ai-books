# 2. 사이클 유형 분포 — 데이터 품질이 말하는 것

## 사이클 유형 분포 — 데이터 품질이 말하는 것

수집된 전체 517,130 사이클의 유형 분포를 분석한 결과, 실질적으로 분석 가능한 'NORMAL' 데이터의 비중은 57.61%(297,886건)로 나타났습니다. 이는 전체 데이터의 약 40.11%가 센서 신호 부재나 오류로 인해 유효한 물리량 값을 확보하지 못한 상태임을 의미하며, 데이터 수집 단계에서 상당한 손실이 발생했음을 보여줍니다.

**[표: 사이클 유형별 분포 현황]**

| 사이클 유형 | 발생 횟수 (건) | 비중 (%) | 비고 |
| :--- | :---: | :---: | :--- |
| **NORMAL** | 297,886 | 57.61% | 정상 데이터 수집 완료 |
| **SENSOR_NO_SIGNAL** | 170,693 | 33.01% | 센서 신호 없음 |
| **SENSOR_ERROR** | 36,714 | 7.10% | 센서 측정 오류 |
| **IDLE** | 10,115 | 1.96% | 설비 대기 상태 |
| **WARMUP** | 1,722 | 0.33% | 초기 가동 준비 단계 |
| **합계** | **517,130** | **100%** | - |

**※ 해석: 전체 수집 데이터의 약 40.11%(207,407건)가 센서 이슈(No Signal 및 Error)로 인해 유실되었습니다. 이는 데이터 수집 신뢰도가 저하된 상태임을 뜻하며, 향후 정밀한 분석을 위해서는 센서 인프라의 전면적인 점검 및 수집 체계 개선이 필요함을 시사합니다.**

### 1. 데이터 손실의 원인 및 메커니즘 해석
정상 데이터(NORMAL)의 비중이 과반을 넘겼음에도 불구하고, `SENSOR_NO_SIGNAL`(33.01%)과 `SENSOR_ERROR`(7.10%)가 합산 40.11%라는 높은 비중을 차지하는 원인은 다음과 같이 해석됩니다.

*   **센서 미장착 금형의 사용:** 특정 금형 모델의 경우 센서가 장착되지 않은 상태로 운용되었을 가능성이 높습니다. 이는 특정 모델에서 일관되게 신호가 없는 패턴이 나타날 때 발생하는 현상으로 추정됩니다.
*   **데이터 수집 체계의 간헐적 누락:** 센서 하드웨어는 장착되어 있으나, 수집 시스템(API/DB)으로 전달되는 과정에서 신호가 유실되었거나 통신 오류가 발생했을 때 `SENSOR_ERROR` 또는 `NO_SIGNAL`로 기록되는 메커니즘으로 해석됩니다.
*   **공정 운영 상태의 반영:** `IDLE`(1.96%)과 `WARMUP`(0.33%) 데이터가 포함된 것은, 단순 생산 사이클뿐만 아니라 설비의 대기 및 예열 단계까지 모두 로깅되었음을 의미합니다.

### 2. 후속 분석에 주는 함의
데이터 품질 관점에서 볼 때, 이번 분석의 실질적인 가용 데이터 규모는 `NORMAL` 유형인 297,886건으로 한정됩니다.

*   **데이터 가용성:** 전체의 57.61%만이 분석 가능하므로 데이터 손실률이 매우 높은 편입니다. 하지만 절대적인 수치(약 29.8만 건)가 충분히 크기 때문에, 통계적 유의미성을 확보하고 모델을 학습시키기에는 부족함이 없는 규모로 판단됩니다.
*   **분석 범위의 제한:** 센서 신호가 없는 데이터(NO_SIGNAL/ERROR)는 물리적 수치(온도, 압력 등)가 결여되어 있으므로, 공정 변수 간의 상관관계 분석이나 이상 탐지 분석 대상에서는 제외되어야 합니다.

**핵심 해석**
*   **데이터 손실률 심각:** 전체 데이터의 약 40.11%가 센서 신호 부재 및 오류로 인해 분석 불가능한 상태이며, 이는 특정 금형의 센서 미장착 또는 수집 장치의 불안정성에서 기인한 것으로 추정됩니다.
*   **실질 분석 규모 확정:** 후속 데이터 해석 및 모델링의 대상은 `NORMAL` 데이터셋(297,886건)으로 국한되며, 이는 통계적 분석을 수행하기에 충분한 표본 크기입니다.
*   **운영 데이터 포함:** IDLE 및 WARMUP 사이클이 함께 수집되어, 실제 생산 외의 설비 가동 전후 상태까지 파악할 수 있는 기반이 마련되었습니다.
