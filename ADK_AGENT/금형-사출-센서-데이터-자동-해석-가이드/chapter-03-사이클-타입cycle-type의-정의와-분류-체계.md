# 3. 사이클 타입(Cycle Type)의 정의와 분류 체계

## 사이클 타입(Cycle Type)의 정의와 분류 체계

사출 성형 공정에서 수집되는 데이터는 모든 샷(Shot)이 분석 가능한 유효 데이터를 포함하고 있지 않습니다. 센서의 물리적 연결 상태, 기계의 가동 상태, 그리고 공정 준비 단계에 따라 데이터의 성격이 완전히 달라지기 때문입니다. 따라서 본 가이드에서는 수집된 전체 데이터를 먼저 다섯 가지의 '사이클 타입(Cycle Type)'으로 분류하며, 이 분류 체계는 이후 진행될 모든 통계 분석의 전제 조건이 됩니다. 분석 대상이 되는 'NORMAL' 사이클을 정의하기 위해서는 먼저 분석에서 제외되어야 할 네 가지 비정상 상태(NO_SIGNAL, SENSOR_ERROR, WARMUP, IDLE)의 논리적 기준을 명확히 정의하는 것이 우선입니다.

## 1. NO_SIGNAL (미연결)의 정의와 판정 기준

NO_SIGNAL 타입은 데이터 수집 시스템이 센서로부터 어떠한 전기적 신호도 전달받지 못한 상태를 의미합니다. 이 상태의 가장 핵심적인 특징은 온도 측정 채널(T-Channel)의 모든 값이 NaN(Not a Number)으로 기록된다는 점입니다. 이는 센서가 단순히 값을 측정하지 못한 것이 아니라, 데이터의 존재 자체가 누락된 상태임을 뜻합니다.

물리적 관점에서 NO_SIGNAL은 센서와 데이터 수집 장치(DAQ) 사이의 하드웨어적 단절로 인해 발생한 것으로 해석됩니다. 구체적으로는 센서 케이블의 단선, 커넥터의 접촉 불량, 혹은 데이터 전송 모듈의 일시적 장애 등으로 인해 신호 체계가 완전히 붕괴되었을 때 이러한 결과가 나타나는 것으로 추정됩니다. 따라서 이 타입으로 분류된 데이터는 분석 가치가 없으며, 하드웨어 점검이 우선시되어야 하는 영역입니다.

데이터 사전 관점에서 NO_SIGNAL은 '데이터의 부재' 그 자체를 정의합니다. 분석가는 이 타입의 발생 빈도를 통해 특정 금형이나 설비의 배선 안정성을 평가할 수 있습니다. 만약 특정 시점부터 지속적으로 NO_SIGNAL이 발생한다면 이는 일시적 오류가 아닌 물리적 파손으로 해석해야 합니다.

## 2. SENSOR_ERROR (센서오류)의 정의와 판정 기준

SENSOR_ERROR는 신호는 수집되고 있으나, 수집된 수치가 물리적으로 불가능하거나 센서의 고장으로 인해 신뢰할 수 없는 상태를 의미합니다. 이 타입은 다음과 같은 세 가지 조건 중 하나라도 충족될 때 판정됩니다. 첫째, 2개 이상의 온도 채널에서 최고 온도(T_MAX)가 0으로 측정된 경우입니다. 둘째, 1개 이상의 압력 채널에서 최고 압력(P_MAX)이 0으로 측정된 경우입니다. 셋째, 사이클 타임(CycleTime) 자체가 0으로 기록된 경우입니다.

여기서 주의해야 할 점은 '단순 미장착'과 '센서 오류'를 구분하는 엄격한 기준이 존재한다는 것입니다. 모든 센서가 장착된 상태가 아니기에, 단순히 수치가 낮다고 해서 오류로 판정하면 데이터 왜곡이 발생합니다. 따라서 전체 사이클의 95% 이상에서 온도(T)가 30°C 미만이거나 압력(P)이 50bar 미만으로 측정되는 채널은 '미장착 센서'로 간주하여 SENSOR_ERROR 판정 대상에서 제외합니다.

이러한 구분 방식은 센서의 고장(Failure)과 설계상의 미장착(Not Installed)을 분리하여 관리하기 위함입니다. 미장착 센서는 원래 값이 낮게 나오는 것이 정상이나, 장착된 센서가 0을 출력하는 것은 명백한 하드웨어 오류이기 때문입니다. 결과적으로 SENSOR_ERROR는 '있어야 할 신호가 나오지 않는 상태'를 정의하는 지표로 해석됩니다.

## 3. WARMUP (워밍업)의 정의와 판정 기준

WARMUP 타입은 설비가 가동을 시작했으나, 아직 안정적인 생산 단계에 진입하지 못한 준비 상태를 의미합니다. 이 타입을 결정짓는 결정적인 필드는 T_Detect입니다. T_Detect 필드는 온도를 측정하는 값이 아니라, 용융된 수지가 센서 위치에 도달하는 시점인 '레진 도달 시간'을 의미합니다. 따라서 T_Detect 값이 0으로 기록된 사이클은 모두 WARMUP으로 분류합니다.

수지가 센서에 도달하지 못했다는 것은 물리적으로 수지가 아직 금형 내부를 완전히 채우지 못했거나, 가열 중인 수지의 점도가 너무 높아 센서 위치까지 밀려 들어오지 못했음을 뜻합니다. 즉, 사출기의 히터가 작동하여 설정 온도까지 승온되는 과정에서 발생하는 초기 샷들은 수지의 유동성이 부족하여 센서에 도달하지 못하는 경우가 빈번하며, 이를 워밍업 구간으로 정의합니다.

분석 관점에서 WARMUP 데이터는 제외되어야 합니다. 워밍업 단계에서는 온도와 압력의 파형이 정상 생산 단계와 완전히 다르며, 이는 공정의 안정성을 평가하는 통계치에 심각한 왜곡을 일으키기 때문입니다. 따라서 T_Detect=0이라는 조건은 '물리적 성형이 완전히 이루어지지 않은 샷'을 걸러내는 필터 역할을 수행합니다.

## 4. IDLE (유휴)의 정의와 판정 기준

IDLE 타입은 기계가 작동은 하고 있으나, 실제 생산 사이클이 비정상적으로 길어져 작업이 중단되었거나 대기 상태에 머문 경우를 의미합니다. 이는 주로 사이클 타임(CycleTime)의 통계적 이상치를 통해 판정합니다. 구체적인 판정 식은 다음과 같습니다.

- 판정 기준: CycleTime > [P75 + (P75 - P25) * 3]

여기서 P75는 전체 사이클 타임의 상위 25% 지점(제3사분위수)을 의미하며, P25는 하위 25% 지점(제1사분위수)을 의미합니다. 즉, 일반적인 사이클 타임의 분포 범위에서 사분위 범위(IQR)의 3배를 초과하여 길어진 경우를 IDLE로 정의합니다. 이는 통계적으로 극단적인 이상치(Outlier)를 제거하는 방식과 유사합니다.

이러한 현상은 실제 현장에서 작업자가 제품을 수동으로 꺼내기 위해 시간을 지체했거나, 금형 내 이물질 제거를 위해 일시적으로 공정을 멈춘 경우, 혹은 설비의 일시적 정지 등으로 인해 발생한 것으로 추정됩니다. 즉, 기계적 오류는 아니지만 생산 효율과 무관한 '비가동 시간'이 포함된 데이터입니다.

IDLE 타입으로 분류된 데이터는 사이클 타임이 비정상적으로 길기 때문에, 시간 기반의 공정 분석 시 평균값을 심하게 왜곡시킬 위험이 있습니다. 따라서 이를 분리함으로써 실제 제품이 생산되는 순수 공정 시간만을 분석 대상으로 확보할 수 있습니다.

## 5. NORMAL (분석 대상)의 정의와 결정 구조

NORMAL 타입은 앞서 언급한 네 가지 제외 조건(NO_SIGNAL, SENSOR_ERROR, WARMUP, IDLE) 중 어느 하나에도 해당하지 않는 사이클을 의미합니다. 즉, 하드웨어적으로 연결이 정상이고, 센서가 정상 작동하며, 수지가 센서에 완전히 도달했고, 사이클 타임이 통계적 정상 범위 내에 있는 '순수 생산 데이터'입니다.

NORMAL 사이클의 결정 구조를 논리 흐름으로 정리하면 다음과 같습니다.

1. **1차 필터 (연결성 확인)**: T-채널 전체가 NaN인가? → Yes: NO_SIGNAL / No: 다음 단계
2. **2차 필터 (작동성 확인)**: T_MAX=0(2채널↑), P_MAX=0(1채널↑), 또는 CycleTime=0인가? (단, 미장착 기준 제외) → Yes: SENSOR_ERROR / No: 다음 단계
3. **3차 필터 (도달성 확인)**: T_Detect = 0인가? → Yes: WARMUP / No: 다음 단계
4. **4차 필터 (시간성 확인)**: CycleTime이 통계적 임계치(P75 + 3*IQR)를 초과하는가? → Yes: IDLE / No: NORMAL

결과적으로 NORMAL 타입은 데이터의 '청정도'가 보장된 상태를 의미하며, 이후 진행될 마스터 파형 비교 분석이나 Isolation Forest 기반의 이상 감지 알고리즘이 적용되는 유일한 대상입니다. 분석가는 전체 수집 데이터 중 NORMAL 사이클의 비율을 확인하여 해당 공정의 데이터 수집 효율과 설비 안정성을 판단할 수 있습니다.

| 사이클 타입 | 주요 판정 필드 | 핵심 판정 논리 | 물리적 의미 (추정) | 분석 포함 여부 |
| :--- | :--- | :--- | :--- | :--- |
| **NO_SIGNAL** | T-Channel | All NaN | 케이블 단선 및 커넥터 불량 | 제외 |
| **SENSOR_ERROR** | T_MAX, P_MAX | 0 출력 (미장착 제외) | 센서 소자 고장 및 파손 | 제외 |
| **WARMUP** | T_Detect | 0 (미도달) | 수지 점도 높음/승온 중 | 제외 |
| **IDLE** | CycleTime | P75 + (P75-P25)*3 초과 | 작업 중단 및 대기 시간 발생 | 제외 |
| **NORMAL** | All | 위 4가지 조건 모두 미충족 | 정상적인 제품 생산 사이클 | **포함** |

**요약: 이 표는 수집된 데이터가 어떤 논리적 단계를 거쳐 분석 가능한 'NORMAL' 데이터로 정제되는지를 보여줍니다. 즉, 데이터의 물리적 연결 → 센서 작동 → 수지 도달 → 시간 적절성 순으로 검증이 이루어집니다.**

***

**핵심 요약**
* 사이클 타입 분류는 분석 대상인 'NORMAL' 데이터를 추출하기 위해 네 가지 제외 조건(NO_SIGNAL, SENSOR_ERROR, WARMUP, IDLE)을 순차적으로 적용하는 필터링 과정이다.
* T_Detect=0은 온도가 아닌 '수지의 센서 미도달'을 의미하여 WARMUP으로 분류하며, CycleTime의 통계적 이상치는 IDLE로 정의하여 분석 왜곡을 방지한다.
* 센서 오류 판정 시에는 95% 이상의 저수치 기록 채널을 '미장착'으로 간주하여 실제 고장 데이터(SENSOR_ERROR)와 엄격히 구분한다.
