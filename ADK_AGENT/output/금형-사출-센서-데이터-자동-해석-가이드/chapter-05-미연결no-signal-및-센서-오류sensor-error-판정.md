# 5. 미연결(NO_SIGNAL) 및 센서 오류(SENSOR_ERROR) 판정

## 미연결(NO_SIGNAL) 및 센서 오류(SENSOR_ERROR) 판정

데이터 사전의 관점에서 데이터의 누락이나 비정상 수치는 단순히 '제거해야 할 대상'이 아니라, 그 자체로 하드웨어의 상태를 나타내는 중요한 지표입니다. 본 챕터에서는 수집된 데이터 중 분석 대상에서 제외되는 '미연결(NO_SIGNAL)'과 '센서 오류(SENSOR_ERROR)'의 판정 로직을 정의합니다. 특히 값이 비어 있는 NaN(Not a Number) 상태와 값이 0으로 고정된 상태의 도메인적 차이를 명확히 구분하여, 이것이 물리적인 케이블 단선인지 혹은 센서 자체의 결함인지를 해석하는 기준을 제시합니다.

## 미연결(NO_SIGNAL)의 정의와 물리적 해석

미연결(NO_SIGNAL) 상태는 데이터 수집 시스템이 센서로부터 어떠한 전기적 신호도 전달받지 못했을 때 정의됩니다. 데이터 필드상으로는 T(Temperature) 채널 전체가 NaN으로 기록되는 상태를 의미합니다. 여기서 NaN은 단순한 수치적 결측치가 아니라, 데이터 패킷 자체가 수신되지 않았음을 뜻하는 시스템적 신호로 해석해야 합니다.

이러한 현상이 발생하는 주된 원인은 물리 계층(Physical Layer)의 결함으로 추정됩니다. 센서와 데이터 수집 장치(DAQ)를 연결하는 케이블의 단선, 커넥터의 접촉 불량, 혹은 통신 모듈의 전원 공급 중단 등이 이에 해당합니다. 특히 T채널 전체가 NaN이라는 점은 특정 단일 센서의 고장이 아니라, 해당 금형의 데이터를 전송하는 전체 라인에 문제가 발생했음을 시사합니다.

도메인 관점에서 미연결 상태의 데이터는 분석 가치가 전혀 없습니다. 온도를 측정하는 센서가 연결되지 않았다면 수지의 흐름이나 압력 변화를 추적하는 것이 불가능하기 때문입니다. 따라서 미연결로 판정된 사이클은 이후의 모든 통계 분석 및 이상 감지 로직에서 완전히 배제됩니다. 이는 분석 결과에 편향을 줄 수 있는 '빈 값'을 사전에 제거하여 데이터의 무결성을 확보하기 위함입니다.

결과적으로 NO_SIGNAL 판정은 데이터 분석의 단계가 아니라, 하드웨어 점검의 단계로 해석되어야 합니다. 이 상태가 지속적으로 관찰된다면 분석가는 데이터 필터링에 집중할 것이 아니라, 현장의 케이블 연결 상태와 커넥터 체결 여부를 우선적으로 확인해야 합니다.

## 센서 오류(SENSOR_ERROR)의 판정 로직

센서 오류(SENSOR_ERROR)는 신호는 수신되고 있으나, 수신된 값 자체가 물리적으로 불가능하거나 공정 상 존재할 수 없는 수치일 때 정의됩니다. 이는 미연결(NO_SIGNAL)과 달리 데이터는 존재하지만 '의미 없는 값'이 들어오는 상태입니다. 본 가이드에서는 다음과 같은 세 가지 조건 중 하나라도 충족될 경우 센서 오류로 판정합니다.

첫째, T_MAX 값이 0인 채널이 2개 이상 발생하는 경우입니다. 사출 공정 특성상 금형 내부의 온도가 절대 0°C가 될 수는 없으며, 센서가 정상 작동한다면 최소한의 주변 온도나 금형 예열 온도가 측정되어야 합니다. 따라서 T_MAX=0이라는 수치는 센서의 소자 파손이나 내부 회로 단락으로 인해 고정된 낮은 전압 값이 입력되고 있는 상태로 해석됩니다. 단, 단일 채널의 오류일 가능성을 배제하기 위해 2채널 이상의 동시 발생을 기준으로 삼습니다.

둘째, P_MAX 값이 0인 채널이 1개 이상 발생하는 경우입니다. 압력 센서(P)는 수지의 충전 과정에서 필연적으로 높은 압력을 감지해야 합니다. 만약 사이클 내 최고 압력인 P_MAX가 0으로 기록되었다면, 이는 압력 센서가 물리적으로 파손되었거나 신호를 생성하지 못하는 상태로 추정됩니다. 압력 데이터는 공정 제어의 핵심 지표이므로, 단 하나의 채널에서만 0이 발생하더라도 해당 사이클은 신뢰할 수 없는 데이터로 간주하여 오류로 처리합니다.

셋째, CycleTime이 0으로 기록된 경우입니다. 사이클 타임은 공정의 시작과 끝을 측정하는 시간 간격입니다. 이 값이 0이라는 것은 타이머 트리거가 작동하지 않았거나, 시작 시점과 종료 시점이 동일하게 기록되는 시스템적 오류가 발생했음을 의미합니다. 시간 축이 정의되지 않은 데이터는 이후의 모든 시계열 분석이 불가능하므로 센서 오류와 동일한 수준의 결함으로 처리합니다.

## 미장착(Uninstalled) 기준과 오류 판정의 예외 처리

센서 오류 판정 로직을 엄격하게 적용할 경우, 실제로 센서를 장착하지 않은 금형의 데이터까지 모두 '오류'로 분류되는 문제가 발생합니다. 센서를 장착하지 않은 상태에서는 당연히 온도나 압력 값이 측정되지 않거나 매우 낮은 값으로 유지되기 때문입니다. 이를 방지하기 위해 본 가이드에서는 '미장착'이라는 별도의 상태를 정의하여 센서 오류 판정에서 제외합니다.

미장착의 판단 기준은 전체 수집 사이클의 95% 이상에서 다음 조건이 충족되는지 확인하는 것입니다. 온도 센서의 경우 T < 30°C, 압력 센서의 경우 P < 50bar 기준을 적용합니다. 이는 센서가 금형 내부에 삽입되어 수지와 접촉하고 있다면, 공정 중 발생하는 열과 압력으로 인해 반드시 이 임계값을 상회하게 된다는 도메인 지식에 근거합니다. 

만약 특정 채널의 값이 지속적으로 30°C 미만이거나 50bar 미만으로 유지된다면, 이는 센서가 고장 난 것이 아니라 처음부터 해당 위치에 센서를 설치하지 않은 상태로 해석하는 것이 타당합니다. 따라서 95% 이상의 사이클이 이 기준에 해당한다면, 해당 채널에서 발생하는 T_MAX=0이나 P_MAX=0 현상은 '센서 오류'가 아닌 '정상적인 미장착 상태'로 간주하여 오류 판정 대상에서 제외합니다.

이러한 예외 처리 로직은 하드웨어 유지보수 효율성을 높이는 데 목적이 있습니다. 모든 0 값을 오류로 처리할 경우, 관리자는 장착하지 않은 센서까지 교체해야 하는 불필요한 리소스를 낭비하게 됩니다. 따라서 '지속적인 저수치'는 미장착으로, '간헐적인 0 값 발생'이나 '특정 조건의 0 값'은 오류로 구분하여 해석하는 엄격함이 필요합니다.

## 하드웨어 결함과 데이터 누락의 구분 및 요약

미연결(NO_SIGNAL)과 센서 오류(SENSOR_ERROR)는 모두 분석 대상에서 제외되는 데이터이지만, 그 원인과 대응 방안은 완전히 다릅니다. 이를 구분하는 핵심은 '데이터의 존재 여부'와 '값의 유효성'에 있습니다.

미연결은 데이터 자체가 존재하지 않는(NaN) 상태이며, 이는 주로 전송 경로(케이블, 커넥터)의 물리적 단절에서 기인합니다. 반면, 센서 오류는 데이터는 존재하지만 그 값이 물리적으로 불가능한(0) 상태이며, 이는 센서 소자 자체의 결함이나 시스템 설정 오류에서 기인하는 것으로 추정됩니다.

두 상태의 판정 기준을 표로 정리하면 다음과 같습니다.

| 구분 | 판정 기준 (Trigger) | 도메인적 해석 | 주요 추정 원인 |
| :--- | :--- | :--- | :--- |
| **미연결 (NO_SIGNAL)** | T 채널 전체 = NaN | 신호 수신 불가 상태 | 케이블 단선, 커넥터 접촉 불량 |
| **센서 오류 (SENSOR_ERROR)** | T_MAX=0(2채널↑) \lor P_MAX=0(1채널↑) \lor CycleTime=0 | 신호는 수신되나 값 무효 | 센서 소자 파손, 시스템 트리거 오류 |
| **미장착 (Uninstalled)** | 95% 이상 T < 30°C \lor P < 50bar | 센서 미설치 상태 | 설계상 센서 제외 또는 설치 누락 |

위 표에서 알 수 있듯이, 분석가는 데이터 사전의 정의에 따라 NaN과 0을 엄격히 구분하여 기록해야 합니다. 특히 미장착 기준(30°C / 50bar)을 먼저 적용한 뒤, 남은 데이터 중 0 값을 찾아 센서 오류를 판정하는 순차적 필터링 과정이 필수적입니다. 이 과정을 통해 하드웨어의 실제 결함 여부를 정확히 진단하고, 분석 대상인 NORMAL 사이클의 순도를 높일 수 있습니다.

**핵심 요약**
* **미연결(NO_SIGNAL)**은 T채널 전체가 NaN인 상태로, 케이블이나 커넥터 등 물리적 연결 문제로 해석된다.
* **센서 오류(SENSOR_ERROR)**는 T_MAX=0(2채널 이상), P_MAX=0(1채널 이상), CycleTime=0인 상태로, 센서 소자 결함이나 시스템 오류로 해석된다.
* **미장착 기준**(T < 30°C, P < 50bar가 95% 이상)을 통해 실제 고장과 단순 미설치 상태를 구분하여 불필요한 오류 판정을 방지한다.
