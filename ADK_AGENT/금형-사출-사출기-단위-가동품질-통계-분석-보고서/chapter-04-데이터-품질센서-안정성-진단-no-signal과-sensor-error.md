# 4. 데이터 품질·센서 안정성 진단 — NO_SIGNAL과 SENSOR_ERROR

## 데이터 품질·센서 안정성 진단 — NO_SIGNAL과 SENSOR_ERROR

## 분석 배경

본 장에서는 수집된 전체 사이클 중 분석 불능 상태를 유발하는 '수집 안정성 지표'를 진단한다. 데이터 품질 저하의 핵심 원인은 (A) 센서/데이터 품질 에러(NO_SIGNAL, SENSOR_ERROR)와 (B) 가동 비효율(WARMUP, IDLE)로 구분되며, 본 분석의 목적은 전자인 '수집 안정성'의 결함을 정량화하는 것이다. 특히 NO_SIGNAL(신호 미검출)과 SENSOR_ERROR(센서 값 이상)는 발생 기전이 상이하므로, 이를 분리하여 접근함으로써 설비별 하드웨어 결함인지 혹은 통신/설정의 문제인지를 판별한다. 분석 단위는 CSV의 `machine` 열과 `controller` 폴더가 1:1로 대응되는 사출기 기준이며, 제공된 실측 수치를 기반으로 우선 점검 대상 설비를 도출한다.

## 심층 분석 및 도메인 추론

### 1. NO_SIGNAL의 지배적 발생과 시스템적 결함 추론
전체 수집 사이클 3,320,582회 중 NO_SIGNAL이 2,900,949회(87.36%)로 압도적인 비중을 차지한다. 특히 toprun_A2(99.85%), toprun_C7(99.44%), toprun_C650-4(99.17%) 등 상위 8개 설비의 에러율이 모두 88%를 상회한다. 

NO_SIGNAL은 T1~T8_Max 값이 전부 결측(NaN)인 상태를 의미한다. 이는 단순한 센서 개별 고장이 아니라, 사출기 컨트롤러에서 데이터 수집 시스템으로의 신호 전송 경로 자체가 단절되었음을 의미한다. 도메인 관점에서 볼 때, 이는 다음과 같은 원인으로 추정된다.
첫째, 컨트롤러-수집 서버 간의 통신 프로토콜 설정 오류 또는 네트워크 인터페이스의 물리적 단절 가능성이 높다. 
둘째, 특정 제조계열(toprun)에서 공통적으로 나타나는 현상인 점으로 보아, 해당 설비 군의 데이터 덤프 설정이나 API 매핑 과정에서 체계적인 누락이 발생하고 있는 것으로 보인다. 
결과적으로 toprun_A2, C7, C650-4, C650-5, C5, C11, A5, A3 설비는 현재 데이터 수집 체계가 사실상 작동하지 않는 상태이며, 수집된 데이터의 대부분이 무의미한 '빈 껍데기' 사이클임이 입증된다.

### 2. SENSOR_ERROR의 국소적 집중과 하드웨어 결함 분석
NO_SIGNAL이 '통신 단절'의 문제라면, SENSOR_ERROR는 '데이터 오염'의 문제다. SENSOR_ERROR는 센서가 연결되어 신호는 들어오나, 장착된 T채널의 T_Max가 0이거나 P채널의 P_Max가 0인 경우, 혹은 사이클 타임이 0인 경우에 판정된다.

가장 심각한 지점은 woosung_54 설비이다. 해당 설비의 SENSOR_ERROR 건수는 9,023건으로, 전체 15대 설비 중 최다치를 기록하고 있다. woosung_54의 센서 에러율 47.08% 중 NO_SIGNAL(3,064건)보다 SENSOR_ERROR(9,023건)가 약 3배 가량 높게 나타난다. 이는 통신망은 정상 작동하고 있으나, 실제 물리적 센서가 값을 출력하지 못하는 하드웨어적 결함이 발생했음을 시사한다.

또한 toprun_D8(6,139건)과 woosung_42(995건)에서도 유의미한 수준의 SENSOR_ERROR가 관찰된다. 특히 toprun_D8은 NORMAL 비율(64.69%)이 높음에도 불구하고 SENSOR_ERROR가 6,139건 발생했다는 점은, 가동 중 간헐적으로 센서 신호가 끊기거나 특정 채널의 센서가 파손되어 오작동하고 있을 가능성을 뒷받침한다. 이는 제품 불량률과는 별개의 문제이며, 순수하게 '계측 시스템의 신뢰성'이 훼손된 상태로 판단된다.

### 3. 수집 안정성 관점에서의 설비 그룹화
데이터 품질 수치를 기반으로 설비를 세 가지 그룹으로 재분류할 수 있다.
- **[그룹 1] 통신 불능 그룹 (toprun 다수):** NO_SIGNAL이 지배적이다. 센서 교체가 아닌 네트워크 및 컨트롤러 설정 전면 재검토가 필요하다.
- **[그룹 2] 센서 결함 그룹 (woosung_54, toprun_D8):** 신호는 수신되나 값이 비정상이다. 센서 소자 교체 및 배선 점검이 시급하다.
- **[그룹 3] 안정 수집 그룹 (woosung_48, woosung_45):** 센서 에러율이 매우 낮다(woosung_48은 4.18%). 이 그룹의 데이터가 분석의 기준점(Baseline)이 되어야 한다.

결론적으로, 전체 사이클의 87%를 차지하는 NO_SIGNAL 문제는 개별 사출기의 문제가 아닌 데이터 파이프라인의 시스템적 결함으로 보이며, woosung_54의 SENSOR_ERROR 문제는 명백한 하드웨어 유지보수 대상이다.

## 챕터 요약 및 제언

### 핵심 정리
- **수집 안정성 붕괴:** 전체 사이클의 87.36%가 NO_SIGNAL로 판정되어, 데이터 수집 시스템의 실효성이 극도로 낮은 상태이다.
- **에러 성격의 명확한 분리:** toprun 계열은 '통신/설정 누락(NO_SIGNAL)'이 주원인이며, woosung_54는 '물리적 센서 고장(SENSOR_ERROR)'이 주원인으로 분석된다.
- **최우선 관리 대상:** 센서 에러율 99% 이상의 toprun 상위 설비들과 SENSOR_ERROR 절대 수치가 가장 높은 woosung_54를 최우선 점검 대상으로 지정한다.

### 엔지니어 조치 제언
- **toprun 계열 설비:** 컨트롤러-서버 간 통신 프로토콜 및 데이터 덤프 설정값을 전수 조사하고, 물리적 네트워크 케이블의 결선 상태를 재확인할 것을 권장한다.
- **woosung_54 설비:** 즉시 가동을 중단하거나 센서 점검을 실시하여, T채널 및 P채널 센서의 단선 여부를 확인하고 노후 센서를 교체할 것을 권장한다.
- **데이터 필터링 적용:** 향후 분석 시, NO_SIGNAL과 SENSOR_ERROR가 포함된 사이클은 분석 대상에서 완전히 배제하고, NORMAL 사이클만을 대상으로 통계적 유의성을 확보해야 한다.
