# 2. 데이터 분석 소프트웨어 개발 방향

## 2. 데이터 분석 소프트웨어 개발 방향

본 시스템은 총 517,130 사이클의 대규모 데이터를 효율적으로 처리하고, 운영 중인 분석 모델을 실시간 공정에 적용하기 위한 수집-전처리-모델링-서빙 파이프라인 구축을 목표로 한다. 전체적인 설계 방향은 **[데이터 수집-전처리-모델링-서빙 전체 파이프라인 아키텍처 다이어그램]**을 기반으로 하며, 데이터의 정합성과 추론의 실시간성을 확보하는 데 중점을 둔다.

### 2.1 수집 및 적재 파이프라인
사이클 단위(Shot 단위)로 발생하는 센서 데이터와 공정 시간 데이터를 실시간으로 수집하여 분석 가능한 형태로 적재한다.

*   **데이터 인입**: 517,130건의 사이클 데이터를 기준으로, 각 사이클의 시작(StartTime)부터 종료(EndTime)까지의 센서 값 및 공정 시간(ProcessTime1~6)을 단위 패킷으로 수집한다.
*   **저장 구조**: 금형 모델(Model), 파트 번호(PartNo), 재료(Resin/Grade) 등 메타데이터와 함께 시계열 센서 데이터를 매핑하여 저장하는 관계형 또는 시계열 데이터베이스 구조를 채택한다.
*   **처리 단위**: 개별 센서의 로우 데이터가 아닌, 사이클 단위로 집계된 피처(Start, End, Max 등)를 기본 적재 단위로 설정하여 분석 효율을 높인다.

### 2.2 전처리 및 피처 엔지니어링
수집된 데이터 중 센서 오류 및 신호 누락 구간을 처리하고, 모델의 예측 성능을 높이기 위한 파생 피처를 생성한다. 상세한 처리 과정은 **[전처리 단계에서의 센서 데이터 보간 로직 흐름도]**를 통해 구현한다.

*   **결측치 및 이상치 처리**:
    *   **분석 대상**: `SENSOR_NO_SIGNAL`(170,693건) 및 `SENSOR_ERROR`(36,714건) 타입의 데이터.
    *   **보간 전략**: 센서 간 높은 상관관계를 활용한 회귀 보간법을 적용한다. 
        *   예: $T5\_Start$와 $T6\_Start$의 상관계수 $r=0.962$, $T5\_Max$와 $T5\_Start$의 상관계수 $r=0.96$ 등 고상관 피처를 이용하여 누락된 센서 값을 추정한다.
*   **피처 엔지니어링**:
    *   **공정 시간 피처**: `ProcessTime` 필드(ms 단위)를 초(sec) 단위로 변환하여 분석에 활용한다.
    *   **통계 피처**: 센서별 $\text{Max} - \text{Start}$ 값 등을 통해 사이클 내 온도/압력 변동 폭을 산출한다.

### 2.3 모델링 계층
이미 검증되어 운영 중인 모델(`models_in_use`)을 추론 엔진으로 통합하여 일관된 분석 결과를 제공한다.

| 분석 과제 | 적용 모델 | 주요 피처 수 | 비고 |
| :--- | :--- | :--- | :--- |
| **이상 탐지 (Anomaly)** | Isolation Forest | 33개 | 실측 이상률(전체 11.72%)을 베이스라인으로 하여 이상 징후를 탐지 |
| **금형 식별 (Mold ID)** | Gradient Boosting | 45개 | 29개 클래스 분류 |
| **사이클 타입 분류** | Gradient Boosting | 45개 | NORMAL, IDLE, WARMUP 등 분류 |
| **사이클 타임 예측** | Gradient Boosting | 32개 | 평균 CT 58.02초 기준 예측 |
| **웜업 판별 (Warmup)** | Logistic Regression | 33개 | 초기 가동 상태 판별 |

### 2.4 서빙 및 대시보드 아키텍처
분석 결과를 현장 관리자가 즉시 확인할 수 있도록 API 기반의 서빙 구조와 실측 지표 중심의 대시보드를 구성한다.

*   **데이터 서빙**: 모델링 계층에서 도출된 추론 결과를 REST API 형태로 제공하여 대시보드와 연동한다.
*   **핵심 모니터링 지표**:
    *   **사이클 타임**: 전체 평균 $58.02\text{sec}$ 대비 개별 모델 및 사이클의 편차 모니터링.
    *   **모델별 이상률**: 금형 모델별로 상이한 이상률(최저 $MBN66622301: 0.00008705\dots \approx 0.0087\%$ $\rightarrow$ 최고 $MCK71924401: 0.1359\dots \approx 13.59\%$)을 베이스라인으로 설정하여 상대적 이상 징후를 탐지한다.
    *   **공정 효율**: `cool_sec` 평균 $32.72\text{sec}$ 등 주요 공정 단계별 시간 분포(p25~p75)를 시각화한다.

### 2.5 MLOps 및 재학습 체계
금형 교체나 공정 조건 변경 시 모델의 성능 저하를 방지하기 위해 지속적 학습 및 모니터링 체계를 구축한다.

*   **재학습 트리거**:
    *   **신규 금형 도입**: `mold_models`에 정의되지 않은 새로운 모델 ID 인입 시.
    *   **성능 저하**: 실측 이상률이 모델별 베이스라인(예: $MCK71986401$의 $0.03677\dots \approx 3.68\%$)에서 유의미하게 벗어나는 경우.
*   **파이프라인 구성**: `데이터 수집` $\rightarrow$ `성능 모니터링` $\rightarrow$ `재학습 데이터셋 구성` $\rightarrow$ `모델 업데이트` $\rightarrow$ `배포` 순의 자동화 워크플로우를 지향한다.
*   **모델 버전 관리**: 각 금형 모델별로 최적화된 가중치를 관리하여, 모델 교체 시 해당 금형에 최적화된 추론 모델이 즉시 로드되도록 설계한다.
